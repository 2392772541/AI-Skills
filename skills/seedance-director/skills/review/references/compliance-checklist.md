name: compliance-checklist
description: 当跑合规横切线、逐条做布尔判定、给命中项找依据与规避写法时翻它。12 类判据 + 片型附加组，每类四段：依据 / 命中样态逐条布尔 / 不算命中边界 / 可执行改向。🔴 绝对红线、🟡 平台误杀规避、🔵 投放侧合规三色严格分性质，按定位取条目用，不顺序读完。
---

[定位]
    本卡是五类病里「红线」的判据库，不是又一份规则。SKILL.md 已立纪律：布尔判定、零容忍、任一 🔴 命中即 blocking、逐条过、命中要定位符 + 原文证据。本卡给的是"这条具体长什么样才算命中、依据什么、怎么改能规避"——翻这里。
    🔴、🟡、🔵 是三种性质，混判即缺陷。🔴 绝对红线 = 法律与平台硬禁，内容里有它就不许生成，命中即 blocking；🟡 平台误杀规避 = 不是法律红线，是提升生成通过率的工程约束，命中只标"建议改 + 通过率风险"；🔵 投放侧合规 = 内容本身能生成，卡的是上线前的手续与资质，命中只标"投放前置事项 + 责任方"、reflow_to 一律 user。🟡 与 🔵 都不判 FAIL、不置 blocking，除非同时踩了某条 🔴。生成侧与投放侧不许互相顶替：内容干净、缺的是备案或许可，是类 12 命中，不是类 1–10 里任何一条命中。
    判定只看被审对象的文字与素材引用，不替用户脑补动机。证据是原文片段，不是转述。
    各审级的扫描范围：拆解审扫剧作与设定层，即拆解阐述、资产清单、大纲；资产审扫三个 prompts 包、镜头表审扫全集镜头表，图像与视频提示词都算；成片审全量重扫 + 跨条组合风险——单条无害、连起来构成可操作教程或侵权叙事的，按组合判。

[怎么用]
    1. 逐条扫：每条/每镜/每个资产提示词过一遍 12 类，不是整篇扫一遍就算。
    2. 命中先归类：先判 🔴、🟡 还是 🔵，再写命中样态 + 定位符 + 原文证据。
    3. 给可执行改向：每条命中都要能让回流 skill 照着改，不是只说"违规"。
    4. 写进报告：合规节 PASS/FAIL、逐类布尔、blocking 标记、回流去向。路由细表见 reflow-routing.md：角色/服装类回 character-design，场景类回 scene-design，道具类回 prop-design，提示词文字类回 motion-compile，剧情设定层回 script-breakdown / script-adapt，投放侧类回 user。

[联网纪律]
    平台红线和法规会更新。判前涉及"某条是否仍是红线、平台拦截边界是否变化、新规是否生效"，先 WebSearch 核实再下结论，不拿记忆当事实；拿不准的合规结论一律重查。

[类 1 · 🔴 真人肖像]
    依据：
        写实真人脸已由平台开放支持，可自由用于创作，不再是红线。仍保留的法律边界：用特定真实公众人物的肖像/姓名作主体，受《民法典》肖像权与《生成式人工智能服务管理暂行办法》约束，需授权。
    命中样态 · 逐条布尔：
        - [ ] 以明星/政要/名人这类可辨认的真实公众人物的肖像或姓名作主体或配角，无授权迹象。 → 提示注意肖像权授权，非强制 FAIL；政治人物从严，叠类 3 判。
    不算命中 / 边界：
        - 写实真人脸本身，即原创的真实感人物、写实风格角色：不命中，自由用。
        - 点名真实导演/摄影师署名当风格快捷键，如"Deakins 式布光"：不命中——创作手法，鼓励用。
    改向：
        涉特定公众人物肖像/姓名 → 提示用户确认授权，或改为不可辨认的原创形象。其余不拦。

[类 2 · 🔴 版权 IP]
    依据：
        《生成式人工智能服务管理暂行办法》第四条要求尊重知识产权。已有判例：用户投喂 AI 生成《斗破苍穹》版权角色形象图，被法院判赔 5 万元——红线对国产网文/动漫 IP 同样落地，不止迪士尼/漫威。
    命中样态 · 逐条布尔：
        - [ ] 角色名/形象/设定取自已知版权 IP——迪士尼、漫威、DC、哈利波特、宝可梦，及《斗破苍穹》《斗罗大陆》等国产 IP 的角色名与标志性形象。
        - [ ] 描述复刻某 IP 的标志性造型/法宝/招式/场景设定，即使不写角色名。
        - [ ] 复刻经典影视的具体片段、分镜、台词、海报构图。
        - [ ] 受保护的品牌 logo、商标、知名产品外观当画面主体。
    不算命中 / 边界：
        - 通用题材母题，如"修真""废材逆袭""末世丧尸"类世界观，不构成侵权——母题不可版权化，具体角色名/形象才是红线。
        - 用户自有原创 IP：不命中。
    改向：
        IP 角色名与形象回 script-breakdown / character-design 改原创；标志性场景回 scene-design、法宝道具回 prop-design 改原创；复刻片段改原创分镜；世界观抄袭回剧作层改设定。

[类 3 · 🔴 政治 / 国家安全]
    依据：
        《生成式人工智能服务管理暂行办法》第四条禁止危害国家安全与利益、煽动分裂、宣扬恐怖主义极端主义等内容；歪曲否定英雄烈士另受《英雄烈士保护法》约束。
    命中样态 · 逐条布尔：
        - [ ] 反对宪法确定的基本原则、危害国家安全与利益、损害国家形象。
        - [ ] 煽动分裂国家、破坏国家统一和民族团结、破坏社会稳定。
        - [ ] 歪曲、丑化、亵渎、否定英雄烈士事迹和精神。
        - [ ] 宣扬恐怖主义、极端主义；违禁政治符号、旗帜、口号当画面元素。
        - [ ] 涉及国家领导人、政治人物形象或姓名，与类 1 叠加时从严。
    改向：
        回对应生成 skill 删除/替换敏感元素；涉剧情设定回 script-breakdown。此类通常不可"改写规避"，须从内容上移除。

[类 4 · 🔴 宗教]
    依据：
        平台内容政策 + 国家宗教事务相关规定：不得违反宗教政策、宣扬邪教与封建迷信；生成侧对宗教人物形象拦截率更高。
    命中样态 · 逐条布尔：
        - [ ] 违反国家宗教政策、损害宗教和睦。
        - [ ] 宣扬邪教、封建迷信，如算命、附体、邪术驱魔当正面叙事。
        - [ ] 生成佛陀、耶稣、先知等具体宗教人物形象，或可被认作真实宗教崇拜对象的形象。
    不算命中 / 边界：
        - 玄幻/修真题材的虚构神祇、原创神格体系：架空世界观 ≠ 现实宗教，不命中——但直接挪用现实宗教符号当法器则命中。
    改向：
        现实宗教人物形象回 character-design 改原创；现实宗教符号道具回 prop-design 改架空；删除邪教与迷信的正面渲染。

[类 5 · 🔴 色情 / 低俗]
    依据：
        《生成式人工智能服务管理暂行办法》第四条禁止淫秽色情；"清朗"专项重点打击"一键脱衣"等违背伦理功能。
    命中样态 · 逐条布尔：
        - [ ] 淫秽色情、裸露、性行为或性器官的直接描绘。
        - [ ] 性暗示、软色情——挑逗姿态、暧昧体液、刻意强调性特征的镜头语言。
        - [ ] 任何脱衣/换装到暴露的指令链。
    改向：
        回 character-design / motion-compile：删性化描述、服装改正常着装、镜头语言去性暗示。与类 11 🟡 暴露服装分清：这里是硬禁，类 11 是误杀规避。

[类 6 · 🔴 犯罪教唆]
    依据：
        类型化的血腥、暴力、武打是恐怖/动作/战争片的创作刚需，已放开，不当红线。仍保留的硬线：禁止可操作的真实犯罪指导。
    命中样态 · 逐条布尔：
        - [ ] 含赌博、诈骗、制毒制爆等真实犯罪手法的可操作指导，含跨条拼合后构成完整教程的组合。
    不算命中 / 边界：
        - 血腥、残肢、打斗、战争、恐怖等类型化暴力画面：不命中，按创作需要自由用。
    改向：
        回 motion-compile / script-breakdown 删除具体可操作方法，保留剧情冲突本身。
    注：
        自杀/自残作剧情转折不限；仅避免把过程当正面、唯美的细节渲染，此为软提示、不判 FAIL。

[类 7 · 🔴 未成年人]
    依据：
        《生成式人工智能服务管理暂行办法》要求防范对未成年人的侵害；专项治理把未成年人列为重点领域。
    命中样态 · 逐条布尔：
        - [ ] 任何形式对未成年人的侵害、性化、暴力伤害。
        - [ ] 危害未成年人身心健康的内容，如诱导危险行为、恐怖惊吓面向未成年人。
        - [ ] 未成年角色被置于成人化、性暗示或受害情境。
    改向：
        回 script-breakdown / character-design：移除侵害情节；必要时调整角色年龄设定，避免未成年角色进入风险情境。

[类 8 · 🔴 仇恨 / 歧视]
    依据：
        《生成式人工智能服务管理暂行办法》要求防止民族、信仰、国别、地域、性别、年龄、职业、健康等歧视。
    命中样态 · 逐条布尔：
        - [ ] 基于上述维度的贬损、刻板丑化、煽动仇恨。
        - [ ] 把某群体设为天然反派或低人一等的叙事/视觉符号。
    改向：
        回 script-breakdown / character-design：删歧视性设定与符号，群体形象去刻板化。

[类 9 · 🔴 人身权利]
    依据：
        《民法典》人格权编 + 《生成式人工智能服务管理暂行办法》：不得侵害他人肖像权、名誉权、荣誉权、隐私权和个人信息权益。
    命中样态 · 逐条布尔：
        - [ ] 侵犯具体真人/组织的名誉权，如污名、诽谤性情节。
        - [ ] 侵犯隐私权——暴露真实个人隐私信息、可辨认的真实店铺/住址/路人。
        - [ ] 侵犯肖像权、其他知识产权。
    改向：
        回对应生成 skill：指向真实主体的内容改虚构、去标识化。

[类 10 · 🔴 虚假信息]
    依据：
        《生成式人工智能服务管理暂行办法》第四条禁止虚假有害信息；《人工智能生成合成内容标识办法》要求 AI 生成内容可被识别、禁止恶意删除/篡改标识。
    命中样态 · 逐条布尔：
        - [ ] 散布谣言、伪造事实、伪造新闻/官方通告/权威背书。
        - [ ] 把 AI 生成内容伪装成真实纪实、真实事件影像。
        - [ ] 伪造可被误认为真实的证据性画面，如伪造证件、监控。
        - [ ] 被审文字出现"去水印/去角标/去 AI 标识"类指令 → 按恶意删除标识的 🔴 命中。
    改向：
        回 motion-compile / script-breakdown：去伪纪实/伪权威包装，明确虚构定位；删去标识指令。
    注：
        显式/隐式标识义务在用户出片导出环节由平台侧承担，不是审提示词的判定项——只有上条"去标识指令"入判。

[类 11 · 🟡 平台误杀规避 · 通用组]
    定位：
        命中不判 FAIL，标"建议改 + 通过率风险"。是生成侧高频误杀写法，改了显著提升出图出片成功率。仅当同时踩 🔴 才升级 FAIL。
    命中样态 · 逐条：
        - [ ] 服装过度暴露/紧身/内衣泳装类描述 → 建议改正常着装或减少暴露词。
        - [ ] 动漫/漫画风格叠加任何擦边描述 → 动漫风拦截阈值更低，描述更克制。
        - [ ] 医学/解剖/手术类场景 → 易被判血腥，建议加"医学示意"语境。
        - [ ] 大面积裸露皮肤、湿身、束缚类视觉 → 非色情但高误杀，建议弱化。
    改向：
        服装类回 character-design、画面描述类回 motion-compile：逐条软化，标注"为通过率规避，非红线"。

[类 12 · 🔵 投放侧合规 · 备案 / 分级 / 许可]
    定位：
        内容能不能生成、片子能不能上线，是两件事；本组只管后者。与类 1–10 的分界：内容里有违禁物 = 那几类；内容干净、缺的是手续与资质 = 本组。命中不判 FAIL、不置 blocking、不改 compliance 线 status——它拦不住生成，只决定成片能不能公开投放。
    依据：
        网络剧片上线走《网络剧片发行许可证》与重点网络影视剧信息备案；重大革命历史、民族宗教、军事外交等题材另有重大题材备案要求。国内无正式影视分级，但平台有内容分级与青少年模式的自审要求。音乐、字体、影像素材与真实品牌的商用授权按各自许可条款。《人工智能生成合成内容标识办法》的显式标识义务落在出片与上线环节，不落在提示词。
    命中样态 · 逐条布尔：
        - [ ] 题材落在重大革命历史、民族宗教、军事外交、涉案这类需前置备案或从严审查的区间。
        - [ ] 暴力、惊悚、性暗示的强度需要分级或限制受众才适合投放，内容侧本身未踩 🔴。
        - [ ] 引用的音乐、字体、影像素材或真实品牌，内容侧不构成类 2 侵权，但商用投放需另拿许可，授权状态查不到。
        - [ ] 片子定位为公开发行，项目里却查不到发行许可与备案的责任人与进度。
        - [ ] 成片的 AI 生成标识由谁在哪一步打，交付材料里无着落。
    不算命中 / 边界：
        - 自用、内部试片、不公开投放：本组整组不适用，标 clear。
        - decisions.md 已记过备案与许可安排：有着落即 clear，不重复提醒。
    改向：
        reflow_to 一律 user——手续与资质是用户侧决策，审核只暴露、不派制作 skill；fix 写清是哪一项、要什么材料、卡在哪一步，随成片审报告呈给用户。内容层面无须改动，不许因本组去改剧本或提示词。

[类 13 · 片型附加项 · 按 creative-brief 的片种分轨取用，只查本片片型那组]
    电影级 / 短剧：
        - 🟡 类型化暴力虽放开，密集血腥特写连排仍有误杀风险 → 建议关键帧避开创口大特写。
        - 🟡 短剧高频冲突桥段，如婆媳/地域/职业贬损梗，易滑向类 8 刻板丑化 → 建议冲突落在具体人物行为，不落在群体标签。
    漫剧，动漫风：
        - 🟡 全片处于动漫风低拦截阈值区，类 5、类 11 相关描述全程从严自查；未成年感角色外形即幼态脸+成人情境，按类 7 从严判。
    广告 / MV：
        - 🔴 真实品牌 logo、商标、产品外观入镜按类 2 判；真人名人形象暗示代言按类 1 + 类 9 判。
        - 🔵 功效/排名绝对化断言，如"最好""第一""根治" → 广告法投放侧风险，按类 12 判、随报告提示用户在生成侧自查，不判 FAIL。
    UGC vlog：
        - 🔴 伪装真实记录——伪街拍、伪监控、伪新闻现场——按类 10 判；UGC 质感块 + "真实事件"暗示是高危组合。
        - 🟡 画面含可辨认真实店铺招牌、路人面孔描述 → 类 9 风险，建议虚构化处理。

[判定速查 · 写进报告的最小集]
    每级扫完，compliance 线给出：
        - status：PASS/FAIL，任一 🔴 命中即 FAIL；🟡 与 🔵 单独命中不改 status。
        - dimensions：1–13 各一个 hit/clear，12 为投放侧合规组、13 为片型附加组。
        - blocking：任一 🔴 命中即 true；🟡 与 🔵 单独命中不置 true。
        - 每条命中：定位符 + 类别编号 + 🔴/🟡/🔵 + 原文证据 + reflow_to + fix。
    三色在报告里分区高亮，不混在一段。
