# 场景板提示词母版

## 使用说明

场景板提示词的可填空母版：主板、角度板、变体板、穿行取角条含截取清单、reference-index 登记块。{{}} 内为填空位，填完删掉括号连同提示语；成品是一段连贯散文，整块复制即出图。每个围栏 = 一条可投喂提示词或一个逐字引用块，围栏第一个字就是模型读到的第一个字；元信息全在围栏外——条头、锚定资产注记、截取清单一律不进围栏。落盘去向：04-assets/scenes-prompts.md，按集追加。

## 条头母版 · 落盘文件内的元信息行，不进生成框

按板型取一行，写在该板提示词围栏之上：

- 主板：## {{epNN}} · {{场景名}}（{{新增/变体}}｜scene-{{NNN}}｜{{核心/边角}}）
- 角度板：## {{epNN}} · {{场景名}} · {{角度名，如：吧台侧反打}}（scene-{{NNN}}-a{{N}}，同属 scene-{{NNN}}）
- 变体板：## {{epNN}} · {{场景名}} · {{变体名，如：打烊断电版}}（scene-{{NNN}}-v{{N}}，基于 scene-{{NNN}}）
- 穿行条：## scene-{{NNN}} 穿行取角条（即梦平台执行）

## 主板母版

生成条 · 图像规则集，整块投喂即梦平台文生图。

```
{{逐字嵌入 00-bible/visual-style.md 的视觉风格通用基准段——媒介质感 / 色域 / 光逻辑 / 镜头性格四件，与角色/道具板同一段，一字不差；场域锚句不在这里，它进下一段}}{{烤入属性块：按 visual-style.md 烤入清单，如变形宽银幕光学块/胶片特性组；无烤入项则删本槽}}。{{风格短语，如：写实胶片质感}}场景设定图，一张干净的单角度参考图：3/4 视角{{景别，如：广角建场}}，从{{机位描述，如：大门内侧}}斜看向{{看向哪个角，如：吧台与卡座相交的一角}}。

这是{{地点类型与空间身份，如：一间 1997 年南方小城的街边台球厅}}，{{场域锚句：本场域的年代器物/字体/灯具制式，从 00-bible 定稿处取；具体陈设与时代物证只在这一句落地，它只属于本场域，不进角色板、道具板与跨场恒定层}}。{{时段}}，{{光逻辑：世界内光源 + 方向 + 光质，如：两排吊在球台上方的白炽灯罩投下暖黄硬光，门口透进街上霓虹的青绿}}，整体色调{{色彩语域落地：底色 + 强调色及其框内来源；两套色温并存时显式声明谁优先}}。{{空间结构与纵深：主结构在哪、功能区怎么排、纵深怎么递进，一到两句}}。{{材质分区逐段：每个功能区一句，落到材质 + 磨损 + 光色，用真实表面语言}}。画面内的可辨识地标：{{锚点一}}、{{锚点二}}、{{锚点三}}{{每个锚点点名 + 位置 + 可见特征}}。{{氛围收尾一短句，具体不旁白}}。
```

锚定资产注记，跟在条头下、不进生成框：{{按三档之一处理并写明——档 1 空槽位置写环境不写它；档 2 "外形以 @编号 为准"同源参考；档 3 继承 @编号 设定只补环境；无则删本行}}

```
{{逐字嵌入同一段视觉风格通用基准段}}{{同一烤入属性块}}。{{风格短语}}场景设定图，一张干净的单角度参考图：与 scene-{{NNN}} 同一空间、同一光逻辑、同一时段，机位改为{{本角度机位：站在空间哪一侧、朝哪个方向看，如：从球台短边看向吧台，即坐在吧台一侧人物的身后视野}}，3/4 视角{{景别}}。

本角度看见：{{此方向入画的结构与纵深一句；与别的板共享的结构逐字取自底版「几何关系」，不在这里另写一套}}。{{此方向的材质分区：只写本角度可见的区，各一句}}。可辨识地标：{{本角度入画的锚点，与主板同名同位——锚点名不换、位置关系不变}}。{{场域锚句，与主板同源同句}}。{{氛围收尾}}。
```

## 穿行取角条母版

生成条 · 视频规则集——症状驱动负向可用——整块投喂即梦平台取角，不进成片、不进任何条的条头【上传清单】；与本卡图像提示词分属两栏，永不混排。

```
{{时长 15–30 秒}}，{{画幅同全片}}，写实空镜。以 @scene-{{NNN}} 主板为唯一空间参考：镜头从{{起点方位}}出发，以缓慢匀速{{路径描述：经过哪些功能区、绕过哪些锚点，如：贴着球台长边推进，经过吧台转向大门}}，全程无人无动物，陈设与光照保持主板状态不变，画面稳定无晃动。
```

截取清单，对照角度覆盖需求逐条列，留在围栏外：
    {{角度 1：停在什么方位、看向哪里 → 拟登记为 scene-NNN-aN}}
    {{角度 2：……}}

截取后必须提质放大再当参考图；逐帧与主板核对锚点/材质/光，不合格换穿行路径重拉。

## 登记块

无内联母版，防字段分叉。登记条目的骨架与字段以全库唯一母版 script-breakdown 的 reference-index-template.md 的「场景」段为准：照其条目骨架逐字段填空，落进 04-assets/reference-index.md 场景段。本卡不复制字段清单——两处清单必漂移。场景段填法三点提示：角度覆盖按镜头表精推、大纲粗推或默认档，粗推时在该栏标「待镜头表定稿后核对」；可选的人用规划图 scene-NNN-plan——俯视 · 勿投喂——在「出图要求」行附注，不另加字段；场景板被视频条引用时的继承禁令——只控几何材质光线氛围、不控构图——归 motion-compile 绑定时写入，不是登记字段。填好的标杆见 examples/scene-example.md 登记块。

## 写作要点

1. 基准先行：每张板第一段 = visual-style.md 通用基准段逐字嵌入，烤入属性块紧随其后——先钉全片，再写本板。通用基准段管全片画风、场域中立；本场域的陈设与时代物证住场域锚句，那一句只进本场域的板与条——它是角色板、道具板与跨场恒定层都拿不到的一层。
2. 一板一角度：主板、每个角度板、每个变体板各是独立一张干净图、独立编号；不拼宫格、不一图多视角。
3. 3/4 视角写法：写"从哪个位置斜看向哪个角"，让两个面与一条纵深同时入画；禁正对单面墙。
4. 锚点点名：每个锚点给名字 + 位置 + 可见特征，与登记块、空间地图底版三处同名——名字变了绑定就断。
5. 角度板不重造世界：同一空间/光逻辑/时段一句声明，只写本角度可见的东西；锚点名与位置关系必须与主板一致；跨板共享的结构逐字取自底版「几何关系」，对账法见 ../references/angle-coverage.md [判据卡 · 多板共享几何对账]。
6. 变体只写变化：空间与机位一字声明"同原版"，笔墨全给变化点；变体是新编号，不覆盖原板。
7. 密度纪律：每句都要有信息增量，删无可删——不为凑篇幅注水，修饰堆叠不加信息只稀释注意力。
8. 纯正向：一切「无 X/不要 X」改写为期望态；「排除项」清单一律翻译成"这里是什么样"。
9. 双规则集隔离：穿行取角条独占围栏、规则集声明写在围栏外的标题行，图像提示词里不出现负向症状句，取角条里不套图像词数纪律。

## 自检

- [ ] 每张板开头逐字嵌入通用基准段，与角色/道具板同一段；段内无本场域陈设。
- [ ] 每张板 3/4 单角度、无正面、无宫格、独立编号；每个围栏 = 一条可投喂提示词或一个逐字引用块，元信息全在围栏外。
- [ ] 锚点在提示词正文、登记块、空间地图底版三处同名同位；跨板共享结构逐字同源于底版「几何关系」，拿本场动作对每张板反推得同一结果。
- [ ] 场域锚句一句在板内且与 00-bible 定稿处同句，只落在本场域的板上。
- [ ] 色彩两套描述并存时已显式声明层级。
- [ ] 锚定资产按三档处理、档 2、3 已记 @依赖。
- [ ] 变体只写变化点、新编号、原板未动。
- [ ] 全文无负面句式、无质量词空话；穿行取角条已单独声明规则集。
- [ ] 登记块字段填齐、缺口与待核对项标注清楚。
