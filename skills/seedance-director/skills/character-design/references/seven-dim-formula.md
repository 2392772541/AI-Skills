[定位]
    七维公式是 Seedance 2.5 官方的真人人物公式，动画/风格化人物同样适用，是本站一切文字描述的内容骨架：密版按七维填满，提示词主体描述按七维精选。三格法管图，见 references/three-panel-method.md；七维公式管文字。
    总公式：人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂] + [发型/发色] + [服装/服装质感] + [体型/情绪/气质]
    本卡每节按「怎么认 / 认错长什么样 / 典型例子」给判据，每节另在首行给该维的子公式。

[年龄与种族定位]
    子公式：
        年龄段精确到十年内 + 性别 + 种族/地域特征 + 一句身份定位。
    怎么认：
        读完能在脑内 casting 出一个具体的人，而不是一类人。
    认错长什么样：
        「中年男人」——三十五还是五十五？体制内还是跑船的？
    典型例子：
        「六十岁上下的中国南方男性，常年在江面讨生活的渡船人。」

[肤色与皮肤质感]
    子公式：
        冷暖色调 + 肤色名词 + 质感形容词 + 强制保真后缀，写实项目必挂。保真后缀是官方常量，逐字挂：「保留真实的微细毛孔与肌肤纹理」，可加雀斑/瑕疵/晒斑等真实缺陷。
    怎么认：
        色调有冷暖方向、质感有成因——风吹日晒或久居室内。
    认错长什么样：
        只写「皮肤黝黑」；写实项目漏挂保真后缀——出图皮肤呈塑料感。
    典型例子：
        「偏暖的深小麦色皮肤，被江风磨出粗粝的质感，颧骨和鼻梁上有深浅不一的晒斑，保留真实的微细毛孔与肌肤纹理。」

[面部细节特征]
    子公式：
        眼型 + 眉骨 + 鼻梁 + 唇形 + 下颌线，至少组合 3–4 点。
    怎么认：
        3–4 个部位各自落到形状词，合起来是一张能认出的脸——这几点也是 G1 校验锚对照密版时逐项核对的点。
    认错长什么样：
        「五官端正」「面容沧桑」——没有一个部位可核对。
    典型例子：
        「窄长的单眼皮眼睛、眉骨低平，鼻梁高而带一处旧断痕，嘴唇薄且下唇干裂，下颌线松弛、颌角有白色胡茬。」

[眼神与灵魂]
    子公式：
        形容词 + 比喻 + 底层情绪。
    怎么认：
        三件齐——什么样，落形容词；像什么，落比喻；底下压着什么，落情绪。官方例句：「眼底仿佛有一汪春水……透着深深的眷恋」。
    认错长什么样：
        只写「眼神犀利」；或写成「怒视前方」这类表演指令——表情动作是可变层，归动态提示词。
    典型例子：
        「眼神浑浊却定，像看惯了涨水与退水的旧码头石桩，底下压着一层化不开的倦意。」

[发型与发色]
    子公式：
        长度/形态 + 发色 + 贴合方式与碎发细节；官方允许加被风吹、凌乱一类环境互动——但在资产表里，环境互动收敛为静态可复现的状态，即碎发怎么垂、怎么贴，动态的风吹交给视频侧。
    认错长什么样：
        「短发」——哪种短、什么色、怎么贴都没有；写成「头发在风中飞舞」的动态——资产图不该有风。
    典型例子：
        「花白的板寸头，发茬硬而稀疏，鬓角灰白杂黑，额前无碎发。」

[服装与服装质感]
    子公式：
        版型 + 颜色 + 衣物名词 + 材质/新旧状态 + 穿着细节。服装维同时承担时代——角色板上时代的唯一载体就是这一维：年代形制写进衣物，领型、扣式、面料工艺；取值从 00-bible/visual-style.md「时代与世界锚」的年份/地理与服装形制来，不自拟。承载房间陈设与时代物证的场域锚句归场景板，不进本维、也不进板上任何位置——角色板是中灰底空场。时代即法律，不在资产期锚死，模型会把人物拖回当代——"One extra holding a phone and the shot is gone."（一个群演掏出手机，这条就废了。）
    怎么认：
        材质有触感，如洗到发白的粗帆布；新旧有来历，如肘部磨亮；细节有穿法，如袖口挽两折。
    认错长什么样：
        「穿着朴素」；现代卫衣出现在民国戏——时代失守；靠背景摆一张旧月份牌来交代年代——那是场景板的活，角色板的年代只能穿在身上。
    典型例子：
        「洗到发白的藏蓝色粗帆布对襟褂子，领口磨出毛边，袖口挽两折露出小臂，下身黑色宽腿布裤，裤脚沾着干涸的泥点，脚上一双旧黄胶鞋。」

[体型/情绪/气质]
    子公式：
        身高体态 + 体格成因 + 气质一句收尾。官方公式里此段兼管构图——「胸部以上的半身特写构图」——但在资产表里构图由三格版式统辖，此段只写体态与气质、不写构图。
    怎么认：
        体格能读出职业与过往——体格即传记。
    认错长什么样：
        「身材匀称」；在此段写「特写构图/直视镜头」——构图句与三格版式句打架。
    典型例子：
        「一米七上下，肩背厚实但已微驼，是常年弓身撑篙压出来的形；整体气质沉默、耐磨，像一件用旧但没坏的工具。」

[密版 · 短串 · 提示词主体的蒸馏关系]
    密版 = 七维全维填满的一整段散文，密度标准：具体到碎发黏哪、唇色、服装磨损纹样——供本站出图对照与台账反查，只登记在 reference-index，永不进动态提示词成品。
    短串 = 从密版蒸馏的一句话：年龄 + 关键面部 + 发型发色 + 标志服装。用途：下游行内 @char-NNN + 这句锁身份。判据：一句写完、下游愿意原样引用；长了下游会自己重描而漂移。
    提示词主体 = 七维精选：G1 取定位/肤色/面部/眼神/发型这几个头部相关维，G3 取体型/服装/鞋/穿戴件/气质等全身相关维 + 发型背面，各自写成紧凑散文、删无可删。
    认错长什么样：
        密版整段抄进 G1——超词、稀释注意力；短串写成三行——下游拒用；G3 里重复写脸——脸源唯一性要求 G3 的脸交给参考图 G1，正文只写「同一张脸参考所给特写」。
