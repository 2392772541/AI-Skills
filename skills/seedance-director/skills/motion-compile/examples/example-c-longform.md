# 标杆 C · 三回合对峙合成一条的长条

## 示例定位

长条标杆：三个对白回合、A 轨时间戳、22 秒，落 duration-pacing [时长分档] 的合条档。**全库其余标杆都在 18 秒以下，本例专门补上两档。**
本例只讲长条特有的东西——为什么合、时间怎么分、为什么段长不能均匀、长了以后新增哪些风险。首句声明、绑定段、恒定层两层、结束状态五字段、负向分层这些通用编法一律照标杆 A，本例不重复解释。
例子自洽，资产编号与基准段均为虚构；人物与场景沿用拆解标杆《顶针》的当铺戏，便于跟那份对照着看。

## 先看合条判断——这一步决定了后面全部

拆解标杆 breakdown-example 的 s01 把前两个回合放一条、第三个回合另起，理由是**第三回合基调换了象限**：从例行翻到对峙，尾部还要接一记突发动作，属异质。那是正当的拆。

本例是另一种情况，同样三个回合，判断相反：

| 问 | 本例的答 |
|---|---|
| 中间有没有真正的戏剧断点？ | 没有。三个回合是一次连续的施压，压力单调上升，基调始终在"对峙"这一个象限 |
| 时间连不连续？ | 连续，同一场对话不跳时 |
| 拆开要付什么代价？ | 两道缝：各写一次接缝手法、各继承一次结束状态五字段、各重绑一次资产、各编一次提示词；缝本身是漂移与穿帮的高发处 |
| 合起来要付什么代价？ | 回合间节奏必须用时间戳显式分配，不能让模型自己匀；控制密度上升 |

**没有断点却拆开，那是 15 秒天花板留下的习惯，不是判断。** 2.5 下把它合回来是容量红利，主动用——判据在 beat-splitting [合并信号]。

## 全例总注 · 只讲长条特有的四件事

基础编法照标杆 A，这里不重复。长条比短条多出来的，只有下面四件：

- **时间戳按回合分配，不按段数平摊。** 三个回合拿到 5 秒 / 5.5 秒 / 6.5 秒，加起势 2 秒与落幅 3 秒。分配依据是内容不是公平——第三回合是压力顶点，要装下"拿起表、翻看、摊牌、对方无言"四件事加两次停顿，6.5 秒是算出来的不是分出来的。**回合间节奏必须显式写死，不能让模型自己匀**：合条最典型的死法就是模型把三个回合平均掉，前两回合被拉长、顶点被压扁，整条的力气全泄了。
- **段长故意不均匀，均匀就是机械扩写。** 2 / 5 / 5.5 / 6.5 / 3——最短段是最长段的不到三分之一。每段同长度同密度是长条的头号失败模式：看着规整，成片是一条没有轻重的流水账。参照真实素材里的做法——15 秒剧情片把 4.5 秒给了视觉高潮那一段，其余段 1.5 到 2.5 秒。**长不是把每段拉长，是把该长的那段留够。**
- **反应 hold 一秒不能少，这是合条的全部代价。** 三个回合各自的停顿——1.5 秒、2 秒、以及第三回合里那次无言——占了 22 秒里的 5 秒多。合条是容量红利，但红利不是拿来多塞事件的：**富余还给气口，绝不加事件填满**。把三个回合塞进 22 秒却砍掉停顿，等于把"塞太满"的老病搬进更大的箱子，比拆成两条更糟。
- **长条新增两类风险，都要显式锁。** 一是**越轴**：条越长镜头越多，模型自己找机位的机会越多；本例在空间地图里写死"机位全程保持在阿禾左肩一侧、不越过两人连线"，并在针对性负向里升格成带判定尾的硬性句。二是**镜头性格漂移**：22 秒里有切、有反打、有缓推，每一次都是模型换镜头的机会，所以 40° 在四个段里各锚一次、推近那段另补"无长焦压缩"。这两样在 14 秒的条里可以只写一次，长条必须逐段锚。

不适用本例但要知道的：22–30s 的整场长条另需逐拍骨架与镜头N 分镜撑住，控制密度还要再上一档，判据见 duration-pacing [时长分档] 读表纪律。
