[定位]
    宫格是生产手段，不是绑定对象。一张多格底板一次生成，格与格天然共享同一副脸、同一场景、同一光线与调色——这是「一次生成锁一致性」的物理来源；随后对选中格做提示词提取，得到高清单帧，进入关键帧序列即类型 1 的帧池。
    两个用途：主用是批产一致性关键帧，辅用是低成本探索机位构图。
    整板直接投喂视频属次选路径，仅限特定用法，见 [整板投喂 · 次选]。

[宫格生产提示词]
    结构——图像侧规则：正向描述为主，格数与格内容显式声明：
        1. 底板声明：一张图内包含 N 个连续分镜画面，按 X×Y 排列，每格是一个完整镜头画面而非单独的人物或场景元素，全部格共享同一风格、同一人物、同一场景与同一光线。
        2. 通用基准段 + 场域锚句：两层都从 00-bible/visual-style.md 逐字嵌入，锚句取本场景所属场域那一句——宫格底板是带画面内容的整帧场景图，与场景板同源同字。风格不进提示词，批产出来的一致性锁的是错误的调；年代物证不进，格子里长不出这个年代的东西、也对不上它要供帧的那张场景板。取用规则的真相源见 director-grill 的 visual-style-spec.md [基准文本规范 · 两层] 的取用规则。
        3. 人物与场景引用：按资产编号 @char-XXX / @scene-XXX 垫图引用，加一句话职责说明：身份来自角色参考、空间来自场景参考。
        4. 逐格内容：第 K 格：景别 + 机位角度 + 人物位置与姿态 + 该格的画面瞬间。每格只写一个画面瞬间，不写运动过程——格是帧不是条。
        5. 格间一致性声明：所有格中人物为同一人，面孔、发型、服装完全一致；场景为同一空间的不同角度，空间关系彼此成立。
    格数与分辨率权衡：格越密单格越低。批产供帧目的建议 4–6 格；纯探索机位可到 9 格——反正要重新提取，糊一点无妨。底板登记为 ctrl-epNN-sXX-cN-grid-vN，只作谱系留档，本身不进上传清单，次选路径除外。

[提取四层母版]
    核心规则：选中的格必须用提示词重新提取，绝不能用平台切割工具。机械裁切每格分辨率大跌——源图六千像素级，裁切格小而糊；「把第 N 格单独放大高清显示」本质是一次受约束的重新生成/高清重建，产物保持源图级分辨率。
    四层结构：目标选择 + 输出动作 + 不可变条件 + 局部修改。可填空母版：
        把第{{N}}格分镜单独放大高清显示。
        不要改变{{机位/角度/构图/场景/人物身份/服装}}。
        只把{{局部对象}}修改为{{具体细节}}，其余内容保持不变。
        画面中不出现格线、边框、分镜编号或任何相邻格内容。
    - 无局部修改需求时删第三行，保留其余三层。
    - 末行是分格框防渗行：宫格底板上的格线、边框、编号是图形元素，提取时必须显式声明去除，否则以窄边、白线形式残留在帧边缘，随帧渗进视频。
    - 提取物登记 ctrl-epNN-sXX-cN-kfX-vN，谱系行写明：来源底板编号 + 格号 + 修改记录。

[单节点完成替换铁律]
    加人、替换人物、加细节、改光照，必须在提取的同一次生成里一并完成——不能提取一次、再拉一次改人物、再拉一次改光照。每次重生成都会重新解释整张图：人脸继续漂移、材质重采样、构图微调、色彩与锐度代际损失。节点链越长图越糊，这是宫格路径的第一死因。
    若提取后仍需修改：回到底板重新提取并把修改并进四层母版的第三层，版本 bump 为 -v2，不在提取物上叠加编辑。

[整板投喂 · 次选]
    仅一种用法合法：分镜脚本整体生成——把整张宫格当「完整分镜脚本」交给视频模型单次生成整段。官方四步声明结构：
        1. 分镜指代声明：@grid 为完整电影分镜脚本，共包含 N 个连续镜头，每一格代表一个完整镜头，而非单独的人物或场景；不得把分格框渲进画面。
        2. 主体设定：逐一 @资产编号 详述身份职责说明。
        3. 逐镜补齐：每格对应镜头的构图/景别/运镜/动作——宫格只给画面，运动仍靠文字。
        4. 全局风格与禁止项收尾。
    定位声明：此路径与关键帧序列的效果对比属待实测项；实测结论落地前默认走提取 → 关键帧序列主路径，整板投喂仅在用户显式要求或快速草稿场景使用。整板投喂时格线随图进入视频上下文，属已知渗漏风险，第 1 步的「分镜脚本」指代声明与随句的分格框排除句是两道防护，缺一不可——排除句的形态由 motion-compile 的 asset-binding.md [控制图绑定] 定死，本卡为只读副本。

[判据卡 · 该走宫格]
    怎么认：
        同场需要 ≥2 张关键帧且要求同脸同景同调；或机位构图还没想好、想低成本看一批候选再挑。单帧需求且构图明确时不走宫格，单帧直出更便宜。
    认错长什么样：
        - 平台裁切当成品：帧糊、边缘有格线白边——分辨率不足加渗漏双输。裁切只允许用于快速预览挑格，选定后必须提示词提取。
        - 提取后连环小修：提取 → 再改人物 → 再改光照，三代之后脸已经不是那张脸——违反单节点铁律，回底板重提。
        - 底板不带风格基准：批产出一批"一致地错"的帧，全部返工。
        - 把宫格当独立控制类型绑进视频：宫格没有自己的绑定句式，产物必须以单帧身份进关键帧序列；绑定块里出现 grid 编号即是错，次选路径除外。
        - 探索用 9 格底板直接供帧：探索格分辨率本就吃紧，供帧用底板该重新用 4–6 格生产。
    典型例子：
        - 对话戏 3 机位帧：双人位/正打/反打/备选侧位的 4 格底板 → 提取 3 格 → 进条 c2 帧池。
        - 探索定场构图：9 格不同机位 → 挑第 6 格 → 四层母版提取并把"水龙头加淡白水渍"这类局部修改并进同次生成。
