# B 轨动态提示词母版

## 使用说明

- {{}} 内为填空位；〔〕内为按需项，用不到整块删除。
- 一条两块：条头在围栏外、不进生成框——元信息行 + 上传清单表，用户照它传图；围栏内的九段是投喂正文，资产一律写平台地址 @图N。传完图整块复制围栏粘贴即生成，中间零替换。
- @图N 的号 = 条头上传清单的上传顺序号，本母版里的 1/2/3 只是最常见排布的示范，实际按本条清单的行号写；项目编号 char-NNN / scene-NNN / prop-NNN / ctrl-… 只活在条头那一列，围栏里一个都不许出现。号是位置不是身份——同一个角色在别条可能是别的号，每条各自数，绝不从上一条抄号。
- B 轨铁律：除首句声明的总时长外全条不出现任何秒数，镜头按事件顺序排；每镜一个视觉任务。镜头表的逐镜时长走配重语言通道落地——「本条最长的一镜，占全条约三分之一」「一拍即过」「与上一镜等长」；它替代秒数、不是补充秒数，写了配重就不许再补秒数注释。本条最长镜与最短镜必带配重语言，与均分持平的镜不写；配重句落在冒号后动作句的句末、不进运镜骨架。判据详 references/dual-track.md [B 轨 · 镜头N轨写法]。
- 对话戏默认骨架：建立镜即双人定位 → 过肩正反打交替 → 情绪节点近景/特写插入 → 双人全景或中景收束。镜数按镜头表已排定的镜号走，本站不增删镜。
- 台词嵌进所属镜头：引号直写原文 + 语气 + 声线锁逐字引用；倾听者写可见反应、嘴唇静止。
- 恒定层逐字粘贴四处：visual-style 通用基准段、visual-style 里本场场域的场域锚句、reference-index 人物短串、本场镜头表场头的场级空间地图块——场域锚句只取本场场景所属的那一条，外景条一个内景陈设都不许带；空间地图块只搬七行事实行、且先按本条裁一次（裁法见 blocking [空间地图块引用规范]，除删除外一字不改），块标题行与块下【编译期注记】不搬——标题里的 scene-NNN 是项目编号，进围栏即残留。
- 多人场空间地图块必带，在第 3 段，逐字取自本场镜头表场头；且每次切镜后重述谁在哪、看哪。

## 自检

填后自检：条头清单与正文双向对账、@图N 连号、围栏内零项目编号残留——逐项动手核。
- [ ] 每个围栏 = 一条可投喂提示词或一个逐字引用块，元信息与上传清单全在围栏外；每镜头部三件套齐：镜头N + 一句运镜 + 动作；每镜一个视觉任务；最长镜与最短镜各带一句配重语言，且无一处秒数注释来解释它。
- [ ] 台词逐字与镜头表一致、嵌在所属镜头内、不跨镜；声线锁逐字引用；倾听者有反应任务且嘴唇静止。
- [ ] 空间地图按本条裁剪后逐字注入：无非本条人物、无别条镜号，块标题行与编译期注记未随入；机位侧 / 轴线 / 板内可见地标清单 / 可见范围 / 重述规则五处跨本场每一条逐字一致；每次切镜后重述空间；轴线不越。
- [ ] 控制图块的回指已去 @ 换代称；正文全特征代称；多人同框不串脸声明在绑定段末。
- [ ] 恒定层：通用基准段与 visual-style.md 可 diff 为零；场域锚句取的是本场场域那一条，外景条零内景陈设。
- [ ] 每镜运镜句带视场角锚点 + 光学结果语言；同一镜内不换镜头性格，正反打同组两镜档位一致。
- [ ] 结束状态覆盖两名或全部角色；主体 ≤5。
