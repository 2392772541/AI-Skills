# Agent Skills 审核与规范基准

## 1. 结构规范
- 必须包含根目录下的 `SKILL.md`。
- 必须以 YAML Frontmatter `---` 开始和结束。
- 推荐具备 `scripts/`（脚本）、`references/`（参考文档）、`assets/`（输出素材）。

## 2. 字段要求
- `name`：小写字母、数字、单连字符；长度 1~64 字符。
- `description`：字符串，严禁包含尖括号 `<` 或 `>`；长度 25~1024 字符。
- 严禁其他非标准根属性（如内部临时参数），可放入 `metadata` 字典。

## 3. 触发质量五要素
1. **能力界定**：明确说明解决了什么业务或技术痛点。
2. **触发时机**：必须包含明确的条件引导词（如 `Use when...`、`用于当用户...`）。
3. **表达多样性**：覆盖用户真实表达动词与领域名词。
4. **边界收敛**：避免滥用“任何任务”、“全部”等通配词导致误触。
5. **名称解耦**：不得依赖用户显式说出技能名才触发。

## 4. 验证层级
- **Level A**：静态规范与元数据（确定性通过）
- **Level B**：技能识别与加载发现（目录路径探测）
- **Level C**：脚本显式调用验证（语法/依赖/Help）
- **Level D**：自然语言触发能力（评分与启发式评估）
- **Level E**：真实业务任务交付（真实验收，绝不谎报）
