[定位]
    生成前的结构审计。"On an AI film a weak scene costs real money."（在 AI 片里，一场弱戏烧的是真钱。）传统剧本医生改的是纸，这里改的是还没花出去的生成费。
    五元素定义是定制的，不是教科书的。"These definitions are bespoke. Do not substitute textbook craft definitions."（这些是定制定义，禁止用教科书定义替换。）判断拿不准时，回来重读对应元素的判据卡再下判词。
    本站只做审计 AUDIT 与立项。按五元素正向写剧本、逐场共创的 WRITE/CO-WRITE 归 script-write；审计后的改写执行归 script-adapt/script-write。

[因果链总纲]
    审任何一场戏，脊柱是这条链，按序过：
    Goal 目标——固定引擎，每场都是通向它的因果一环
    → Obstacle 障碍——威胁某一阶段或整个目标的强境况；说出什么在冒险、什么尺度
    → Tactic 战术——威胁逼出的、基于不完整信息的合理猜测；结局必须返回信息、改变下一步
    → Reversal 反转——反预期之转；每个 sequence 至少一个
    → Value Shift 价值转变——反转迫使观众改判角色；没有价值转变的反转是死重。

[判据卡 · Goal 目标]
    怎么认：
        主角为「修复既已确立之事」而战的那一件事，全片不变——「既已确立」指此前任何时点铺垫过的：深层背景、几场之前、甚至一分钟前；上一场沾上的臭味，也算这一场要修复的「过去」。"The major goal never changes."（主目标永不变。）主角永远不会搞错目标，只会错在战术。
        每场戏的场目标必须是通向故事目标因果链上的一环。移除测试：把这场戏删掉，因果链还成立吗？成立 → 这场不合格。"No orphan scenes."（不许有孤儿场。）
        "他该做什么"不单独测——正确的一步由障碍加赌注共同决定，世界会让正确的一步变成非选不可。
    认错长什么样：
        把"主角改主意了"判成目标变化——那是战术变化，目标没变。
        用主题当目标，如"他的目标是找到自我"——目标必须是可失败的具体事。
        一场戏"氛围很好"就放行——氛围不豁免移除测试。
        主角采取了赌注撑不起的战术，如楼着火了他在洗澡，却没被标记——这要么是坏写作要么是刻意的自毁行为，必须点名是哪种。
    典型例子：
        推销员马库斯的故事目标：拿下这单挽回公司。某场戏：他浑身臭味被保安拦在门外，先去洗澡。场目标"把自己弄干净"是因果链一环——不洗澡进不了提案室。删掉这场，他直接出现在提案室 → 链断了，场成立。反之若加一场"他在车里回忆童年"，删掉后链照样通 → 孤儿场。

[判据卡 · Obstacle 障碍]
    怎么认：
        一个强境况，威胁路径上的一个阶段或整个目标。"It threatens — it does not merely cost."（它构成威胁，而不只是消耗。）只让主角多花力气而不可能让他失败的，不是障碍。
        两种形态：分支搜索空间——很多文件夹要翻、时间紧、不能被打扰；或单一硬墙——电脑没电，搜不了一台死机。硬墙通常孵化一个新的子目标：找充电器 → 家里没有 → 出门去借。
        必须标尺度：local（威胁当前阶段）还是 global（威胁整个目标）。
        审计口令："name what is at risk, and at what scale."（说出什么在冒险、在什么尺度上。）说不出什么真的可能失败 → 障碍是假的，戏就松了。
    认错长什么样：
        把"麻烦"当障碍：路上堵车但他反正来得及——没有东西被威胁。
        障碍与赌注不匹配没被标记：天大的障碍拦着一件无所谓的事。
        只有情绪没有境况："他很犹豫"不是障碍，除非犹豫背后有个让犹豫合理的强境况。
    典型例子：
        身上的臭味威胁"进提案室"这一阶段（local）；投资人今晚离城则威胁整个目标（global）。审计时两个都要写明尺度——修复优先级不同。

[判据卡 · Tactic 战术]
    怎么认：
        威胁逼出的一步棋，基于主角当下不完整的信息做的合理猜测——引擎的燃料是真相差（truth gap）：他所信的与实情之间的距离。"Search under uncertainty, not error-as-stupidity."（这是不确定下的搜索，不是把犯错写成愚蠢。）
        "错误"的战术不是蠢：翻"家庭照片"文件夹没找到 → 现在他知道不在那——每次失败必须返回信息、收窄搜索、改变下一步。
        零信息失败 = 空转（wheel-spin）：失败了但什么也没学到、下一步和上一步一样——判弱。
    认错长什么样：
        把合理试错判成"主角降智"——只要那一步在他当时的信息下是合理猜测，就不是降智。
        放过空转：连试三次同一类办法、每次失败都不改变认知，审计时只算一次战术加两次注水。
        战术不是被逼出来的：没有威胁他也会这么做 → 这不是战术是日程。
    典型例子：
        找充电器：先翻抽屉——合理，以前放过 → 没有，知道家里没备用 → 改去便利店——信息改变了下一步。对照：翻完抽屉又翻同一个抽屉 → 空转。

[判据卡 · Reversal 反转]
    怎么认：
        反预期之转，三种形态：
        形态 1 我的行动反噬我自己——为了 X 做的事反过来毁了 X。例：为提案去洗澡 → 洗澡让我迟到错过提案。
        形态 2 隐藏能动性揭示——我以为我在作用于它的人或物，其实一直在作用于我，或善或恶。例：我以为在说服买家，买家早就在操纵我的失败，或暗中推我一把。这是惊悚片的招，常在真相差闭合的瞬间引爆。
        形态 3 一般情况——局面转向战术意图的反面。
        位置规则：每个 sequence 至少一个反转。单场戏可以是纯升级；但一个"解决了的 sequence"零反转 → 不合格。
    认错长什么样：
        把"意外事件"当反转：天上掉下来的变故不反任何预期，只是新障碍。反转必须反着此前建立的预期来。
        数错层：sequence 会嵌套，如没电孵出"去买充电器"的小 sequence，每个自我解决的单元都要有自己的反转——只在最外层数一次会漏判。
        形态标错：把"行动反噬"标成"一般反转"会低估修复选项——反噬型的修法是改行动与后果的因果，不是加意外。
    典型例子：
        为了体面提案去洗澡 → 迟到错过提案：形态 1，教科书级的行动反噬。护士例行查房发现病人早已自己拔了管：形态 2，被照护者一直是行动者。

[判据卡 · Value Shift 价值转变]
    怎么认：
        观众对角色评判的变化，由反转触发。发生在观众脑中，不在纸面上。
        核心规则："A reversal with no value shift is inert."（没有价值转变的反转是死重。）情节翻得再响，说不出"判词前 → 判词后"，这个反转就是白翻。
        判词是观众持续修订的动词裁决，一条弧线可以是：老实人 → 有经验 → 老谋深算 → 不，他是走投无路 → 孝子 → 巨婴 → 这才是真男人。
        除了逐个反转验判词，还要审整段轨迹：这些改判连成的是一条设计过的、越挖越深的弧线，还是随机摇摆？
    认错长什么样：
        把情节震惊当价值转变：观众"没想到！"但对角色的看法没动 → 死重。
        判词写成情绪："观众很感动"不是判词。判词是对人的裁决："原来他是怕事的" → "原来他早就决定自己扛"。
        只审存在不审轨迹：场场有改判但方向乱跳——好人坏人好人坏人——摇摆不是深化。
    典型例子：
        便利店老板全片被读作"多一事不如少一事的怕事老头"；结尾他从柜台下拿出早备好的奶粉——观众回放整晚：他早认出了那个"劫匪"。判词前：怕事；判词后：这条街最软的心。反转属形态 2 隐藏能动性揭示，与价值转变咬合，成立。

[sequence 切分法]
    sequence = 某一 jeopardy 从开启到解决的场次段落；jeopardy 即威胁着一个阶段或子目标的障碍。开启：障碍开始威胁；解决：闯过去了，或它击败主角逼出新路径。
    路径的一个阶段 = 一个子目标，由威胁它的障碍定义——两种说法等价。
    sequence 可嵌套：硬墙孵化的子目标自成小 sequence。审计时标注层级：全子目标 sequence 还是其内部的子 sequence。
    整本剧本进来时：先切 sequence——jeopardy 开启 → jeopardy 解决——再逐 sequence 审。不切先审是乱枪。

[审计流程]
    前提：故事目标必须已知。不知道就先问用户——不知道故事目标，Goal 审不了。
    按链序走，对每场执行；Reversal 与 Value Shift 看所在 sequence：
    1. Goal：一行写出场目标。是因果链一环吗？跑移除测试。
    2. Obstacle：写出强境况 + 它威胁什么 + 什么尺度。什么都不真正冒险 → 标"松弛"。
    3. Tactic：列出战术。每个是被威胁逼出的吗？是当时信息下的合理猜测吗？失败返回信息了吗？标出空转与无动机战术。
    4. Reversal：定位 sequence 内的反转，标形态。解决了的 sequence 零反转 → 不合格。
    5. Value Shift：每个反转写"判词前 → 判词后"。写不出 → 标 INERT（死重），列为优先修复。再看整段轨迹：递深还是摇摆。

[输出格式]
    审计结论在对话里呈现，不落独立文件——但对话关窗即散，所以拍板后按母版把两件写进蓝图「剧作审计结论」节：结论表（定位 ｜ WEAKEST POINT ｜ 用户拍板 ｜ 移交），与五元素逐条要点存档——每元素一行，写到下一个窗口凭它就能复核、不必重跑审计；否掉的档位与否掉的理由按全库分层归 decisions.md。对话里的呈现结构固定：

    SCENE/SEQUENCE：{{一行定位}}

    CHAIN CHECK
    - Goal——{{判词 + 一行依据}}
    - Obstacle——{{什么在冒险 + 尺度 + 判词}}
    - Tactic——{{被逼出的？合理猜测？返回信息？判词}}
    - Reversal——{{形态 + sequence 内 ≥1？判词}}
    - Value Shift——{{每个反转的 判词前 → 判词后；或 INERT；轨迹注记}}

    WEAKEST POINT：{{修复收益最大的那一个单点}}

    WHAT IF……
    1. Minimal · 保原稿：{{只动最弱单点，其余全部保留用户原样}}
    2. Clean · 干净版：{{完整可行的重构方向，允许偏离原稿更多}}
    3. Optional · 可选：{{真有增益才给，没有就省略这档}}

[三档 WHAT IF 规则]
    1. Minimal：从用户自己的版本出发，只改最弱的那一个点，让他其余的戏照旧成立。这是默认推荐档——保护用户的所有权。
    2. Clean：完整可行版，哪怕离原稿更远。
    3. Optional：只在真觉得有增益时给，凑数不如不给。
    每档写到拍级具体：谁做什么、反转怎么落、判词怎么变——具体到 script-adapt/script-write 拿去就能改写，但不在本站产出成页剧本。
    用户拍板后按 [输出格式] 存档；改现有场移交 script-adapt，补写新场移交 script-write；改回来后复核该场的链，复核结果追记蓝图同一节。用户选"不修"也是拍板，照样存档——那是他的决策，不是没问题。

[立项模式]
    输入只有梗概时，审不了场，改立骨架。五元素立项清单，连同蓝图交 script-write：
    Goal：主角要的那一件事，一句，可失败、可完成。
    Obstacle：威胁它的强境况，标尺度；至少一面硬墙或一片搜索空间。
    Tactic 方向：主角会用什么路数去试——决定人物的行动质感。
    Reversal 至少一处：预埋在哪、什么形态。
    Value Shift 轨迹粗线：观众对主角的判词，开场是什么、结尾是什么、中间至少改判一次。
    五项有一项立不起来 → 回到拷问，不带病移交。

[猎杀优先级]
    最常见的真实剧作失败，按序猎杀：
    1. 死重反转：翻了情节但没翻观众判词——最常见也最贵，最先杀。
    2. 孤儿场：删掉后因果链仍成立的场——每一场都是一整组生成费。
    3. 空转战术：零信息失败——观众的耐心和用户的预算一起烧。
    4. 假障碍：什么都不真正冒险的"麻烦"——整场松弛。
    5. 摇摆轨迹：改判方向随机——人物散架。
