[定位]
    本卡服务 SKILL.md [风格基准定稿]「定稿视觉风格基准」：把拷问产出的风格草案落成 00-bible/visual-style.md 里可直接进提示词的通用基准段。字段规范与字段表在 director-grill 的 visual-style-spec.md，本卡只管其中「DP 署名锚 + 摄影三件套」这一项怎么挑、怎么落。
    本表是常见锚的快捷方式，不是可选集合：草案已挂署名且在表内，就顺着对应行补三件套；没挂署名就按题材情绪挑一行；锚在表外、或是杂交与带偏移声明的锚，回 SKILL.md [风格基准定稿] 走 [风格锚研究法]，不许硬掰成表里最近的一行。
    定稿只落实方向，不改方向——对草案有实质偏离要进待确认区问用户。

[怎么用本卡]
    定风格锚时，挂一个 DP/导演署名当快捷键，比写"电影感、高级、有质感"有效得多——模型对 "Roger Deakins lighting" 这类专名有精确响应，对 "cinematic" 近乎无响应。多方实战一致结论："电影级/UE5/史诗级/照片级这些词没有任何作用"。
    挂名不是抄袭，是借调性。流程：
    1. 按题材 + 情绪从下表挑 1 个署名，最多叠 2 个、用 × 连接，别堆——叠超过 2 个模型取平均，风格糊掉。
    2. 不要只写名字——把该行的「光位/色板/质感」三件套也落进基准。名字是锚、三件套是保险：模型某些专名认得不全，三件套补齐它认不全的部分。只写署名不写特性 = 没写；同一条教训在胶片牌号上也成立——只加型号一句没有用，必须把调子、特性、颗粒一起描述，整个组成起来才是它的风格。
    3. 把署名连同三件套揉进通用基准段，与色锚质感锚一起写入 00-bible/visual-style.md，色锚质感锚见 film-stock-color-grades.md；色彩语域的配比与强调色纪律见 director-grill 的 visual-style-spec.md [字段规范 · 色彩语域]，全库单源不在此复述。一处定、处处引：设计站每张图提示词开头嵌这段，motion-compile 恒定层逐字嵌这段。

[署名 → 三件套对照表]
    每行给：风格关键词/光位倾向/色板倾向/质感与构图/适配题材。挑一行，把后四列揉进通用基准段。

    Roger Deakins——《1917》《银翼杀手2049》《肖申克》
        关键词：极简光源、自然主义、克制。
        光位：一两个光源就够；精准补光留住暗部细节而不破自然感；大面积单向光、剪影、负空间。
        色板：低饱和、按场景换单色家族编码情绪：冷青 = 控制/疏离、琥珀 = 记忆、深橙 + 压暗黑 = 荒漠。
        质感：球面镜头、干净构图、对称、画面呼吸感强；不炫技。
        适配：写实正剧、科幻史诗、悬疑；要"高级但不花"的首选。

    Emmanuel Lubezki——《荒野猎人》《生命之树》《地心引力》
        关键词：自然光至上、长镜流动、逆光。
        光位：大量自然逆光在主体周围造近乎神性的轮廓辉光；偏好黄金时刻、窗光、火光等真实光源；几乎不打硬影棚光。
        色板：自然、通透、随天光走；冷暖随时间真实漂移。
        质感：广角 + 沉浸式运动、景深大、临场感强，像"在场"而非"在看"。
        适配：自然/生存题材、灵性/史诗、回忆与梦境、一镜到底感的氛围片。

    Janusz Kamiński——《辛德勒的名单》《拯救大兵瑞恩》
        关键词：标志性逆光、漫游镜头、克制用色。
        光位：招牌强逆光从窗/门灌入；高对比、烟雾里的体积光。
        色板：常压成低饱和、沉郁；黑白与去色段落标历史/记忆。
        质感：手持漫游、颗粒、纪实粗粝感。
        适配：战争、历史、沉重正剧、记忆闪回。

    Gordon Willis——《教父》系列
        关键词：低照度、敢于欠曝、顶光。
        光位：大胆压暗、顶光让眼窝陷进阴影；明暗对比强。
        色板：暖琥珀/深褐 sepia 标年代与权力；暗部沉。
        质感：胶片厚重、暗调、庄重。
        适配：黑帮、权力史诗、年代正剧、室内戏。

    David Fincher——与 Jeff Cronenweth/Erik Messerschmidt，《七宗罪》《社交网络》
        关键词：高对比、冷调、深阴影、精密。
        光位：高对比、压低暗端、剪影与大块阴影；光位极度控制、几乎无随机。
        色板：冷绿/青、低饱和、工业；偶尔单点暖色破冷。
        质感：极锐、稳定、构图严丝合缝；数字感的干净。
        适配：犯罪、心理惊悚、冷峻都市、科技/阴谋。

    Bradford Young——《降临》《登月第一人》
        关键词：暗调绘画感、肤色为先、低照度。
        光位：拥抱暗部、低照度，暗部有信息而非死黑；为深肤色保细节是核心关切。
        色板：招牌 minus green——压掉除绿外的饱和；整体沉、情绪化、像油画。
        质感：偏画家而非匠人，情绪从画面里冒出来。
        适配：情绪化正剧、科幻冥想、人物内心戏、多元肤色打光。

    Greig Fraser——《沙丘》《新蝙蝠侠》
        关键词：自然光质感、宽容暗部、史诗 + 亲密并存。
        光位：大量"看起来像现场就有"的光；强方向光配大面积柔环境光；史诗场景也保亲密。
        色板：金色 = 宿命/生存、压暗黑；冷暖按地域/情绪切单色家族。
        质感：略带噪点的胶片质感、宽幅、厚重不脏。
        适配：科幻史诗、沙漠/异星世界、黑暗英雄、年代亲密戏。

    王家卫风 · 与杜可风——《花样年华》《堕落天使》
        关键词：高饱和霓虹、单色主导、动态模糊、迷离。
        光位：霓虹与窗光做主光、明暗对比强；光的"缺席"也在叙事。
        色板：高饱和、一种颜色主导整个画面——红、绿或琥珀；浓得发腻 = 主观的浪漫与怅惘。
        质感：颗粒、抽帧/动态模糊、frame-within-frame 压抑构图，梦一般的怀旧。
        适配：都市情绪、暧昧爱情、霓虹夜、文艺片、MV。

    Wes Anderson 风 · 与 Robert Yeoman——《布达佩斯大饭店》
        关键词：极致对称、正面平视、糖果色、做作的秩序。
        光位：均匀、平、少戏剧阴影；像建筑制图般规整。
        色板：人工调控的糖果/粉彩配色：粉、芥末黄、薄荷绿，高度统一的配色码。
        质感：居中对称构图、平面化、玩具感。
        适配：黑色喜剧、童话寓言、复古、风格化强的轻题材。

[挑名小抄 · 题材/情绪 → 优先候选]
    科幻史诗、宿命感 → Greig Fraser、Roger Deakins。
    写实正剧、高级克制 → Roger Deakins、Janusz Kamiński。
    自然/生存/灵性 → Emmanuel Lubezki。
    黑帮/权力/年代 → Gordon Willis。
    犯罪/心理惊悚/冷峻都市 → David Fincher。
    情绪化人物内心、油画感 → Bradford Young。
    都市暧昧爱情、霓虹夜 → 王家卫/杜可风。
    黑色喜剧/童话/复古 → Wes Anderson。
    短剧/UGC vlog：署名照样可用但要轻——挑一个克制的如 Deakins 或 Lubezki，三件套写松，自然光、低饱和即可，别把手机质感的片写成影展片；媒介质感块归 motion-compile 词库，本卡不管。

[把署名落进基准的写法]
    正例：
        名字 + 三件套——"写实电影感 × Roger Deakins 自然光，单一大面积侧逆光、暗部留细节，低饱和冷青色板按场景编码情绪，球面镜头干净对称构图，景深真实如电影截图。"
    反例：
        只有名字没保险——"Roger Deakins style, cinematic, high quality"，专名可能认不全，cinematic 是废词。
    一句话原则：署名带调性，三件套兜底，题材定选谁。落定后揉进 00-bible/visual-style.md 的通用基准段，全片所有资产与条复用，不在每处重新挑名。
