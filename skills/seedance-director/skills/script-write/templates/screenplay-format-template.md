# 剧本文件母版

## 使用说明

- 01-script/epNN.md 的文件级母版：集信息块 + 场次正文骨架。script-write 从零写作、script-adapt 改造既有文本，产出文件都长这个样子。
- 各槽位的写法标准见 references/screenplay-format.md；script-adapt 产出时在集信息块之后插入改造清单，母版见下节——script-write 从零写作不产此块。
- {{}} 内为填空位；〔〕内为按需项，用不到整块删除，不留空壳。
- 「写作要点」是填写自查，不进产物。

## 集信息块母版

```
# 《{{剧名}}》EP{{NN}} 剧本

- 来源：01-script/source/{{原始文件名}} ｜ 路由：{{三类改造/script-write WRITE/script-write CO-WRITE}}
- story goal：{{主角为之而战的那件唯一的事，一句话}}
- 本集范围：场 {{01}}–{{NN}} ｜ 集尾钩子：{{一句话}}——多集项目填；单集写「单集成片」
- 版本：{{v1}} ｜ {{YYYY-MM-DD}}

〔script-adapt 产出：此处插入改造清单，见下节〕

---
```

## 改造清单母版 · script-adapt 产出时插入，仅两块

处置本体不进清单：可实现性处置以行内【生成注记 → skill】留在正文命中处、带「——卡 NN 处置」尾标，改写直接落文字；回溯对照走 01-script/source/ 原稿；多集切分回写 series-outline 集结构表的「场次范围」列。待决区的「理由」同步补记 00-bible/decisions.md。

| 版本 | 日期 | 变更摘要 | 增量范围与三类扫描结论 | 下游影响提醒 |

## 写作要点

1. 场号 sXX 两位，是下游对账主键，即 02-breakdown、03-shots、05-control-prompts 的 epNN-sXX；单集项目也用 ep01。
2. 场头三要素与歧义禁令：见 references/screenplay-format.md [场头规范]——时段归场头、天气归动作行、时刻归画面内钟表。
3. 【闪回】【梦境】场在场头行首加标记。时间紧接上一场的，场头末尾加「- 紧接」。
4. 动作行与台词的写法标准：references/screenplay-format.md [动作行写法] [台词写法]——不写镜号、景别、运镜、BGM 指令。
5. 【生成注记 → skill】行内标注：取值为 skill 目录名；标注句式、适用场合与下传后的转发去向见 script-adapt 的 feasibility-checklist.md。
6. 版本号规则：内容改动即升版并同步改造清单版本区，走 script-adapt 再入协议；script-write 定稿首版记 v1。
