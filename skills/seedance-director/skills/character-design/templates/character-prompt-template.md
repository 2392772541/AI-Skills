# 角色提示词包母版

## 使用说明

- 每个新增角色复制「角色包母版」逐条填空；状态变体复制「变体条母版」；群演复制「群演条母版」；三件登记按「登记块」的指引走 reference-index 母版。{{}} 内为填空位，槽外文字是定式、原样保留；每个围栏 = 一条可投喂提示词或一个逐字引用块，围栏第一个字就是模型读的第一个字，元信息全在围栏外——条目头与表演档案、生成与验证注记、密版增量、登记块复制时不带进去。
- 填完：角色包与变体条落进 04-assets/characters-prompts.md，追加不覆盖、标清集数；登记块落进 04-assets/reference-index.md 角色段，字段以 script-breakdown 的 reference-index-template.md 母版为准。
- {{通用基准段}}槽 = 逐字复制 00-bible/visual-style.md 的视觉风格通用基准段——媒介质感 / 色域 / 光逻辑 / 镜头性格四件，不改写、不删句。承载具体陈设与时代物证的场域锚句归场景板，永不进角色板：角色板是中灰底空场，板上除人物外空无一物，写进一间屋子就把那间屋子烤成了角色的一部分。年代形制走服装维——从 visual-style「时代与世界锚」取年份/地理与服装形制，只写穿在身上的东西；质感取词、配色语域另按 SKILL.md [依赖检测] 列的字段从同一份 visual-style 取，不自拟。
- 密度对照标杆：examples/character-example.md。

## 角色包母版

### 条目头：char-{{NNN}} · {{角色名}}（{{核心/边角}}，首登场 ep{{NN}} 场{{XX}}）

#### G1 大特写 · 不笑（校验锚）——生成条

```
{{通用基准段，逐字}}角色定妆特写照，三四分之三视角头肩构图，纯中灰色无缝背景，画面中除人物外空无一物，柔和均匀的定向光从一侧打来，影调过渡自然。这是{{年龄/种族/身份定位}}，{{肤色与皮肤质感；写实项目末尾逐字挂「保留真实的微细毛孔与肌肤纹理」}}。{{面部细节：眼型/眉骨/鼻梁/唇形/下颌线取 3–4 点}}。{{眼神：形容词 + 比喻 + 底层情绪}}。{{发型发色与贴合细节}}。表情平静不带笑意，嘴唇自然闭合，双眼看向镜头方向。
```

#### G2 大特写 · 笑版——编辑条（基于 G1 成图）

```
编辑这张图：让人物露出{{笑的性质：如克制的/敞开的}}笑容。
改动：仅嘴部与眼周——{{嘴角如何、露不露齿、眼角眼周如何}}。
严格保留：五官、脸型、肤质、发型、光线、背景、构图、调色与颗粒，全部与原图一致。
只改笑容，其余 100% 不变。
```

#### G3 三格角色表——生成条（以 G1 成图为参考图，表中特写格 = G1 的脸）

```
{{通用基准段，逐字}}角色定妆设定图，纯中灰色无缝背景，画面中除人物外空无一物，柔和均匀的定向光从一侧打来。画面水平排列同一个人的三个视图：左格是三四分之三视角的头肩大特写、表情平静不带笑意；中格是正面全身、画面从领口以下取景、不含头部；右格是完整的背面全身、含后脑发型。三格必须是同一个人，发型发色、服装、体型完全一致，脸与所给参考特写是同一张脸。人物自然站立，双臂垂放身体两侧，双手空着。{{体型身形与体格成因}}。{{服装：版型 + 颜色 + 衣物名词 + 材质/新旧 + 穿着细节，年代形制照 visual-style「时代与世界锚」的年份/地理与服装形制写死——领型、扣式、面料工艺，只写穿在身上的形制，不搬场域陈设}}。{{鞋}}。{{穿戴类固定特征，若有：全片戴着不摘的眼镜/戒指/顶针/腕表/耳饰/佩章等，逐件写形制 + 戴在身上哪一处；同时入库为道具的双源件，形态照 reference-index 道具段写、不自拟}}。{{气质一句收尾}}。特写格突出{{面部与发型细节}}，中格看清{{剪裁与垂坠}}，右格看清{{背部剪裁与发型背面}}。
```

#### 声线锁——非生成提示词 · 供动态提示词逐字引用

有台词角色才写，沉默角色此段写「无」。

```
「{{年龄}}的{{性别/身份}}，{{地域/口音——类别 + 一两个音位标记}}。{{音区与音色}}；{{语速与说话方式}}；{{情绪底色——压力下向哪个方向变化}}。」
```

#### 表演档案

核心角色由 performance 的 master-profile-template.md 的表演档案母版产出后贴此，150–220 词一段式；边角角色可省。

    {{Character acting as …… 整段}}

#### 生成与验证注记

    顺序 G1 → G2 → G3{{ → G4+}}。G1 先生成并与密版逐维对照——脸型/五官 3–4 点/肤质/发型，锚不对改词重出、不往下；G1 成图此后不再整体过模型。批量生成期的稳定性验证按 06-motion-prompts/ep{{NN}}-motion-prompts.md 头部「生成顺序与校准」小节执行。

```

## 群演条母版

### 条目头：char-{{NNN}} · {{群演名，如 码头晨市人群}}（边角，群演，首登场 ep{{NN}} 场{{XX}}）——{{生成条/纯文字登记}}（二选一：跨条复用出图走生成条、填下面的围栏；一次性路人不出图，只留条目头与登记）

```
{{通用基准段，逐字}}群体质感参考图，三四分之三视角中景，{{该场景光或中灰底软光}}。画面是{{身体的质量与局部：挤在/散在{{何处——只给人群所踩所倚的一层承托面，如石阶、摊位边，不铺场域陈设}}的身体、前景交叠的{{手臂/肩背}}、后景无清晰面孔的人影}}，所有人物面孔模糊不可辨。{{服装的年代形制范围，取自 visual-style「时代与世界锚」的年份/地理与服装形制，正向穷举}}。{{氛围一句收尾}}。

## 登记块

无内联母版，防字段分叉。登记条目的骨架与字段以全库唯一母版 script-breakdown 的 reference-index-template.md 的「角色」段为准：照其条目骨架逐字段填空，落进 04-assets/reference-index.md 角色段。本卡不复制字段清单——两处清单必漂移。填好的标杆见 examples/character-example.md 登记块。
