# 人物提取与稳定设计

## 提取顺序

1. 通读指定原文，收集直接外貌描写、他人观察、换装动作、身体特征和行为线索，附段号。不要扩展到未提供章节。
2. 合并别名、同一人物的不同称呼；不能因换衣或受伤建成另一个人。确实不同年龄阶段或替身时，建立关联版本并解释。
3. 用六要素写一段话：年龄、性别、肤色、发型发色、五官、服装。未知项标未知；只在必要时最小推导。一般抓 1–3 个最强面部辨识点，补充有意义的体型、步态和习惯动作；不硬塞全部细节。
4. 为每项新增特征附来源类别：原文明确、合理推导、设计建议。用户确认的设计建议可转为已采纳设计，但不能回标“原文明确”。
5. 检查角色区分：轮廓、年龄感、发型、服装轮廓和习惯动作是否易分辨。允许相似人物，但需要叙事依据或说明识别困难。

## 四层隔离

- 固定身份：脸型、五官、肤色基线、体型、稳定标记。原文没写疤痕，不能擅加疤痕当永久锚点。
- 装束版本：衣服、鞋、贴身装饰，记录出现范围。剧情中会转交或脱离身体的关键饰品另建道具。
- 临时状态：湿污、血迹、伤势、呼吸、疲惫；记录发生、持续和解除位置。
- 表演倾向：在什么刺激下产生什么动作；不要写“永远愤怒”“全程悲伤”。某镜的动作与情绪归该镜。

## 证据冲突

原文前后冲突时保留两处原文与位置，判断是否为年龄、换装、视角差异；不能自行用后文覆盖前文。不能确定且影响身份时询问；不影响当前输出时标待定并继续其他工作。

## 文本与图像交接

角色档案登记完整描述，另蒸馏一句身份短串。固定 ID 跨场沿用，变体使用父 ID 关联。角色卡不重复展开道具和场景，只引用其 ID。

默认先出干净背景、自然中性状态的清晰身份参考提示词。只按实际镜头需要补充视角和装束，不强制每人生成笑版与三格板。人物板不是分镜图；中性资产光照不应变成所有场景的固定布光。

三格同图、保真后缀、蒙版局部修改均只是候选手段。相同参考可帮助降低漂移，但不保证同脸、不保证未编辑区像素不变。图像审核检查具体识别点、服装和版本后再登记通过。

## 人·物·场与表演

从小墨提取方法保留六要素、直接白描、证据区分、服化道背景一致性及索引；以 Seedance 管理编号、参考图、简短身份描述、声线、变体和分镜引用。场景总览的微俯视仅用于空间设计说明，不能自动指定实际影片的每个机位。

台词角色可登记声线；无配音或沉默角色明确标无，不创建多余声音档案。气质描述只给表演方向，具体动作交给 Seedance 的 performance（表演）手册并受本镜叙事任务约束。
