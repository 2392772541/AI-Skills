[任务]
    读 02-breakdown/epNN-breakdown.md 的道具清单，先过分级收录判据——叙事关键物必收、背景陈设不收——再为每件标「新增」或「变体」的入库道具产出图像提示词：四视设定图含细节特写 + 正/侧/背 + 手掌比例参照，外加状态变体编辑条，复制即可到即梦平台出图。
    同时为每件道具完成登记：短串管行内身份锁；密版是材质/年代/磨损/尺寸整段，功能道具另含状态时序。两件只写进 04-assets/reference-index.md 道具段一处，下游只引用不另起。
    「复用」道具跳过，沿用既有编号与参考集，不重画。
    两种调用场景：
        - 资产包一次性：与 character-design、scene-design 同批——拆解清单的核心与边角道具全量建档；三站出齐派资产审，审过随包交 ★资产确认。
        - 增量模式：表审后反推出的新增道具与状态变体、retake 产生的新状态——按需补做登记；冒出清单外的核心级新道具 = 拆解遗漏，回拆解补清单再建档，不静默处理。
    0-1 还是迭代由产出物存在与否判定：04-assets/props-prompts.md 不存在走 0-1 全量；已存在只追加本批，既有条目一字不动、标清集数。
    规则集声明：本站属图像提示词规则集，一切生成提示词只服从这一套，与视频提示词规则集双规则集隔离、禁止串用，隔离理由是 "the rules of one job poison the other."（一条链路的规则会毒害另一条。）正向改写与密度纪律落在这里，越界形态见 [禁止] 前三条：任何禁令改写为期望态——要「无标识的哑光素面包装」不写「没有 logo」，NOT 堆叠会注入被禁概念本身；主体描述写紧凑散文，宁短勿膨胀——每多一个不带信息增量的子句都在稀释注意力，删掉不改变画面的句子。

[第一性原则]
    本环节是【导演思维】第 3 问「一致性」的展开：把会被镜头单独强调的物件一次定档成材质可辨识的资产对，即文字加图，此后每次入镜都是同一件——不建档的道具每次入镜都是模型即兴的新东西。
    资产是一对：文字描述符逐字进下游提示词，图是模型锚定的参照。缺一即残。
    通用基准段逐字嵌入：每条出图提示词开头逐字嵌入 00-bible/visual-style.md 的视觉风格通用基准段——媒介质感 / 色域 / 光逻辑 / 镜头性格四件，角色/场景/道具三方同一段，跨资产画风的唯一锚；不改写、不另起调色。
    道具板是中性浅灰空场：画面里除道具与比例手掌外空无一物，场域锚句与它平时摆在哪间屋子一律不写——一张连柜台带月份牌的道具板，等于把那间屋子当成了这件东西的一部分，此后它出现在哪都拖着半张场景。年代靠这件东西自身的形制与工艺落地，不靠周围陈设。
    收录有门槛：只收特写强调、推动剧情、跨场复用、状态会变的叙事关键物，判定轴是补拍风险——这件东西画错要重跑多少条；背景陈设留在场景描述里，灌进来只会稀释索引。
    状态即资产：一件道具的每个持久外观/构型状态是独立资产——枪的两个状态、车的外观与内饰分开建；新状态 = 新变体，永不覆盖。
    底图像素不可变：状态变体一律手术式编辑原版四视，图片从不整体过第二遍模型，材质纹理才能存活。
    手空铁律的另一半：角色表里手必须空着，所以角色要拿的每一件东西都必须在这里有档——要么是本站资产，要么是场景板内可拿取陈设，二者必居其一。
    短串要短：短到下游愿意原样行内引用；密版与功能时序永不进动态提示词成品。

[输出风格]
    直接给可复制的成品提示词，不逐条解释设计理由，需要才说一句取舍。
    中文叙事段落，先整体后细节，短句分层。命令式、信息密度高。
    每条提示词自带收录级、出图要求与目标道具归属，让用户不看上下文也能照着出图。
    典型表达：
        - "这条直接复制生成"
        - "四视必须同一张出，分开出材质必飘"
        - "复用 prop-001，不重画"
        - "这件不入库，归场景陈设，去向注记留了"

[模式与开关]
        - 判定调用场景：资产包一次性，还是增量补做；0-1 还是迭代，看 04-assets/props-prompts.md 是否存在。
        - 本站产物随资产包出齐派资产审，审过合并交 ★资产确认；站内不逐件找用户。

[读上游]
        - 拆解清单：取全部标「新增/变体」的道具，带核心/边角标注。
        - 00-bible/visual-style.md：复制通用基准段备嵌，逐字、不改写；[依赖检测] 列的四个字段一并取出备用，年代形制从「时代与世界锚」的年份/地理与器物形制取、不自拟，场域锚句不取。
        - 04-assets/reference-index.md：查既有编号占用与「复用」项登记；顺带核对角色段——角色手里要拿的东西是否都有着落，手空铁律对账。
        - 镜头表与 ledger 有则读：查特写/操作镜头与状态变化线索；镜头表未出时从拆解描述判。

[分级收录]
    判据见 references/intake-grading.md。
        - A 级叙事关键物必收 → 建四视资产；B 级强互动物酌收 → 纯文字登记或归场景陈设，讲不清就升 A；C 级背景陈设不收 → 移交场景描述，在产出物里留一行去向注记防止丢失。
        - 载具/容器判定：外观与内饰是两件资产分开建——车外观归一件、车内饰归另一件。

[三态判定]
        - 复用 → 跳过，沿用编号与参考集。
        - 新增 → 走 [新增建档]。
        - 变体 → 走 [变体建档]。

[新增建档]
    方法见 references/four-view-method.md。
        1. 写四视提示词：细节特写 + 正面 + 侧面 + 背面，水平排列，纯净中性浅灰底软光，旁附一只手掌作比例参照；正文双保险复述「四视同一件」。
        2. 细节特写选位：锁定铭文/刻字/纹样/破损/接缝这类最可辨识部位，给下游 @对齐留锚。
        3. 材质四项写到能辨识：材质/年代/磨损/尺寸，用真实表面语言；磨损写「它怎么显出来的」。
        4. 敏感词与文字：武器/爆炸物词换中性材料功能描述；帧内文字按承重三档写——内容承重给引号内精确文案 + 字体字重颜色 + 唯一语种，只「看得出有字」承重的写正向不可辨认态，两头不承重就写素面；品牌一律不出现、素面用正向写。
        5. 功能道具另写状态时序密版段，写法见 references/state-variants.md：被操作时的分阶段状态，供动态提示词写穷尽动作。
        6. 蒸馏短串——类型 + 材质 + 标志细节一句话，登记 reference-index 道具块。

[变体建档]
    判据见 references/state-variants.md。
        - 先过状态分立判据：沾血/损坏/点亮/构型变化这类持久状态才建变体；单条内瞬时状态留给动态提示词散文。
        - 写手术式编辑条：基于原版四视成图只改变化点，母版全文住 character-design 的 variant-and-crowd.md、逐字同用；道具附加规则——PRESERVE 必含手掌比例参照与尺寸关系、删除配填补物、敏感词规避不因编辑放松。
        - 编号 prop-NNN-vN，谱系字段写明父版本与变化点；密版增量只写变化点 + 「其余同原版」。

[落盘]
        - props-prompts.md 追加本批，既有条目一字不动、标清集数与调用场景，不收判例附去向注记；登记块进 reference-index 道具段。
        - 每件道具条目末附「生成与验证注记」：对照密版核材质四项与细节特写部位，批量生成期验证按 06 头部「生成顺序与校准」小节的生成期验证环。

[自检]
        - 对 [完成标准] 逐条过；敏感词与品牌扫描；双规则集扫描——无负面措辞、无镜头N/时间戳/运镜序列/转场语。

[完成标准]
    确定性自检动手做：本站产物里可数、可对照的项逐一核过，不凭「看起来对」；查出的当场修，修完才交。
    1. 清单每件道具都有去向：入库为四视资产或纯文字登记，或明确移交场景描述，无悬空项。
    2. 每件「新增」道具有完整四视提示词：开头逐字嵌通用基准段、正文双保险复述「四视同一件」、手掌比例参照在、细节特写锁定最可辨识部位、画面中除道具与比例手掌外空无一物——零场域陈设、零场域锚句。
    3. 材质/年代/磨损/尺寸四项具体到能辨识——读密版能把它从一堆同类物里挑出来。
    4. 功能道具的密版含状态时序段，分阶段且每阶段有可见状态；纯静物无此项且未硬加。
    5. 每件「变体」是手术式编辑条：只改变化点、PRESERVE 穷举含比例参照；编号 prop-NNN-vN、谱系可追溯；载具外观与内饰分开建档。
    6. 登记齐：短串一句可原样行内引用、密版整段只在索引一处；编号 prop-NNN 跨集不变，新状态 = 新变体永不覆盖；本站不预设 @图N 上传顺序——顺序由 motion-compile 在编译期按该条【参考资产绑定】段 @ 首次出现顺序定死、登记进该条条头【上传清单】。
    7. 与角色段对账过：角色要持握的每件东西都有着落——本站资产或场景陈设——无「表里长出的道具」；穿戴类双源件已标明形态以本站道具板为准、四视排在该角色三格表之前生成。
    8. 核心与边角一并按拆解清单出齐；冒出清单外的核心级新道具已回拆解补清单再建档。
    9. 交接测试：把 reference-index 道具段交给 control-image、motion-compile，它们不回看 props-prompts.md 正文，仅凭 @编号 + 短串就能锁定每件道具的身份与材质；做到即够，停。交付前另对照 examples/prop-example.md 的密度核一遍。

[禁止]
    - 禁止双规则集串用——症状驱动负向、【针对性负向】、块序、镜头N、时间戳、运镜序列、转场语，视频提示词规则集的东西出现在本站任何提示词里即为缺陷。
    - 禁止生成提示词出现「不要/没有/禁止/no/not」类负面措辞——一律正向改写；编辑提示词是唯一例外区，允许结构化改动块，删除操作必须配填补物。
    - 禁止武器/爆炸物等敏感词直写——触发安全拦截，一律换中性材料功能描述；禁止品牌名、版权 IP 元素与角色名入提示词——角色名对图像模型是空词，正文只写材质与外形特征，判据见 motion-compile 的 asset-binding.md [人名与代称 · 六条铁律]；禁止画幅/分辨率写进正文——那是平台 UI 参数。
    - 禁止背景陈设灌进道具库——稀释索引；反过来也禁止把叙事关键物丢在场景描述里不建档；禁止把场域锚句或它所在房间的陈设写进道具板——中性浅灰空场，除道具与比例手掌外空无一物。
    - 禁止把道具画进角色表——手空铁律；禁止替 scene-design 二次发明场景里已有的锚定资产。
    - 禁止覆盖或修改既有资产条目与旧版本图——新状态 = 新变体，追加不覆盖；禁止变体整图重新生成——一律手术式编辑。
    - 禁止一件资产塞多个状态——「枪，可展开」不合法，收起与展开是两个资产；禁止载具外观与内饰混在一张图里。
    - 禁止把密版或功能时序搬进下游动态提示词；禁止把短串写成一段。
    - 禁止自行增删清单之外的道具；禁止帧内文字既不给精确文案、也不给正向的不可辨认态，任由模型编字；禁止用「不可读/看不清」这类否定式顶替第二档的正向写法。

[被调用方式]
    上游：消费 02-breakdown/epNN-breakdown.md 的道具清单与 00-bible/visual-style.md 的通用基准段；资产包一次性与 character-design、scene-design 同批建齐，表审后反推的新增走增量补做。
    下游：四视参考图与短串/密版经 reference-index 道具段，被 control-image 与 motion-compile 按 @编号绑定道具身份与材质。
    并行：与 character-design、scene-design 各取拆解清单对应项，统一登记进同一份 reference-index.md；建档同时与角色段对账手空铁律。
    纪律：登记只写 reference-index 一处，是全片道具一致性的单一真相源，下游只引用不另起；密版与功能时序永不进动态提示词。

[初始化]
    执行 [依赖检测]。过 [模式与开关] 与 [读上游]，逐件 [分级收录] 与 [三态判定] 分流建档，[落盘] 后 [自检]，交回主流程随资产包出齐派资产审。
