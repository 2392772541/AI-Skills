# 标杆改造 · 《末班车》小说片段（三类改造全流程 + 一次版本增量重扫）

## 示例定位

本例演示一段章节体小说文字从进站到落盘的完整改造，再演示落盘后改版怎么回站重扫：输入判定 → 结构改造 → 可视化改造 → 可实现性改造 → 终检 → 改造清单 → 版本增量重扫。示例自洽，不指向真实项目。每段之后的「为什么这么编」解释这一步为什么这么编。

## 原始输入 · 存 01-script/source/末班车-第三章节选.md

```
深夜十一点半，末班地铁进站。站台上人不多。周野挤在下班的人潮里，心里乱成一团：白天医生的话翻来覆去地响——手术费还差八万。他想起父亲年轻时背着他蹚过洪水的样子，鼻子一酸。手机震了一下，是催款短信："尊敬的用户，您的借款已逾期 3 天，请尽快处理。"他愤怒极了，狠狠攥住手机。这时他注意到站台尽头有个穿灰夹克的男人，似乎一直在看他。两人对视一眼，男人立刻别开脸。周野感到一阵莫名的恐惧。列车进站，人群像潮水一样涌上车。
```

## 段 1 · 输入判定

```
- 章节体、无场头、含大量叙述与心理描写 → 小说与长文本 → 走结构改造。
- 原文原样存 01-script/source/，改造只动副本。
```

为什么这么编：

"深夜十一点半，末班地铁进站"有场景有动作，容易被误判成"差不多能拍"。判定看的是形状——有无场头、台词、场次结构——不是文笔。这段一句台词都没有、心理描写占一半，是典型小说体。

## 段 2 · 结构改造

```
- 切场：全段在同一时空——地铁站台，深夜——连续发生 → 一场。
- 场头：场04 内景 地铁站台 - 夜。
- "深夜十一点半"不进场头——时段词只用五个：精确时刻画面化——写进动作行首句的站台屏幕。
- 逻辑矛盾登记："站台上人不多"与"挤在下班的人潮里""人群像潮水一样涌上车"互相打架，末班车设定统一为人少，同时也规避大规模群体雷区，矛盾修复记入改造清单。
```

为什么这么编：

时间歧义与前后矛盾这类小 bug 必须在正式制作前消除——留到拆解阶段，下游各站会各自猜一个版本：scene-design 按空站台出图、motion-compile 按人潮写提示词，直接崩一致性。

## 段 3 · 可视化改造 · 逐句手术

```
逐句手术记录：

| 原句 | 问题 | 改写 | 转写路径 |
|---|---|---|---|
| 心里乱成一团；医生的话翻来覆去地响 | 不可拍的心理 | 他盯着到站屏上跳动的「末班车」三个字出神，指尖无意识地敲着大腿 | 心理外化为动作 |
| 想起父亲背着他蹚洪水，鼻子一酸 | 不可拍的回忆 | 他从手机壳里抽出一张压得起毛边的旧照片，拇指压过照片上父亲的肩膀，呼吸慢了半拍 | 心理外化为对物件的动作；闪回方案挂待决 |
| 他愤怒极了，狠狠攥住手机 | 前半句是结论 | 他攥紧手机，指节压白，把手机脸朝下扣在大腿上 | 情绪写成序列，删结论 |
| 感到一阵莫名的恐惧 | 不可拍的感受 | 他收回视线，攥着照片的手插回外套口袋，往灯柱的阴影里退了半步 | 情绪写成动作 |
| 似乎一直在看他 | 「似乎」不可拍 | 灰夹克男人的视线越过报刊亭落在他身上；对视一眼，男人立刻低头看手机 | 视线写实 |
```

为什么这么编：

"想起父亲蹚洪水"有两条出路：外化——成本低，一张旧照片解决，还顺手给 prop-design 埋了一个可复用道具；或新增【闪回】场——多一场戏 = 多一套场景与人物资产。创作取舍不擅自定——默认给低成本外化，闪回作替代方案挂待决区，适配确认 让用户选。

## 段 4 · 可实现性改造 · 雷区扫描

```
- 命中卡 04 · 画面内承重文字：催款短信全文可读 → 等效改写：屏幕亮起 + 顶部弹出通知条，字迹在反光里挤成一团、难以逐字分辨；逾期信息改由画面语言承担——他扣下手机的动作 + 后续剧情交代。备选：如剧情必须读到文字，标注 prop-design 出短信屏幕特写设定图。
- 命中卡 01 · 大规模群体："人潮""人群像潮水" → 已随结构改造统一为末班车空站台：前景乘客两三人，稀稀拉拉上车。
- 卡 11 · 同框人数，顺手加固：灰夹克男人的「唯一性」是悬疑点 → 剧本写死站台可见人数，加行内标注。
```

为什么这么编：

短信这类「屏幕文字」是最常见的漏放项——小说里它是叙事工具，画面里它是承重文字——观众要是读不对那行字，逾期这件事就没交代。处置顺位先试等效改写——多数情况下观众不需要逐字读到短信，只需要知道"是催债的"——台词化或道具图控制留给真正承重的文字。

## 段 5 · 改造成品 · 写入 01-script/ep01.md 正文

```
## 场04 内景 地铁站台 - 夜

空旷的站台。到站屏显示 23:31，「末班车」三个字在滚动。零星两三个乘客散在候车线后。

周野（32 岁，洗旧的深色工装外套，眼下有熬夜的青黑）站在灯柱边，盯着到站屏出神，指尖无意识地敲着大腿。

他从手机壳里抽出一张压得起毛边的旧照片——年轻的父亲背着个孩子，裤腿卷到膝盖。拇指压过照片上父亲的肩膀，他的呼吸慢了半拍。

手机震动。屏幕亮起，顶部弹出一条银行通知，字迹在反光里模糊不清。

他攥紧手机，指节压白，把手机脸朝下扣在大腿上。

站台尽头，一个穿灰夹克的男人（40 岁上下，帽檐压得低）的视线越过报刊亭，落在他身上。

两人对视一眼。男人立刻低头看手机。

周野收回视线，攥着照片的手插回外套口袋，往灯柱的阴影里退了半步。

列车进站，气流掀起站台上的一页旧报纸。稀稀拉拉的乘客陆续上车。

【生成注记 → motion-compile】站台可见人数写死：周野、灰夹克男人、背景乘客两至三人；全局禁止项尾缀「无额外人物」——卡 11 处置。
【生成注记 → prop-design】旧照片为剧情承重道具，后续场次复用，需建设定图；画面中照片内容以构图与人物剪影可辨为度，不要求可读细节。
```

## 段 6 · 改造清单 · epNN.md 头部摘录

处置本体不进清单：卡 04 与卡 01 的等效改写已落在段 5 正文里，卡 11 的标注放行就是段 5 那条带尾标的行内注记——清单只剩要用户裁决的和要记版本的。

```
### 待决区

| # | 位置 | 建议 | 理由 | 替代方案 |
|---|---|---|---|---|
| 1 | s04 | 父亲回忆用照片外化，即当前版本 | 闪回需新增场景与人物资产，成本高 | 新增【闪回】场：父亲背子蹚洪水；若该意象是全片母题则值得建资产 |

```

## 段 7 · 版本增量重扫 · 适配确认 裁定后回写

适配确认 用户选了待决区那条替代方案：加【闪回】场。改动落进正文即一次版本增量，回本站走 SKILL.md [再入协议]。

```
圈增量：本次改动只有一处——s04「拇指压过照片上父亲的肩膀」之后新增闪回一段，无删除、无其他改写；扫描范围就是这一段。

三类重扫，逐类跑：
- 结构：闪回是独立场 → 切出 场05【闪回】 外景 河堤 - 日，场头三要素补齐；原 s05 起场号整体后移一位，落正文与场头。
- 可视化：增量三句逐句问「画面里具体看见什么」——「父亲年轻时的样子」答不出 → 改写为「年轻的父亲把裤腿卷到膝盖，把孩子往背上颠了一下」；另两句通过。
- 可实现性：增量对雷区表逐卡过一遍——命中卡 09 特殊物理与材质失控（人蹚浑水、水与人持续交互）→ 降档：水位压到小腿肚、本段只留这一个物理事件，标注【生成注记 → motion-compile】液体段需物理锁——卡 09 处置；卡 01 排除——闪回只有父子两人。

范围外扩：本次改动增删了场次、动了场号顺序 → 回查 s04 落幅与原 s05 开场的衔接，出画方向与入画逻辑仍可接。

版本区新增一行：
| v1.1 | {{日期}} | 适配确认 裁定：加【闪回】场，场号后移 | 增量 = s04 后新增闪回一段；结构 → 切出场05、场号重排；可视化 → 改写 1 句；可实现性 → 命中卡 09 降档、行内注记留痕 | 下游全链尚未建立，经查无下游影响；下一站 script-breakdown 直接读 v1.1 |
```

为什么这么编：

改剧本是主流程常规动作，不是意外——剧作审计加戏、★适配确认裁决、下游发现剧本事实有误，都会回头动剧本。而后加的段落最危险：它长得像剧本、读起来顺，却一次三类改造都没过过。这段闪回不重扫，「父亲年轻时的样子」会带着不可拍的叙述一路传进镜头表，蹚水那段的物理锁也不会有人写。扫的是增量不是全本——成本只有一段的量，漏掉的代价是全链。

## 全例总注

- 原始输入永不改动，所有手术都在副本上做——某句改坏了，随时能对照 source 找回原意，这就是可回溯资产链。
- 每一处心理描写都外化而不是删除：删除让人物变空壳，外化让拆解阶段拿到「物理指令」的原料、表演阶段拿到潜台词的载体。
- 三处雷区两处走等效改写、一处标注放行、零处删——处置顺位在前的优先；真正要删剧情时才动用待决区。
- 行内标注【生成注记 → skill】直接写进剧本正文，随 epNN.md 传下去，由剧本拆解按去向转进拆解件——下游不需要回头翻改造清单才知道这里有雷。
- 旧照片是改造过程「顺手生出的资产」：一次外化决策同时服务了可视化的心理落物、道具层的可复用设定与后续剧情的父子线信物。好的改造会让下游更富，而不只是更安全。
