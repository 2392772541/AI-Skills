# 道具提示词母版

## 使用说明

- 每件新增入库道具复制「四视条母版」填空；状态变体复制「变体条母版」；功能道具在密版加「状态时序段母版」；不收项复制「去向注记母版」；登记按「登记块」的指引走 reference-index 母版。{{}} 内为填空位，槽外文字是定式、原样保留；每个围栏 = 一条可投喂提示词或一个逐字引用块，围栏第一个字就是模型读的第一个字，元信息全在围栏外——条目头与状态时序段、生成与验证注记、密版增量、去向注记、登记块复制时不带进去。
- 填完：四视条与变体条落进 04-assets/props-prompts.md，追加不覆盖、标清集数；登记块落进 04-assets/reference-index.md 道具段，字段以 script-breakdown 的 reference-index-template.md 母版为准。
- {{通用基准段}}槽 = 逐字复制 00-bible/visual-style.md 的视觉风格通用基准段——媒介质感 / 色域 / 光逻辑 / 镜头性格四件，不改写、不删句。承载具体陈设与时代物证的场域锚句归场景板，永不进道具板：道具板是中性浅灰空场，画面里除道具与比例手掌外空无一物，写进一间屋子等于给这件东西配了个永久底座。年代形制写这件东西自身的形制与工艺；材质取词、配色语域另按 SKILL.md [依赖检测] 列的字段从同一份 visual-style 取，不自拟。
- 密度对照标杆：examples/prop-example.md。

## 四视条母版

### 条目头：prop-{{NNN}} · {{道具名}}（{{核心/边角}}，收录级{{A/B}}，首登场 ep{{NN}} 场{{XX}}）——生成条

```
{{通用基准段，逐字}}道具定妆设定图，纯净中性浅灰无缝背景，画面中除道具与比例手掌外空无一物，柔和均匀软光，画面水平排列同一件道具的四个视图：细节特写、正面、侧面、背面，旁附一只摊开的手掌作比例参照、不接触道具。四视必须是同一件，材质、配色、磨损、尺寸比例完全一致。道具是{{类型与整体造型一句定物}}。{{材质与工艺：具名到工艺}}。{{颜色与纹样}}。{{年代与磨损：年代形制照 visual-style「时代与世界锚」的年份/地理与器物形制写，只写这件东西自身的形制与工艺、不搬场域陈设，磨损用真实表面语言写「怎么显出来的」；崭新道具写崭新的真实证据}}。{{尺寸：真实数值 + 与手掌的比较关系}}。{{关键可辨识细节：铭文/刻痕/破损/接缝；帧内文字先判承重档再写——内容承重给引号内精确文案 + 字体字重颜色 + 唯一语种；只「看得出这里有字」承重的写正向不可辨认态，如「一行阴刻小字，笔画彼此挤压、刻痕被磨钝」；两头都不承重就写素面本色、不写字}}。细节特写格放大{{最可辨识且恒定的部位}}，让下游引用时对得准。
```

生成与验证注记：

    对照密版核材质四项——材质/年代/磨损/尺寸——与特写部位；批量生成期验证按 06-motion-prompts/ep{{NN}}-motion-prompts.md 头部「生成顺序与校准」小节执行。

## 登记块

无内联母版，防字段分叉。登记条目的骨架与字段以全库唯一母版 script-breakdown 的 reference-index-template.md 的「道具」段为准：照其条目骨架逐字段填空，落进 04-assets/reference-index.md 道具段。B 级纯文字资产同样占编号入索引，在「出图要求」「参考图位置」行注明「无图」。本卡不复制字段清单——两处清单必漂移。填好的标杆见 examples/prop-example.md 登记块。
