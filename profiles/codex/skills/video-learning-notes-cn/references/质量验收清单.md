# 质量验收清单

## 文件与链接

- [ ] 笔记位于用户指定目录，活动 Vault 已确认。
- [ ] YAML frontmatter 完整，代码围栏成对。
- [ ] 所有 `![[...]]` 从 Vault 根目录可解析，`missing embeds = 0`。
- [ ] 最终笔记没有绝对路径、临时目录、`file://` 或失效链接。
- [ ] 未静默覆盖用户已有文件。

## 内容覆盖

- [ ] 每个原始主要主题已进入正文或“有意省略项”。
- [ ] 每个学习目标都有对应讲解和练习。
- [ ] 重要定义、推理、步骤、案例、问答、失败路径和边界均已保留。
- [ ] 正文具有连续讲解感，不是标题加短 bullet 的大纲。
- [ ] 至少抽查三处时间戳/截图与正文是否一致。

## 事实与术语

- [ ] 课程原话、结构化提炼、实操延伸、外部补充和待确认已区分。
- [ ] 人名、产品名、专业词、数字和因果关系已交叉核对。
- [ ] 首次出现的英文/专业词已解释中文意思、用途和重要性。
- [ ] 5 个以上术语时存在术语表。
- [ ] 待确认内容没有进入事实卡或确定性结论。

## 图片

- [ ] 原视频截图、小黑解释图、内容关系图表、知识全景图使用不同目录和明确图注。
- [ ] 原视频截图带集数/来源与时间戳。
- [ ] 小黑图遵循“追上限，不追下限”：实质性长文默认 8 张、短文默认 3 张；少于默认数量时有明确理由，且全部图片覆盖不同认知锚点、经过逐张视觉检查、没有装饰填充或重复构图。
- [ ] 内容关系图表先做选型审计：类型符合主导关系，确有文字/表格无法替代的价值；每张交付 `.html` 与 `.png`，并通过 `self_check.py`。
- [ ] 图表节点超过复杂度预算时拆分为总览与细节；中文可读、焦点不超过 2 个、无重叠连线、无无证据补全。
- [ ] 需要全景图时，长文达到 12–18 模块、6–12 证据锚点，并交付 `.excalidraw` 与 `.png`；若用更合适的关系图替代，记录选型理由。
- [ ] AI 图片没有被用作课程证据。

## 学习与实操

- [ ] SOP 包含输入、步骤、产物、验收标准和失败处理。
- [ ] 每个关键坑点包含触发条件、后果、识别信号和规避/补救。
- [ ] 同时包含 Recall 与 Thinking 闪卡。
- [ ] 回忆、解释、对比、场景、实操题均有覆盖，答案后置或折叠。
- [ ] 有可复制模板、检查表和主提示词。

## 最终报告

- [ ] 报告视频数、总时长、帧数、截图数、小黑图数、内容关系图表数与类型，以及全景图模块数。
- [ ] 给出可点击绝对路径、验证器结果、遗漏审计和未决项。
- [ ] 所有报告数量与磁盘实际文件一致。
