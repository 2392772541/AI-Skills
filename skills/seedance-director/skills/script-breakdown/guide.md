[任务]
    剧本拆解。把适配定稿的本集剧本翻成后面各站能照做的统一中间表示——讲戏本。四件事：
        1. 逐场讲戏：每场先把这场戏讲给自己听——这是【导演思维】第 2 问的内化——落成场阐述与条阐述散文。
        2. 拆条：把每场切成生成单元，即条。一条 = 一次 Seedance 生成 = 一条提示词，2.5 单条上限 30s、场景级容量非必须填满，一场 ≈ 2–5 条为常态。条的划分是本站独占真相源；条内几个镜头归 shot-design，本站只做预估不定死。
        3. 配节奏与时长：每条先定节奏意图，再数拍、预算气口、落时长预算区间，标镜尾二态——接续或落地——与条间接缝卡。
        4. 提资产清单：人物/道具/场景三张表，每项标核心/边角 + 素材状态三态：新增、复用、变体。核心/边角定的是锁定强度——核心全套锁、边角轻量建档；三张表整表交资产包一次性出齐，表审后反推出的新增再补增量。
    首集、或视觉风格基准仍是草案时，额外一件事：把拷问产出的风格基准草案按字段规范落成定稿，写入 00-bible/visual-style.md——基准文本分两层，合起来是全片跨资产一致性的单一真相源：通用基准段全片一段，每张图提示词开头与每条动态提示词的恒定层都逐字嵌它；场域锚句按场域分列成表，只进本场域覆盖的条与本场域内的场景板，角色板与道具板一句都不嵌。

[第一性原则]
    本环节是【导演思维】第 2 问「画面化」的展开：把剧本的每一句话翻成能被拍出来的物理动作、具体光影与可预算的时间，翻不动的当场暴露，不带进下游。
    拆的颗粒就是出片的颗粒：一条 = 一次生成 = 一条提示词。多拆一刀下游多一条提示词，拆错全链跟着错。条的划分只在本站定，下游不许另拆。
    容量非必须填满：2.5 单条 30s 是场景级叙事容量，不是目标。时长跟内容走——先定节奏意图，内容即事件拍加气口反推时长，富余还给气口，绝不为塞满 30s 加戏或并异质叙事。容量翻倍之后，"闷头填满"的代价也翻倍。
    物理动作优先：讲戏只写镜头拍得到的具体动作和环境。"揉太阳穴、抓皱衬衫领口"能拍，"表现疲惫、内心挣扎"拍不了。情绪靠动作和环境托，不直说。
    画面密度≠文字密度：剧本一句话带过的高光——武打、追逐、奇观、情绪爆发——按银幕体量展开成多拍多镜配够时长；对称另一半是留白克制——安静戏别塞事件，气口和反应 hold 是戏，要单独预算。
    清单为下游服务：三张资产表是给设计站照做的资产表，不是剧情备忘。按入表标准筛，标核心/边角与三态；群演不入表、在阐述里写死外观。
    中间表示优先：拆解文档是结构稳定、字段齐整的 IR，可被下游站与审核对账，比文采重要。数字真相源单点化：条归本站，镜头数归 shot-design，时长换算细则归 references/duration-pacing.md——别处出现的数字都是只读副本。
    讲戏内化：讲戏是讲给自己听的，把意图钉死再落笔；用户看的是蒸馏结果，不是思考过程。

[风格基准定稿 · 仅首集或仍是草案时]
    - 按 director-grill 的 visual-style-spec.md [落盘骨架] 的字段表逐项补全草案：字段名与规范定义以那张卡为准，本站只填不另立、不挑着填。
    - 本站两张词表是常见锚的快捷方式，不是可选集合。草案的锚落在表内，就顺着对应行把特性抄全——references/dp-signature-styles.md 挑 DP 署名 + 三件套、references/film-stock-color-grades.md 挑色调流派 + 胶片牌号；表外锚、两锚杂交、带偏移声明的锚，一律先走 visual-style-spec.md 的 [风格锚研究法] 上网研究再蒸馏，结论落「风格锚」字段的「可迁移项 / 只属于原作项」两栏。禁止凭记忆出特征；禁止把表外锚硬掰成表里最近的一行。
    - 落层 1 通用基准段：按 visual-style-spec.md [基准文本规范 · 两层] 写成一段可直接进提示词的文字——媒介质感 / 色域 / 光逻辑 / 镜头性格四件，无年份、无地名、无任何具体陈设，写入 00-bible/visual-style.md 并标版本。跨资产一致性由这一段接管：设计站每张图提示词开头嵌它，motion-compile 恒定层逐字嵌它。把陈设也揉进这一段是本规范判死的头号事故——等于把一间屋子灌进全片每一帧。
    - 落层 2 场域锚句表：场域划分依剧本场头走——场头即内外景 + 地点 + 时间，与第 2 步编的场一一对应；内外景一律分立，同一空间改变了可见陈设或点着的光源物的不同时段、天气也分立；每场必须指到唯一一个场域，没有场次落空、也没有场次同属两域。逐域写 1–2 句：年份与地理 + 2–3 件本域可见的时代物证与陈设 + 本域的强调色来源物。第 2 步编完场号后把 sXX 回填进「覆盖场次」栏，第 4 步场景表落定后再回核一次——每一场都指得到唯一一个场域，才算定稿。锚句只进本场域覆盖的条与本场域内的场景板。
    - 定调帧即拿一张图管全片风格，不作默认手段——2.5 参考图容量虽已放宽，图作全片风格锚的稳定性待实测校准，文字基准仍是唯一真相源。
    - 定稿只是把已确认的草案落实成可执行文字，不再拉用户确认；若定稿对草案有实质方向偏离，列进待确认区问用户，不擅改。

[编场号]
    场跟剧本场头走——内外景、地点、时间；编 sXX 两位补零，按叙事顺序连续不跳号。

[逐场讲戏与拆条 · 本站主体]
    每场做完再下一场：
    - 先扫生成注记：01-script/epNN.md 本场段落里的行内【生成注记 → skill】是可实现性改造「标注放行」那一半工作量的唯一交接口；本站下游没有一站再读剧本，转发义务只能落在这里。按去向分流——去向 script-breakdown 的当场执行掉，如「本段为长动作，拆条以气口为缝」；去向 shot-design / motion-compile / sound-writing / review 的，按辖域逐字转进对应层级的【生成注记】栏——只管一条的进条栏、覆盖本场全部条的进场头场级栏、跨场的进第 1 节集级栏并点名辖域场次，一条只住一栏不逐场重抄，层级判据见 templates/breakdown-template.md 写作要点 8——不概括不合并不改写；去向 character-design / scene-design / prop-design 的，留到第 4 步进清单附注。一条都不许落地失踪。
    - 场阐述：先把这场讲给自己听——这场在全片干什么活、情绪从哪到哪、打算怎么拍。落一段场级散文。
    - 拆条：按 references/beat-splitting.md 三信号下刀——情绪转折、叙事功能转换、节奏容量；反向检查该合该拆，编条 ID sXX-cN。每条过一遍主体预算：把具名主体逐个列名写进条字段，不只记个数——下游 shot-design 排完镜要拿这份名单重数条级主体；1–5 个最稳，超了是拆条或降主体信号，待实测校准。
    - 配节奏与时长：按 references/duration-pacing.md——先定节奏意图，再按戏分档数拍，单独预算气口，时长落预算区间，条 4–30s 分档全部待实测校准；标镜尾——接续 0.5s 余势，或落地 1.5–3s 停稳。
    - 条阐述：每条一段自然散文，六维度揉在一起：画面内容/人物动作/台词声音/镜头感觉/光影氛围/气口与镜尾。声音线索就地写进散文——谁说什么用引号、音效绑在哪个动作上、环境声一层、要不要音乐；它们最终全部编译进动态提示词文字，本站先把线索讲清。
    - 高光条落逐拍骨架：判据是密度落差——下游动态提示词要逐拍穷尽、密度比散文高 4–5 倍的条，把已数出的拍列成「拍N 一句动作」的顺序清单；hold 也是拍，显式入列并带时长下限，如「hold：停在老秦停住的手上 ≥2s」。骨架只定拍序与轻重，不排时间轴——拍级时间戳归 motion-compile 编译时单源排定。非高光条维持散文，不拆骨架。
    - 条间接缝卡：每道相邻缝标出点/入点/手法，手法 ≥1；镜尾态与手法绑定校验，禁在动作半途、台词半句、转身中途下刀；缝上做了省略的，把下条要当既成事实用的每件画面物证逐件指到上游条的落点，指不到就补上游或换物证。细则在 beat-splitting.md。

[清单三张表 · 人物/道具/场景]
    - 入表标准与筛法照 templates/breakdown-template.md 各表说明；群演写死外观在阐述里，不入表。
    - 每项标核心/边角，定锁定强度：核心 = 主角级人物、贯穿场景、叙事关键道具，全套锁——角色表 + 声线锁 + 短串；边角 = 本场配角、次场景、随手道具，轻量建档。判据：这项资产错了要不要返工半集？要 → 核心，拿不准标核心，宁多勿漏。两档都随资产包一次性出齐；下游冒出清单外的核心级新资产 = 拆解遗漏，回本站补清单再补做。
    - 每项标三态：新增；复用附既有编号，如 复用 char-001；变体附原编号加差异，如 变体 char-001 雨夜湿身版。新状态 = 新变体，永不覆盖。
    - 场景条目附带两笔：锚定资产——这场画面里会出现、另有自己设定图要被 @ 的资产，标"背景出现/场景主体"；角度覆盖初判——这场有没有对话正反打、追逐横移，供 scene-design 对着 shot-design 反推清单备角度。
    - 道具收录按补拍风险分级：叙事关键物、人物动作对象、可能被单独补拍的一律入表；纯背景陈设留在场景描述里。
    - 收讲戏时扫出的资产侧生成注记：去向 character-design / scene-design / prop-design 的注记，逐字转进对应清单项的附注行并点名是哪一项——三个设计站不回头翻剧本，转不进来等于没排这颗雷。

[迭代模式 · 已有拆解时]
    问清变更 → 定位受影响的场与条做增量更新，改一条查相邻条的接缝与时长衔接；基准要动走变更记录与 decisions.md，不静默改。

[完成标准]
    确定性自检动手做：本站产物里可数、可对照的项逐一核过，不凭「看起来对」；查出的当场修，修完才交。
    1. 自包含测试打底：把 epNN-breakdown.md 单独拎出来，不靠脑子里的剧本记忆，光凭它下游每一站能不能直接动手。还要回头翻原剧本才动得了，就是没写够。
    2. 场号 sXX 连续补零、跟剧本场头一致；每场有场阐述。
    3. 每条单一叙事目的——一句话概括不靠"并且/然后/同时"；反向检查做过；条 ID sXX-cN 稳定连续。
    4. 每条先定了节奏意图，按戏分档数拍，气口单独预算；时长落在预算区间、没为凑满 30s 加戏或并异质叙事；具名主体逐个列了名、条内 ≤5，超了有显式理由。
    5. 镜尾逐条分清接续/落地；条间接缝卡齐全，出点、入点、手法俱在；镜尾态与手法不打架——标了动作匹配剪就没落地停死；缝上有省略的，下条用的每件画面物证都能指到上游条里造成它的那句画面事实，跨场缝逐道核过。
    6. 高光条有逐拍骨架——含 hold 拍的顺序清单、零时间戳；非高光条没有硬拆骨架。
    7. 条阐述全用可拍的物理动作和具体光影，无抽象情绪词漏网；声音线索——台词、音效、环境声、音乐意向——写进了散文；群演外观写死。
    8. 三张清单按入表标准筛过，每项有核心/边角标记 + 三态；复用/变体对过 reference-index 既有编号；场景条目标了锚定资产与角度覆盖初判。
    9. 首集：视觉风格基准定稿已写入 00-bible/visual-style.md——通用基准段可直接进提示词、四件齐且段内无年份无地名无陈设；场域锚句表覆盖本集全部场次，无场次落空、无场次同属两域，每句带年份地理与至少两件本域可见的时代物证；字段表按 visual-style-spec.md [落盘骨架] 逐项定稿、缺一项不算定稿，草案里的 [假设]/[待补充] 标注已清空；其中「时代与世界锚」与「烤进资产项」为硬项，空着一律不许交。reference-index 骨架已建。
    10. ep02+：上集落幅与未解线头已对账，承接写进了相关场的阐述。
    11. 假设与待确认区完整：能稳妥推断的写假设，带依据与风险；定不了的列待确认，标是否阻塞；没把假设当事实写死。
    12. 迭代模式：变更说明点名了受影响场/条与下游需重做项。

[禁止]

    - 禁止写成品提示词——本站产出是中间表示，动态提示词归 motion-compile，图像提示词归设计站。
    - 禁止重复确认配置——片种/画幅/风格方向已在立项收口定稿，本站只对账不重问；缺本集特有参数才问。
    - 禁止为凑满 30s 加戏、并条、拉长动作；禁止把两段异质叙事塞进一条。
    - 禁止注水：讲戏散文与条阐述精炼、精准——删掉这句下游不会少做对任何事的，就删；不为凑满模板格式写字，同一事实不在两处重复。
    - 禁止用抽象情绪词讲戏；禁止凭梗概硬拆，缺剧本回 script-adapt；禁止自行扩写剧情或资产，一律进假设/待确认区。
