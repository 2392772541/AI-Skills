---
name: four-view-method
description: 当你给一件入库道具写四视提示词、拿不准版式、比例参照、特写选位或材质怎么写时翻它。给出四视法全套判据与禁词、敏感词规避写法。
---

[定位]
    四视法是道具出图的默认与唯一主版式；底色与光逻辑统一为中性浅灰 + 软光，与角色表同一光逻辑。核心思路：一张图四视 = 同一次噪声 = 同一件东西；细节特写是下游 @对齐的锚；手掌是尺度的锚。
    本卡每节按「怎么认 / 认错长什么样 / 典型例子」给判据。

[四视构成]
    怎么认：
        一张图、四视水平排列——
            - 细节特写：放大该道具最可辨识的部位，选位判据见下节；
            - 正面、侧面、背面：完整外观三个朝向；
            - 旁附一只手掌作比例参照——道具独有，角色表没有这项；
            - 纯净中性浅灰无缝背景、柔和均匀软光，画面中除道具与比例手掌外空无一物。
    正文双保险：
        开头写一遍版式，正文再复述一遍「四视必须是同一件，材质、配色、磨损、尺寸比例完全一致」——只写一遍，模型会把四视画成四件不同的东西。
    认错长什么样：
        四格四件东西——没复述同一件；比例手掌变成「握着道具的手」——持握姿态被烤进资产，下游每次入镜都被攥在手里；背景出现桌面陈设——杂物成为伪关联物；版式句后面跟着一间具体房间——visual-style 的场域锚句串进了道具板，那一句只属于场景板与对应场域的条，道具板的年代由这件东西自身的形制与工艺承担。
    典型例子：
        见 examples/prop-example.md 各条。

[比例参照判据]
    怎么认：
        手掌旁附、摊开、不持握——「旁附一只摊开的手掌作比例参照，不接触道具」。手掌给画面内比例，文字再给真实尺寸 + 与手掌的比较关系，如「全长约四十厘米，比手掌长出一倍半」。尺度三重锚定即真实尺寸、画面占比、与框内已有物比较——这是它落在资产侧的半边，下游视频条的尺度锚从这里继承。
    认错长什么样：
        手握着道具——姿态固化；只有手掌没有文字尺寸——下游写「掏出」还是「扛起」没依据；用硬币/尺子作参照——引入多余物件，手掌是唯一标准参照。

[细节特写选位]
    怎么认：
        选最可辨识、最不可复制的部位——铭文、刻字、纹样、破损、开叉、接缝、序列号位。判定问句：下游拿什么认出「是同一件」？答案就是特写位。
    认错长什么样：
        特写选了最平整无特征的一面——锚等于没埋；特写选了会随状态变化的部位——沾血前后认不出是同一件，锚要选恒定部位。
    典型例子：
        旧怀表特写选表盖内侧的刻字，不选会起雾的表镜。

[材质四项]
    怎么认：
        材质/年代/磨损/尺寸四项各自落到能辨识——
            - 材质具名到工艺：「黄铜铸件、缝线处蜡渍发黑的植鞣牛皮」，不是「金属和皮」；
            - 年代从形制读出——铆钉款式、老式旋钮；年代形制从 00-bible/visual-style.md「时代与世界锚」的年份/地理与器物形制取，不自拟，写这件东西自身，不搬场域陈设；
            - 磨损写「它怎么显出来的」——用真实表面语言：rust, cracks, tape, fingerprints（锈、裂纹、胶带、指印），如「竹节处有细裂与磨白，刻痕里残留的暗金已氧化成哑光」；
            - 尺寸给真实数值 + 手掌比较。
    为什么：
        真实表面语言抗渲染感——没有磨损来历的道具出图是 3D 渲染件。
    认错长什么样：
        「一把旧刀」——四项全空；磨损堆「饱经沧桑」类形容词——没有可见证据；崭新道具硬加磨损——新旧状态要服从剧情，崭新也是一种要写实的状态：「漆面完整、棱线锋利、只有出厂拉丝纹」。

[禁词与敏感词规避]
    怎么认：
        每行按「雷区 → 正向替代写法」排——
            武器/爆炸物直写 → 触发安全拦截 → 用中性材料功能描述。参照写法："retro industrial electronic prop assembly, numerical readout."（复古工业电子装置道具、数字读数。）描述材料与功能，不点名危险品类；
            品牌与 IP → 一律不出现；要素面就正向写「无标识的哑光素面外壳」，不写「没有 logo」；
            帧内文字 → 模糊的「上面有字」会糊成乱码 → 先判这件东西上的字承重到哪一档，三档三种写法，判错档比写错字贵：
                内容承重，观众要读出写的是什么 → 引号内精确文案 + 字体字重颜色，如「杆身阴刻篆体『文以载道』四字，刻痕暗金」；多语言场景写明唯一语种；
                只有「这里有字」承重、内容不承重——磨浅的落款、挤成一团的批注、外文厂牌 → 写成正向的不可辨认态：给字的形制、行数、走向与磨损或挤压的程度，落到「一行阴刻小字，笔画彼此挤压到难以逐字分辨、刻痕被磨钝」这种能画的期望态。这一档禁写「不可读」「看不清」「不要求辨认」——否定式在图像规则集里反而把「字」注入得更用力；也禁退回第一档硬编一段文案——编出来的内容会被下游当成剧情事实引用；
                两头都不承重 → 这件东西上不写字，正向写素面本色；
            插画触发词 → painterly、概念设定图类措辞 → 写实项目写「道具定妆照/实物设定图」照片系措辞；
            画幅/分辨率参数 → UI 参数，禁入正文。
    认错长什么样：
        写了枪械品类词整条被拦；道具上出现随机乱码文字；素面道具长出虚构 logo；该走第二档的字被写成「字迹不可读」——否定式注入，出图反而写满一板密字；或被硬编成一段厂名，从此这段假文案在下游被当真。

[生成顺序与投喂注记]
    生成顺序：道具四视一条即成，不像角色表有多条锚链；变体条基于原版四视成图编辑，先有原版成图再做变体。对照密版核材质四项与特写部位；批量生成期验证按 06 头部「生成顺序与校准」小节，道具排在角色特写/全身与核心场景之后；唯一例外是双源穿戴件——那是某个角色全片戴着不摘、角色板要照它画的东西，它的四视提前排到该角色三格表之前，判据见 intake-grading.md [典型例子集]。
    投喂侧：按 2.5 官方稳定性排序，多张单视角图 ＞ 单张多视角图——重点特写镜头可把四视裁成单视角分图再作参考图，裁格提取法见 control-image 的 grid-method.md；上传顺序与 @图N 归 motion-compile：编译期按该条【参考资产绑定】段 @ 首次出现顺序定死、登记进该条条头【上传清单】，本站不预设。
    平台图像参数 · 只读副本：出图画幅走 UI 参数；四视横排建议 16:9，处在 2.5 图片输入宽高比 (0.4, 2.5) 与边长 (300, 6000)px 的限内。以上数值与「多张单视角优先」的唯一真相源在 character-design 的 three-panel-method.md 的 [投喂侧注记 · 平台图像参数唯一真相源]，改数只去那里改，本卡照读不改。
