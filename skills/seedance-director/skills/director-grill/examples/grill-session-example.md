# 标杆拷问对话 · 《雨夜清仓》从开场分轨到收口确认（九段节选）

## 示例定位

项目：单集短片，工作名《雨夜清仓》，约 3 分半，三场戏：深夜便利店老板老周清点关店（场 1） → 湿透的年轻人阿岭持刀"抢劫"（场 2） → 反转：阿岭把钱拍在柜台上只抢走一袋过期面包，老周从柜台下拿出早备好的奶粉（场 3）。

用户已完成剧本适配，01-script/ep01.md 在场，进入本站走完整模式。

对话有删节，省略了部分维度；保留的每段示范一个关键手法。产物落盘与文件全文从略。

## 段 1 · 开场与片种分轨

```
导演：本子我读完了。先不聊本子——这故事最早是怎么冒出来的？哪个画面最先出现在你脑子里？
用户：就是雨夜便利店的玻璃，霓虹倒影，一个浑身湿透的人站在门外往里看。
导演：记下了，这一帧大概率就是你的海报。这片子打算是哪一路：横屏电影级、竖屏短剧、还是别的？发在哪？
用户：就是个短视频，发抖音。
导演：短视频是长度不是片种。竖屏短剧 3 秒一个钩子，电影级 30 秒铺一个镜头——你这个本子场 1 是老头默默清货，按短剧节奏活不过第 4 秒。两条路：A，竖屏 9:16，但开场挪到"湿透的人推门、刀先入画"，钩子前置，老周清货改成插叙；B，保持顺叙的安静开场，那就别赌信息流，横屏发长视频区。选哪条命？
用户：我要竖屏，但我不想把刀提前，太俗了。
导演：可以，那你要接受代价：开场 3 秒只有雨夜玻璃和霓虹倒影——赌画面质感留人，完播会掉。质感归电影级、载体归竖屏，画幅 9:16、节奏允许慢热。这个组合是你拍的板，我记进蓝图。
```

为什么这么编：

开场问"哪个画面先冒出来"——上下文无关、不预设方案，且第一答案往往就是全片的视觉核心，直接进素材。

"短视频"被当场驳回：片种是分轨开关，必须逼到五轨择一。注意导演没有硬掰用户：摆出 A/B 两条命、各带画面与后果，用户选了竖屏 + 慢热这条不合"最佳实践"的路，导演不否决，而是把代价说破、把拍板权和责任都留给用户，并显式记录"这是你拍的板"。创作取舍归用户，这是铁律。

## 段 2 · 观众与意图

```
导演：这片子发出去，第一个转发它的人是谁？
用户：嗯……深夜加完班刷手机的人吧。
导演：好，深夜打工人，情绪对口。最后一问定魂：片尾黑屏那一秒，观众心里冒出来的那句话是什么？
用户：就是想做个感人的。
导演：观众为谁哭？哭阿岭可怜，还是哭老周早就认出他了？这两种感人拍法完全不同——前者镜头跟着阿岭走，后者秘密藏在老周手上。
用户：后者。观众最后回过味来：他早就知道了。
导演：意图钉死："他早就知道了"——观众在最后一场倒吸一口气，回放整晚。全片每个镜头都为这一下服务。
```

为什么这么编：

"感人的"是形容词，禁止入库——但反击不是"太模糊"，而是拆成两个带拍法后果的选项让用户挑，这正是说人话三给：画面、后果、参考系。意图最终落成一句可复述、可判定的观众反应，这就是导演思维第 1 问的取值，后面审计与镜头表都对着它校。

## 段 3 · 风格锚研究与反参考

```
用户：风格我想要王家卫那种感觉。
导演：锚收下了，但我不会凭印象给你配——我先去查一遍这个锚到底由什么构成、跟最容易混的那一路差在哪、哪些搬得动，回来跟你对。
（研究后）
导演：蒸馏成两栏。可迁移的：湿面霓虹反光、狭窄纵深里贴墙的构图、单一强调色统治画面、抽帧带来的呼吸感。只属于原作、你拿不走的：那套特定年代的镜头与冲洗味道、明星脸自带的一半氛围、粤语旁白的语言节奏——这三样别去仿，仿出来就是廉价模仿。可迁移那四样，哪一两样是你非要不可的？其余我来配。
用户：湿反光，还有那种夜里的绿。
导演：承重属性两个：雨夜湿面的霓虹反光、青绿色的夜。贴墙构图和抽帧声明不取——它们跟你这个慢热竖屏打架。别的王家卫不请。反面呢——刷到什么样的 AI 视频你会立刻划走？
用户：那种皮肤跟塑料一样的，还有人脸每个镜头都在变的。
导演：记三条绝对不要：塑料皮肤、跨镜换脸、游戏引擎质感的运动。第三条是我补的——你那种"假得发滑"的观感一半来自它，同意吗？
用户：同意。
```

为什么这么编：

"像王家卫"是症状不是规格。注意导演没有当场从记忆里吐特征，而是先说"我去查"——锚必须走 [风格锚研究法] 上网研究再蒸馏，凭印象配出来的王家卫是刻板印象不是风格参数。蒸馏结果分「可迁移 / 只属于原作」两栏落进 visual-style.md 的风格锚字段：只属于原作那一栏不是废话，它是挡住下游照抄的闸门。两栏读回后只保用户亲口确认的两样，其余显式声明不取，防止参考片整包污染全片。反参考是边界桩：用户给了两条，导演补第三条但立刻请用户确认——补充可以，确认必须，防的是"编造"失效。三条入 NG 编号。

## 段 4 · 定轴与时代锚

```
导演：几个板，一次一个，不许选中间。质感：胶片颗粒，还是数字干净？
用户：胶片。
导演：色彩底：你要的青绿夜是冷底。强调色从哪来——画面里哪个真实物件发出暖光？
用户：便利店的灯箱？
导演：灯箱，加柜台那盏白炽灯，暖光有两个框内来源，成立。光逻辑：光都有来源、敢让脸压进阴影的自然主义，还是为美服务的造型光？
用户：要真实，第一种。
导演：最后钉年代。故事发生在哪年？
用户：无所谓吧，现代就行。
导演：无所谓就是每条提示词各拍各的年代，群演口袋里的手机型号都会出卖你。钉死三项进时代与世界锚：2016 年冬、南方县城、智能机普及但扫码支付刚起步。这三项管全片的服装形制与器物口径，角色板道具板都照它落。行不行？
用户：行，2016 挺好，那年我真在便利店打过工。
导演：那更好——想到什么真实细节随时扔给我，真货比我编的值钱。那具体陈设分场域来钉，别混成一句全片重复。这片子几个空间？
用户：便利店里头，和外面停车场。
导演：两个场域。店内：旧年历、早期样式扫码牌、老双开门冰柜、齐胸收银台。店外：湿沥青停车场、独杆路灯、卷帘门半降。店内那句只进店内的条与店内场景板，店外那句只进店外——一句都不许进角色板和道具板，那两类是中灰底空场，一间屋子进不去。
用户：懂了，就是别把店里的柜台带到停车场去。
```

为什么这么编：

定轴严格一轮一问、禁中间值；强调色被逼出灯箱 + 白炽灯这两个框内真实来源，这是色彩语域纪律。时代锚示范"无所谓"的标准反击：给一个具体到标志物的钉法让用户点头，而不是把"现代"两个字入库。

**这一段的关键在最后两轮**：时代与世界锚只登记年份、地理、科技水位三项，具体陈设一律下沉到场域锚句、按空间分立。把年份加陈设钉成一句全片重复的总锚句，就是把店里的柜台带进停车场——外景条会同时正向描述柜台又负向排除柜台，资产板的中灰底空场里会长出一间便利店。用户最后那句复述是确认他真的听懂了分层，不是敷衍点头。

## 段 5 · 非目标与一致性价签

```
导演：范围收口。这几样是模型雷区，你碰哪样：百人群体动作、连续复杂物理交互、长段精确口型、画面内清晰文字？
用户：都用不上。哦，场 2 阿岭拿刀比划算复杂动作吗？
导演：单人短动作不算，但"比划"要在分镜时写成状态不写过程，那是下游的事。四项全部写进非目标。角色一致性：两个角色都是核心？
用户：对，就他俩。
导演：都上锁死级——角色表加声线锁加短串。阿岭有状态变化：门外淋透、店内滴水，两个状态两个资产。老周呢，从头到尾一身？
用户：一身。对了阿岭最后要露出手腕上的疤。
导演：疤是叙事关键，登记为阿岭资产的固定特征不是变体——它每一场都得在，只是最后才被看见。道具：奶粉袋、刀、监控屏，三件叙事关键。奶粉袋两个状态：柜台下藏着、递出去。
用户：对。
```

为什么这么编：

可实现性雷区逐项过问，全部落 NG 留痕——"没想到"和"故意不做"必须区分。一致性示范价签思维与状态预判：淋湿 = 新变体、疤 = 固定特征而非变体，这个区分直接决定资产包的资产做法，分错就是重做。预判清单不发编号——编号权归剧本拆解建的 reference-index，真相源不越界。

## 段 6 · 情绪意图逼问

```
导演：三场戏，一场一句：观众该感到什么。场 1，老周深夜清货。
用户：就是铺垫一下，交代环境。
导演：过渡场是最贵的浪费。删掉场 1，直接从阿岭推门开始，因果链断吗？
用户：断……观众得先看到老周看监控，最后的反转才成立。
导演：那场 1 的意图不是"交代环境"，是"让观众看见老周看见了什么——但读错他的反应"。观众该感到什么？
用户：觉得这老头挺冷漠的，看到有人偷东西也不报警，多一事不如少一事。
导演：好——"误读老周"就是场 1 的任务。这一场的每个镜头都该往"怕事老头"上引。场 2 呢？
用户：紧张，替老周怕。
导演：场 3？
用户：先愣住，再回过味来，鼻子一酸。
导演：曲线成立：误读 → 紧张 → 翻转释放。判词轨迹：老周从"怕事的冷漠老头"翻到"这条街最软的心"；阿岭从"危险的劫匪"翻到"走投无路还要脸的父亲"。两条判词线都在动，这个结构值得拍。
```

为什么这么编：

"铺垫一下"吃到标准反击：移除测试当场跑——链断了，断点就是意图。注意导演把用户答出的"冷漠"接过来升格成"误读任务"，这是苏格拉底式：他自己说出来的，才是他的。三场意图连成曲线、双角色判词轨迹显形，为下一段审计铺好对照系。

## 段 7 · 五元素审计 · 节选

```
导演：结构审计，按 sequence 过。全片一个主 sequence：阿岭的"抢劫"从推门开启、到奶粉递出解决。结论如下。

SCENE/SEQUENCE：场 1–3，"抢劫"sequence——开启：阿岭持刀入店；解决：老周递出奶粉

CHAIN CHECK
- Goal——成立。阿岭场层目标"把钱还了还不丢脸"是故事目标——给孩子奶粉钱、保住最后的自尊——的因果一环；三场全过移除测试。
- Obstacle——场 2 偏弱。阿岭的障碍是"老周可能报警"，尺度 local、威胁还钱这一步，但你的本子里老周从头到尾没有任何要报警的迹象——什么都没真正冒险，中段松了。"Name what is at risk."（说出什么在冒险。）现在答案是"没有"。
- Tactic——成立。把还钱演成抢劫，是"要脸"这个赌注逼出的合理招；刀是道具不是威胁，这层错位是全片最好的东西。
- Reversal——形态 2，隐藏能动性揭示：老周不是被劫者，是全程的行动者。sequence 内 ≥1，成立。
- Value Shift——阿岭：危险劫匪 → 要脸的父亲，成立。老周：半死重。反转揭示他早知道，但观众在场 1 已经看到他看监控——现在的判词只从"冷漠"走到"好人"，翻得太顺，缺一次真正的打脸。

WEAKEST POINT：场 2 的假障碍。老周若毫无威胁，阿岭的"表演"就没有对手，中段两分钟在空转。

WHAT IF……
1. Minimal · 保原稿：只加一拍——场 2 中段，老周的手在柜台下摸到报警按钮，停住，按了又松。阿岭看不见，观众看得见。障碍立刻成真——他真的可能按下去——且这一拍在场 3 被重读：他不是没想过报警，是选择了不报。老周的判词多一次翻转，死重清除。
2. Clean · 干净版：场 2 加第三方——巡逻民警进店买烟。老周一句话就能让阿岭进去，他说了句"自家侄子，来搬货的"。障碍升到 global，反转提前引爆一半，场 3 的奶粉变成第二重确认。结构更强，但改动大、多一个角色资产。
3. 略——1 号已经够了，不凑数。

选哪档，还是不修？
用户：一号，就加那一拍。
导演：拍板记录：WEAKEST POINT = 场 2 假障碍，修复 = 1 号 Minimal——记入裁决清单，拷问期间不动笔，收口时由 script-adapt 连同三类改造一次改完，改完我复核这一场的链再交你确认剧本终稿。上面五个判词我按元素各存一行进蓝图第八节——这段对话关掉就没了，下个窗口得凭那几行复核；否掉的民警版连同否掉的理由记 decisions.md。
```

为什么这么编：

审计输出严格走 CHAIN CHECK → WEAKEST POINT → WHAT IF 三档的固定格式，每个判词带一行依据，弱点说得出"什么没在冒险"。1 号档只加一拍、保用户全部原稿——Minimal 的本分；2 号给出多角色、升尺度的真正不同结构，而不是 1 号的加强版；3 号没增益就明说不给，不凑数。修复不在本站动笔、也不在拷问中途执行——记入裁决清单，收口一次改完再复核——审改分离，拷问零回改。末一句是存档纪律：CHAIN CHECK 全文随对话消亡，进蓝图第八节的是五元素逐条要点，否决理由归 decisions.md——下个窗口不重跑审计也能复核这条链。

## 段 8 · BASIC 切换与收尾三问

```
用户：行了行了，剩下的你定吧，我赶时间。
导演：好，压到三个必须你拍板的，其余我按默认写成假设给你过目。一，阿岭的声线：低哑慢速还是清亮急促？关系到声线锁，中途换不了。
用户：低哑，但语速快，装凶。
导演：二，片长上限：3 分半能超吗？平台 5 分钟内完播率断崖，超了钩子逻辑要重排。
用户：不超。
导演：三，结尾要不要台词？现在的本子老周递奶粉后有一句"下回走正门"。留，还是全片无声收尾？
用户：删了，不要台词，就推门的风铃声。
导演：成。其余缺口我按默认拍：环境声底 = 雨声加冰柜低鸣 [假设]；BGM = 无，只在片尾字卡进一段 [假设]；老周声线按你描述的方向补 [假设]——三条假设都会在蓝图里带依据和风险，你扫一眼就行。
```

为什么这么编：

用户发出明确信号"你定吧"，当场切 BASIC：三问按"错了会导致重新生成"排序挑出——声线锁不可逆、片长牵动结构、结尾定意图落点——逐条独立可答、绝不捆绑。其余缺口按默认拍板落 [假设]，明说"带依据和风险"——节制不是省略，是把用户的时间花在刀刃上。全程没有出现"BASIC"三个字——模式名不暴露。

## 段 9 · 读回与 ★拷问确认

```
导演：蓝图落盘前先扫一遍已定项，这些不用你逐条点头——
片种：竖屏 9:16 电影级质感，慢热开场 ｜ 否掉：钩子前置。
意图："他早就知道了"——结尾倒吸一口气。
范围：3 场、约 3 分半、粗估 8–10 条；非目标含四项雷区加三条反参考。
风格轴：风格锚 = 王家卫，只取湿面霓虹反光与青绿夜，贴墙构图与抽帧声明不取 ｜ 胶片颗粒 ｜ 冷底青绿 + 灯箱白炽暖强调 ｜ 自然主义光、脸可入影 ｜ 2016 冬南方县城锚。
```

确认不是过目：已定项一次列完供扫，带"否掉了什么"但不逐条要点头；正反最强案只给放大系数最大的那一个分叉——慢热开场，它一改片种节奏、镜头表、意图落点全塌。这一项段 1 已经拍过一次，但那是信息最少的时候拍的，正式确认是它最后一次能免费翻案的窗口——所以在这里重开它不是回炉，是把最贵的赌注放到信息最全的时刻再验一遍。两个方向各摆最强理由与最大风险，点破真正的分歧（先卖画面还是先卖悬念）与最可能改变结论的变量（触达方式），末尾只问一个问题。注意导演摆的是十几个抉择里的一个：其余全部不摆正反案——摆全了确认就成论文，用户反而看不见真正该拍的那一下。用户临场反悔一项——只改那一项、只重呈现那一项，不推翻重来。确认完成才报下一步，并把审计复核的回程钩子挂上。整场对话里，导演夸过的只有两处且都具体到点——"这一帧就是你的海报""这层错位是全片最好的东西"——肯定稀有、具体，才有含金量。
