# 任务路由

执行技能已明确时直接使用它；普通编辑、已选框架和一次性问答无需先跑总路由。用户指定的工具、输出格式和当前项目优先。

1. 技能治理请求先进入 `skill-product-manager`。其他任务按交付物选择最少的适用技能。
2. 需要比较相邻能力时读取 [场景边界](references/task-boundaries.md)；仍无法定位时才查 [生成目录](references/generated-catalog.md)。不要一次读取所有技能。
3. 读取选中技能后继续完成原任务。只有用户只问技能推荐时，才以简短推荐结束；路由报告不是执行任务的完成标准。

允许按已有信息采用可逆默认值；只询问会改变交付物或授权范围的关键缺口。辅助技能按实际需要追加，不为固定调用链加载无关说明。

验证路由时检查正向、负向和冲突请求；记录实际命中的技能，不把关键词脚本得分当成模型行为证据。
