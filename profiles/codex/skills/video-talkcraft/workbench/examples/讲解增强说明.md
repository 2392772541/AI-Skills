# 讲解增强：20 种可编辑动效

在「动效库 → 讲解增强」中找到新增卡片，可用名称搜索。点击预览，拖到时间轨后选中片段编辑文字、数值、颜色、动画节奏和透明底。默认卡长 9 秒；慢节奏需要保留足够片段时长。

`explain-kit-20.json` 是可导入的 20 卡展示工程，每卡 6 秒，共 120 秒。导入会替换当前工程，请先导出自己工程的 JSON。`default-demo.json` 保存与程序默认示例相同的内容。

| 动效 | 视频用途 | 实现范围 |
| --- | --- | --- |
| 结构拆解重组 | 产品组成、模块解释 | 三个文字部件展开和收拢；非真实 3D 模型 |
| 流向分配图 | 预算、流量、资源去向 | 一个来源至三个去向，宽度按非负值比例计算 |
| 增减贡献拆解 | 收益、成本、前后差异 | 起点加三个正负增量，终点自动求和 |
| 前后指标迁移 | 改版、实验前后对比 | 三组 0–100 指标 |
| 双轴位置迁移 | 方案定位、策略变化 | 一个对象的起终位置，双轴 0–100 |
| 条件分支决策 | 操作选择、判断依据 | 一个判断、两个分支，选择突出方向 |
| 四步反馈闭环 | 方法论、迭代流程 | 四个环节及中心主题 |
| 分层剖面展开 | 架构、组成层次 | 四层，指定突出层 |
| 层级结构展开 | 组织、知识分类 | 一个根节点、三个分支及对应细项 |
| 观点证据对照 | 评测、论证、澄清 | 三组观点与证据；证据需自行填写核实 |
| 逐级转化漏斗 | 用户路径、销售流程 | 四级非负数值；请提供符合漏斗含义的数据 |
| 矩阵强度揭示 | 多方案比较 | 3×3 矩阵，数值 0–100 |
| 并行任务排期 | 制作计划、项目进度 | 四项任务，总跨度不超过 365 天 |
| 估计区间揭示 | 范围与不确定性 | 三组下界、点估计、上界，刻度 0–100；不计算置信区间 |
| 频数分布展开 | 样本分布 | 四个连续等宽分组，频数由用户提供 |
| 累计贡献聚焦 | 找主要问题或贡献 | 四项数据自动降序，计算累计百分比 |
| 目标达成对照 | KPI、进度评估 | 三组实际值与目标，统一 0–100 |
| 构成占比环图 | 预算、资源组成 | 四项非负值，自动计算总量及占比 |
| 排名位置重排 | 两次评测、排名变化 | 四个对象的两个状态；中间动画不代表真实历史 |
| 集合交集聚焦 | 共同点、产品价值 | 两集合及交集示意，面积不代表数量 |

所有卡片为本地原创的 Remotion 帧驱动实现，没有下载付费模板或增加运行依赖。默认数据均为演示。透明底用于工作台内叠加，当前 H.264 MP4 导出不保留透明通道。显示文字需适合画面密度，长段落应拆成多个片段。

## 验证

- `npm run build`：TypeScript 与 Vite 构建通过。
- `node scripts/verify-explain-kit.mjs`：20 张卡各渲染 3 帧，共 60 PNG；全部具有帧间变化；含长文字、负值、零值和无效区间等边界输入，无渲染错误。
- 浏览器确认素材库 129 卡、新分类 20 卡、名称搜索、示例 JSON 导入、文字参数编辑。
- 实际导出展示 MP4：960×540、30fps、约 120 秒，ffmpeg 完整解码通过。测试结果在 `exports/explain-kit-qa/verification.json`。
- 工作台已有的窄屏布局及旧素材预览缺失不属于本批新增内容；没有声称已解决。
