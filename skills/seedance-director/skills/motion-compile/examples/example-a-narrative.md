# 标杆 A · 单人情绪叙事的 A 轨条

## 示例定位

A 轨叙事条标杆：单人情绪叙事、时间戳分段、紧档、18 秒。先给条头与成品全文，再逐段附「为什么这么编」注解。全文是可直投喂形态——照条头清单传三张图，整块复制围栏粘贴即生成。例子自洽，资产编号、通用基准段与场域锚句均为本例虚构。

## 成品全文

```
生成一段 18 秒、21:9 的写实电影质感视频，深夜修表铺里的单人情绪戏，克制而温热。

【参考资产绑定】
陈伯，这是该角色的参考 @图1，作为其唯一身份、面部、年龄感、发型、身体比例、服装与固有配饰参考；不得继承该图的中灰背景、定妆站姿与表情。
@图1：六十四岁，清瘦驼背的修表匠，深夜打烊时分，藏青围裙沾着机油渍，额头架着掀起的单眼放大镜，右手拿一块起毛的软布——与参考图完全一致。
修表铺内景，这是整个拍摄场景的参考、不是片中某一帧 @图2，作为其唯一空间结构、固定物体、材质、纵深与光源方位参考；只控几何、材质、光线、氛围，不控构图；保持左右关系、入口与消失点不变。
黄铜怀表，这是该道具的参考 @图3，作为其唯一外形、尺寸比例、材质与开合结构参考；表盖起初闭合，静置于柜台绒布上，本条中被陈伯右手拿起、以拇指开盖；不得继承其展示背景。

【全局设定】
整体呈现胶片质感的写实影像：暖黄钨丝灯底色配窗外冷青雨夜，对比柔和、颗粒细腻，光线全部来自画面内真实光源；球面镜头，视场安静克制、透视自然平实。高清、细节丰富、光影自然层次分明。
时代与世界：1998 年中国南方县城，画面中不得出现智能手机、液晶屏幕与现代车辆。
场域锚句（修表铺内景）：齐胸高的老式玻璃柜台压着一层墨绿旧绒布，柜台后木格架上摆满待修的座钟与马蹄表，侧墙挂一面停摆的老挂钟。
出场人物：陈伯（六十四岁修表匠，清瘦驼背，藏青围裙）。
声音基调：全片只有窗外的雨声与店内挂钟的滴答作环境底，无背景音乐。

【分镜正文】
[0-4秒｜打烊与发现]
陈伯俯身用软布擦拭玻璃柜台，动作缓慢匀速，随即手停住——柜台绒布上留着一块闭合的黄铜怀表。他直起腰，视线落在怀表上，呼吸放轻。镜头从中景缓慢推近他的侧脸与柜台——全条锁定 47° 视场角，标准镜头性格，机位距主体 3–5 米，自然人眼透视，无可见畸变，脸与身体比例自然——背景格架随推近逐渐失焦虚化。软布压过玻璃发出细微的摩擦声，雨声持续。
[4-9秒｜拿起与端详]
严格承接上一阶段的人物、摄影机、道具、光线和声音状态，不重复已经完成的动作。他放下软布，右手拿起怀表托在掌心，手腕轻轻一掂，感到分量后眉梢微动；左手把额头的放大镜翻下来对准表盖，凑近端详盖面的划痕。镜头不中断地随他的手部动作推成手部特写，47° 镜头性格全程保持不变，紧凑取景靠机位物理推近取得，无长焦压缩，无广角夸张变形；怀表占画面宽度约三分之一，约为他掌心的一半大。金属链条滑过绒布发出轻响。
[9-14秒｜开盖与上弦]
他拇指按住表冠一推，表盖啪的一声轻响弹开，盖内贴着一张泛黄的黑白小照片。他的呼吸一滞，眼睑垂下又抬起，喉结滚动一次，随即用指腹极轻地拂过照片边缘（这是辨认，也是怕碰坏的珍重）。镜头停在手部大特写上不动，焦点如刀锋钉在盖内的小照片与拂过的指腹上，绒布与柜面纵深在焦点外柔成一片暗调。停了一拍，他捏住表冠缓缓上弦，棘轮发出咔哒咔哒的细密声响，秒针随即颤了一下、重新走动起来。
[14-18秒｜收束]
他合上表盖握在掌心，低声说："还走着呢。"（低哑，几乎气声；声线：苍老沙哑的男声，语速缓慢，尾音下沉，带南方口音）。镜头缓慢后拉回到中景，仍是 47° 标准性格、无滑档，景深随机位后撤恢复，背景格架重新可读但不夸张；他站在暖黄灯下，握着怀表的手垂在围裙前，窗外雨声不停。画面落地停稳约一秒半后定格，双手十指清晰，无多余肢体。

【结束状态】
人物位于柜台内侧、正对柜台，面向店门方向，手中持有闭合的黄铜怀表（右手掌心握住），动作停在握表垂手站立、上弦已完成，情绪为克制的怅然与释然交叠。

【衔接】
承接上条出点：ep01-s03-c1 落幅——最后一位客人推门离店，门铃余音未落，陈伯留在柜台内侧。
本条入点：空间顺承（同一空间新机位，从擦柜台的日常动作静启）。
结尾采用落地态：留约 1.5 秒稳定落幅后定格。

【针对性负向】
结尾定格，不切黑、不转场；全程画面中只有一块怀表，任何时刻出现第二块怀表 = failed take（废镜）。

【全局禁止项】
无字幕、无水印无 Logo、无额外人物、无动作重置、不切黑。
```

## 全例总注

为什么这么编：

逐段过一遍。

- 选轨与定档：单人、无对白往来、情绪沿真实时间发酵——A 轨教科书场景；本片是正片、不是 UGC 或生活流，本条无多 take 选优、场阐述也没放权，松档三条一条不中 → 紧档，逐段编排。控制等级只管这条要不要控制图，与松紧无关。时长 18s 落在 15–22s"完整情绪转折"档，待实测校准；节拍取 4 段，符合情绪长镜 3–5 段的密度分档——没有为凑 30s 拉长。四段逐段做过容量自平衡：全条只有两处自带时长的内容——[9-14秒] 的"停了一拍"约半秒、[14-18秒] 的"停稳约一秒半"，各自远小于所在段的 5 秒与 4 秒，差额留给动作与落幅。反例长什么样：4 秒的段里同时要"两滴水间隔约两秒"与"末尾停满约三秒"，光这两项就 5 秒，段自己先算不平——模型不会按比例缩，它会抢跑或直接删掉那个停顿，而停顿往往正是这段戏的全部力气。
- 首句声明：四要素齐——18 秒/21:9/写实电影质感/一句话基调；一句讲完不铺陈——首句是声明不是散文。
- 条头上传清单：三行的顺序就是绑定段 @ 的首次出现顺序，即角色 → 场景 → 道具，编译时就已确定，所以号能在这里写死。清单在围栏外、不进生成框：用户照它传三张图，再整块复制围栏粘贴，中间一个字都不用改。项目编号那一列是留给人与下游文件反查的真相源——char-001 跨集不变，@图1 只在这一次会话里成立，换一条就可能是别的号；文件列逐字抄 reference-index 的「参考图位置」，不自拟，否则用户面对一堆图不知道传哪张。围栏里检索 char- 零命中是硬指标：项目编号漏进生成框，模型只会把它当一串无意义字符，脸就随机发了。
- 绑定段：三个地址各恰好出现一次，先职责句再 @；角色条目带行内状态公式——「@图1：六十四岁……」这第二次 @ 是铁律 1 的法定例外，照母版写必然有；状态只写本条用得上的——围裙油渍、翻起的放大镜、手中软布，全是后文动作要用的锚点——不抄五官密版。场景带继承禁令原句。道具追踪了持有者、左/右手、开合状态的全条变化：闭合静置 → 右手拿起 → 拇指开盖。运动中的道具会复制、会换手，状态不写就漂。
- 恒定层两层分开装：通用基准段就四件——媒介质感、色域、光逻辑、镜头性格，"球面镜头、视场安静克制"是第四件，缺了它模型在第二段推近时会自己换一支长焦、一条内两种镜头性格；紧跟其后的"高清、细节丰富、光影自然层次分明"是恒定层里的画质固定项，另算一件、不并进四件。这两样都跨场逐字复用；柜台、格架、老挂钟这些具体陈设住场域锚句，只因为本条就发生在修表铺内景才带上——同一部戏的雨夜院子外景条，这一行整行不写，绝不把柜台灌进只有檐、瓦与湿青砖的画面里。本例为虚构基准，实际编译从 visual-style.md 逐字抄两段。时代锚单独一句进恒定层——1998 不逐条重复，模型会把柜台拖回当代；单人简单场，空间地图块省略——省略是按需项规则，不是漏。声音基调只写一层环境底 + BGM 指令，为正文的音效留出层次。
- [0-4秒]：动词领头"俯身擦拭"，不用"深夜的店里很安静"式铺垫起手；触发源可见——怀表入画——才有手停、直腰、呼吸放轻的反应：反应必有触发。运镜单独成句、单一运动缓推 + 失焦，无叠加；光学锚跟运镜同句落位——47° 度数 + 人眼透视、无畸变的结果语言，是把镜头表【镜头语言】的光学槽带进了正文，只留"中景缓推"就等于把这一槽丢在镜头表里。
- [4-9秒]：固定承接句起头——A 轨第二段起必带。"手腕轻轻一掂，感到分量"是物理锚定——重量要被演出来；镜头跟手推成特写用了连贯词"镜头不中断地随"，声明动作变了镜头没切。"占画面宽度三分之一，约为掌心的一半大"是尺度三重锚定——真实尺寸在绑定段、画面占比、与框内已有物比较——防道具尺寸漂移。推成特写时补的"镜头性格不变、无长焦压缩、无广角夸张"是标准档防漂移的短形：不写这句，模型会在推近时自己换一支长焦，一条内两种镜头性格。
- [9-14秒]：情绪节点用物理指令 + 情感解析成对——"指腹极轻地拂过照片边缘"是可拍的物理指令，括号里"（这是辨认，也是怕碰坏的珍重）"向模型解释潜台词；情绪走生理顺序链——呼吸 → 眼睑 → 喉结 → 手指——不写"他很感伤"。音效全部绑可见动作：开盖轻响绑拇指推表冠、棘轮声绑上弦。"秒针随即颤了一下、重新走动"给了动作终点。
- [14-18秒]：台词四件套齐——引号直写原文 + 语气低哑气声 + 声线锁逐字引用，实际编译从 reference-index 抄；台词只有五个字，留足呼吸——台词不占满时长。收束选落地态——本条是情绪段落终点——1.5 秒落幅写明，它是本段唯一的显式时长要求，4 秒段容得下，剩下 2.5 秒够走完合盖、台词与后拉。"双手十指清晰，无多余肢体"是症状负向化进散文的示范——手部特写条的真实风险。
- 结束状态与衔接：五字段逐项落，"上弦已完成"明确任务进度——已完成的动作下条不得重启；衔接段承接了上条出点并声明入点手法，收束两态选了一态并写明秒数。
- 负向与尾缀：症状负向只挑两项：切黑风险 + 道具复制；道具复制升格为带判定尾的硬性判定句写法；尾缀固定五项、无片型附加——正剧无需。零堆砌——没写的负向都是本条不存在的风险。
