# A 轨动态提示词母版

## 使用说明

- {{}} 内为填空位；〔〕内为按需项，用不到整块删除，不留空壳。
- 一条两块：条头在围栏外、不进生成框——元信息行 + 上传清单表，用户照它传图；围栏内的九段是投喂正文，资产一律写平台地址 @图N。传完图整块复制围栏粘贴即生成，中间零替换。
- @图N 的号 = 条头上传清单的上传顺序号，本母版里的 1/2/3 只是最常见排布的示范，实际按本条清单的行号写；项目编号 char-NNN / scene-NNN / prop-NNN / ctrl-… 只活在条头那一列，围栏里一个都不许出现。号是位置不是身份——同一个角色在别条可能是别的号，每条各自数，绝不从上一条抄号。
- 恒定层四处"逐字粘贴"是铁律：visual-style 通用基准段、visual-style 里本场场域的场域锚句、reference-index 人物短串、本场镜头表场头的场级空间地图块，一个字不改地抄，不改写、不概括。场域锚句只取本场场景所属的那一条——外景条一个内景陈设都不许带；空间地图块只搬七行字段，块标题行不搬——标题里的 scene-NNN 是项目编号，进围栏即残留。
- 填写顺序建议：先条头元信息行与首句 → 恒定层第 3 段 → 绑定第 2 段 → 按绑定段 @ 首次出现顺序回填条头上传清单 → 正文第 4 段 → 结束状态与衔接第 5/6 段 → 负向与尾缀第 7/8 段。
- 段 7 无症状则整段删除；其余段一律保留。
- 松档条：第 4 段改为因果链写法、不逐段派镜头，并必带〔镜头自由度边界声明〕，见母版内标注。

## 自检

填后自检：条头清单与正文双向对账、@图N 连号、围栏内零项目编号残留——逐项动手核。
- [ ] 每个围栏 = 一条可投喂提示词或一个逐字引用块，元信息与上传清单全在围栏外；每段显式时长要求求和 < 段时长，无一段算不平；时长在 4–30s 档位内，待实测校准。
- [ ] 恒定层：通用基准段与 visual-style.md 可 diff 为零；场域锚句取的是本场场域那一条，外景条零内景陈设；时代锚在恒定层。
- [ ] 空间地图按本条裁剪后逐字注入：无非本条人物、无别条镜号，块标题行与编译期注记未随入；机位侧 / 轴线 / 板内可见地标清单 / 可见范围 / 重述规则五处跨本场每一条逐字一致。
- [ ] 控制图块的回指已去 @ 换代称；正文全特征代称、无裸人名。
- [ ] 每段镜头响应带视场角锚点 + 光学结果语言，与镜头表【镜头语言】对得上；同一镜内不换镜头性格，跨段不滑档。
- [ ] 结束状态五字段齐；衔接两行齐；收束两态选了一态。
- [ ] 台词与镜头表逐字一致；声音四要素落实；主体 ≤5。
