# 🎬 26Flow 视频视觉资产与直通工作流引擎 (26Flow Pipeline Engine)

> **定位**：纯工程化、高确定性的**“短视频下半部分视觉工程工厂”**。  
> **核心原则**：不干涉上半部分的剧本文学与镜头叙事；专注接收**纯文本分镜**，全包后续所有**视觉参考图制作、工作流工程装配与成片合流导出**。

---

## 🏗️ 架构分工契约 (System Division Contract)

* **上半部分（用户自由创作）**：
  - 无论使用 `seedance-director`（废才导演）、`seedance-xiaomo-director`（小墨导演）、第三方 Agent 还是手写文本；
  - 产出物只需包含：镜头序号、画面描述（生图参考）、运镜描述（视频动态）、口播台词（VO）、时长。
* **下半部分（本技能全权负责）**：
  - **环节一【万能文本吸纳】**：调用 `tools/adapt_storyboard.py` 自动吸纳任意格式的分镜文本并校验镜头连续性；
  - **环节二【视觉参考图制作】**：
    1. **风格参考矩阵（3 选 1 强阻断）**：基于分镜主题先出 3 张截然不同、无文字的风格参考板供用户定夺；
    2. **全局母卡资产锁定**：根据分镜内容生成/挂载全片风格母图、主角人设卡、道具环境卡（存入 `global_assets/`）；
    3. **逐镜分镜参考底图**：生成九宫格大图并调用 `tools/grid_cropper.py` 自动切为单镜底图（`shots/shot_01.png` ~ `shot_NN.png`）；
  - **环节三【26Flow 直通工作流装配】**：调用 `tools/assemble_pipeline_pipeline_flow.py` 自动组装为 37 节点无悬空、三层参考网直通的画布 JSON；
  - **环节四【本地画布调试与成片合流】**：启动本地 MuseFlow 服务（`http://127.0.0.1:8788/`），支持单镜 1~4 张候选图挑选、尾帧连续锁图生视频、并通过 FFmpeg 一键拼接导出最终长视频。

## ⚡ 核心执行规范与三大铁律

### 🚫 铁律一：无字风格矩阵强阻断 (Hard Visual Gate)
1. 收到文本分镜后，**严禁直接全量生图或跳步装配**；
2. 必须先为用户生成 3 张符合中国主流大众审美（如：东方温润3D手办水彩、央视纪录片真实微距、中式现代科技图解）的**纯视觉无文字风格参考板**；
3. **强制停机挂起（WAITING_USER）**：调用 `request_user_input` 弹窗让用户选定风格序号。用户未定前，绝对严禁启动后续底图制作。

### ⚖️ 铁律二：双轨参考图共存与三层直通网 (Dual-Track Reference Assets)
1. **全局母卡（轨一，x=80 列）**：1~4 张全局基准大图（全片画风、主角人设、道具卡），负责全片统一画风；
2. **逐镜分镜底图（轨二，x=580 列）**：必须一一对应具备 `shot_01.png` ~ `shot_NN.png`，作为图生视频起手首帧（Image 1）；
3. **三层参考直通**：
   - 第一层：本镜分镜底图 ──> 视频参考端口（首帧参考，100% 直通）；
   - 第二层：全局风格母图 ──> 全片所有视频参考端口（全景画风锁，100% 覆盖）；
   - 第三层：语义精准匹配主角/道具母卡 ──> 对应镜头参考端口。

### 📐 铁律三：零端口悬空与时间线强锁序 (Zero Floating Ports & Locked Timeline)
1. 装配出的 26Flow JSON 中所有节点连线 100% 贯通，禁止留下孤立未连接端口；
2. 时间线 `clipOrder` 强制按 `01 ➔ 02 ➔ ... ➔ NN` 严格升序绑定；
3. 每个镜头默认生成 10 秒原片，成片剪辑时长写入 `editDuration`，防止被粗暴截断。

## 🛠️ 标准操作流水线 (Step-by-Step SOP)

### 步骤 1：文本分镜标准化吸纳
调用命令：
```bash
python tools/adapt_storyboard.py "用户输入的分镜文件路径或文本" -o storyboard.json -a 9:16
```

### 步骤 2：视觉风格探索与用户确认
向用户展示 3 张无字风格参考图，弹窗询问：
> “请选择本次视频的视觉风格基调：【1】东方温润3D动画 【2】央视真实微距纪实 【3】清爽中式科技图解”

### 步骤 3：全局母图与九宫格切片底图制作
用户选定风格后：
1. 生产全局风格母图与角色道具母图，保存至 `global_assets/`；
2. 生产九宫格分镜大图，执行自动切图：
```bash
python tools/grid_cropper.py "九宫格图片路径" -o "./shots" --crop-bottom 0.06
```

### 步骤 4：一键编译 26Flow 直通工作流
```bash
python tools/assemble_pipeline_pipeline_flow.py -b storyboard.json -s ./shots -g ./global_assets -o final_26flow_workflow.json -a 9:16
```

### 步骤 5：启动本地画布与成片合流
```bash
cd museflow-local-service && python server.py --port 8788
```
引导用户在 `http://127.0.0.1:8788/` 画布中导入 `final_26flow_workflow.json` 进行单镜多候选图调优或一键合流导出 MP4。
