# 中文转录噪声判定规则

| 类别 | 典型表现 | 处理 | 禁止事项 |
| --- | --- | --- | --- |
| 口头填充 | “嗯、然后、这个、对吧” | 删除或合并 | 不要删除语义转折 |
| 自我修正 | “不是 A，是 B” | 保留最终明确说法，必要时记录修正 | 不要只保留第一版 |
| 重复强调 | 同一结论连续说两遍 | 合并，保留强调含义 | 不要把强调当新结论 |
| ASR 术语错 | 品牌、模型、英文名近音 | 原文 + 疑似词 + 证据，标 `待确认` | 不要用常识替换 |
| 数字/单位错 | 百分比、日期、时长、版本号 | 回看原音频/画面；无法核实就标注 | 不要四舍五入或编造 |
| 课堂旁支 | 招聘、设备、闲聊、临时问答 | 移到旁支；与方法无关则不进入主笔记 | 不要让旁支改变课程主线 |
| 例子与结论混淆 | “比如”后面出现个案 | 标为案例，提炼可迁移条件 | 不要把个案当普遍规律 |
| 推测性观点 | “我觉得、可能、应该” | 保留语气并标课程观点 | 不要升级成事实 |
| 外部补充 | 模型/法规/产品的当前状态 | 单独标 `实操延伸`，查权威来源并附日期 | 不要伪装成课程内容 |

## 待确认项格式

```text
【待确认：原文“Open low”｜疑似“OpenAI …”｜缺少清晰音频/画面证据】[P03 12:40]
```

若后续通过原音频、截图或权威资料确认，保留原记录，并在旁边添加“确认依据”和确认日期；不要删除审计痕迹。
