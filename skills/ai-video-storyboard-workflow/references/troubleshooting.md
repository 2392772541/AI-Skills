# 故障排查与运行期守护机制 (Troubleshooting & Protection)

## 1. 晚到结果隔离（Late Result Discarding）
- **问题**：网络波动或慢速任务可能导致上一轮取消的请求在数分钟后返回，直接冲刷当前最新节点。
- **保护**：每个节点每次触发分配独立的 `activeRunToken`；若返回时的 token 与当前节点 token 不一致，前端强制抛弃晚到数据，保护当前版本安全。

## 2. 场景被拒（SCENE_REFUSED）自动降级重试
- **问题**：云端 Muse.ai 或敏感词拦截可能拒绝生成极端化学或农业微观词汇。
- **保护**：系统捕获 `SCENE_REFUSED` 错误码后，自动启动“合规等价转换重试”（Safe Equivalent Retry），在保留镜头戏剧目的前提下微调措辞，最大化出片率。

## 3. 内存与显存保护原则
- 本地服务（`server.py`）严格遵循轻量化原则，纯静态托管与代理开销小于 50MB 内存。
- 视频生成优先借助云端 Muse.ai 或专用 API 桥接，避免本地 GPU 爆显存导致整个操作系统死机或卡死其他任务。
