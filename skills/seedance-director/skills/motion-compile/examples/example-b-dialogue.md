【全局设定】

时代与世界：1937 年江南县城，画面中不得出现电灯开关、塑料制品与现代服饰。
场域锚句（当铺柜台内景）：柜台是齐胸的黑漆木栅，柜面压着深棕绒布；侧墙钉着一张熏黄卷角的旧月份牌，墙角立着一只蒙着灰布的老式立柜。
出场人物：周掌柜（五十八岁当铺掌柜，灰布长衫黑马甲）；沈军官（三十二岁军官，褪色土黄呢军装）。

声音基调：环境底只有柜台后座钟的缓慢滴答与街面隐约的风声，无背景音乐。

【分镜正文】
镜头1：双人中景建立，柜台侧面机位，固定镜头，47° 标准镜头性格、机位距柜台 3–5 米、自然人眼透视无可见畸变、背景格架可读但不夸张：军官立于柜外画左，双手把一只翡翠玉镯搁上柜台绒布，玉石与绒布压出一声几乎听不见的闷响；掌柜立于柜内画右，垂眼看镯，右手搭在算盘上没动。
镜头2：从掌柜肩后拍军官，近景，静止，视线匹配切入，29° 短长焦人像性格、机位距军官 4–6 米、紧凑取景靠镜头拉近而非机身贴近、军官锐利如刻、格架压近他身后化成奶油般柔化的焦外：军官下颌绷紧，视线钉在掌柜脸上，"这镯子，能当多少？"（声音压得平直，尾音发紧；声线：年轻男声，音区偏低，吐字利落如报数，藏着沙哑）。掌柜的圆肩在前景虚化。
镜头3：反打，从军官肩后拍掌柜，近景，静止，29° 同档不换性格、机位距掌柜 4–6 米、掌柜锐利、身后格架压平柔成焦外、军官肩线在前景熔成柔软暗影：掌柜没有立刻答话，先有一个可见的微停顿——他抬眼、目光落在镯身一道旧磕痕上，瞳孔轻轻一缩，捻着顶针的拇指停住了。
镜头4：掌柜手部特写，插入切，俯角静止，29° 短长焦细节档、机位距柜面 2–3 米靠镜头拉近取景、指节与镯身锐利如刻、绒布纤维出焦点即柔化、柜台纵深压成一片柔暗：粗大的指节把玉镯往军官的方向轻轻推回半寸，镯身滑过绒布发出细微的沙沙声，随即定住；本镜一拍即过，是全条最短的一镜。
镜头5：反打回军官近景，从掌柜肩后拍，承接上镜余冲，29° 同档、光学与镜头2 完全一致、无滑档：军官的视线从镯子猛地抬回掌柜脸上，眉心拧起，"你只管开价。"（一字一顿，音量没升、力道在齿间；声线同前）。
镜头6：掌柜近景，从军官肩后拍，静止，29° 同档、与镜头3 一致：掌柜缓缓摇头，声音放得很低，"长官，这镯子——不当为好。"（先顿半拍再开口，低而软，像劝；声线：苍老浑厚的男声，语速迟缓，带江南口音）。他说话时军官在前景虚化，肩线纹丝不动。
镜头7：军官特写，静止，硬切换档至 18° 经典长焦性格、机位距他 6–8 米、强背景压缩把格架压叠到他身后、刀锋般薄的焦平面只留眼睛与嘴角锐利、前后景一并融成柔软焦外、画面带着从远处观察的距离感：他的表情钉在强撑的体面与哀恸之间；喉结滚动一次，泪膜在下睑缘反光却悬而不落，单侧嘴角短促地扯了一下又压平（是"被人看穿了"的难堪，不是愤怒）；本镜是全条最长的一镜，占全条约三成，情绪在这里停满、比前后任何一镜都久。嚎啕欲哭的脸 = failed take（废镜）；轻松的笑 = failed take；面无表情 = failed take。

【衔接】

【针对性负向】

## 全例总注

为什么这么编：

逐镜过一遍。

- 选轨与定档：双人正反打、台词你来我往——B 轨教科书场景，全条零秒数、按事件顺序排镜；14s 落在对白条 8–15s 档，8 个镜号逐字取自镜头表、本站不增删。正片片型，松档三条一条不中 → 紧档，逐镜编排。镜头表给 8 镜的时长轻重悬殊，落地走配重语言通道——只给最长的镜头7 与最短的镜头4 各一句，其余六镜与均分持平、一个字不写；全条零秒数注释，配重是这条唯一的时长通道。
- 条头上传清单：四行顺序 = 绑定段 @ 首次出现顺序，即角色 → 场景 → 道具，编译时已定，所以号在这里就写死、用户不必替换。看清一件事：项目编号的数字与 @图N 的数字毫无对应关系——掌柜是 char-002 却排在 @图1，军官 char-003 是 @图2，场景 scene-002 是 @图3；号是本条会话里的位置，不是资产的身份，下一条谁先出场谁就是 @图1，绝不抄本条的号。项目编号那一列留给人与下游反查，围栏里一个都不出现；文件列逐字抄 reference-index 的「参考图位置」。清单在围栏外，不进生成框。
- 绑定段：四个地址各恰好一次；两个角色都带行内状态公式，锚点全是后文要用的：顶针 → 镜头3拇指停住；缠纱布的左手 → 军官的窘迫史，画面可见但不展开。道具声明"始终静置、无人拿起"——本条最重要的道具事实，谁都不碰镯子才是这场戏的戏眼；末行"不串脸、不互换身份"是双人条标配。
- 恒定层：通用基准段就四件——媒介质感、色域、光逻辑、镜头性格，"球面镜头、视场克制"这一件把全条钉在同一支球面镜头族里，47° 与 29° 只是同一支镜头的两个视场档，不是换了两种镜头性格；后面跟的画质固定项是恒定层另一件、不并进四件。两样都跨场逐字复用；黑漆木栅柜台、旧月份牌、蒙布立柜这些具体陈设与时代物证住场域锚句，只因为本条发生在当铺柜台内景才带上——同片若有巷子外景条，这一行整行不写，绝不让院子里长出一张柜台。空间地图块逐字注入，实际编译从 03-shots 本场场头的场级块抄——机位侧、轴线、两人与铁皮门/格架这些画面内地标的绑定、frame-left/right 全齐；正反打条不带空间地图，越轴与左右翻转就是抽奖。时代锚 1937 进恒定层。
- 镜头1 · 建立镜：先定位后开戏——谁在画左谁在画右、道具在哪，一镜说死；玉镯上柜台的闷响是音效绑可见动作，也是全场的触发源。
- 镜头2/3 · 第一组正反打：头部三件套齐：镜头N + 一句运镜含衔接方式与光学锚 + 动作；光学锚是逐镜必带的一槽——29° 度数打头，后面跟四条可观测结果：紧凑取景靠镜头拉近、主体锐利、背景压近化成焦外、前景肩线熔成暗影；正反打两镜同档同距，一换档双人就不像在同一间屋里，只写"近景 + 静止"则整条滑向一支舒适中焦。台词嵌在说话者的镜头里、引号直写 + 语气 + 声线锁——本例为虚构声线，实际编译从 reference-index 逐字抄；镜头3是倾听者纪律的示范——掌柜的反应先于回答：微停顿、抬眼、瞳孔缩。答话前的反应拍是对话戏的戏肉，且嘴唇静止。
- 镜头4 · 插入切：手部特写承担本条唯一的"动作事件"推回半寸——动作小而清晰、有终点"随即定住"；不让对话戏的运动预算被大动作抢走。句末"一拍即过，是全条最短的一镜"是配重语言的最短档：镜头表给这一镜的时长明显低于均分，不写这句模型会把它撑成和正反打近景一样长，插入切的利落就没了；写它就绝不再补"约一秒"——那是把秒数偷渡回 B 轨。
- 镜头5/6 · 第二组正反打："承接上镜余冲"写进运镜句，镜间靠动作与视线咬合；掌柜的台词"先顿半拍再开口"把节奏写进语气注释；"军官在前景虚化，肩线纹丝不动"同时交代前景与倾听者静止。
- 镜头7 · 情绪峰值特写：配重语言的最长档落在这一镜——"全条最长的一镜，占全条约三成，情绪在这里停满"；镜头表给它的时长是本条 8 镜里最长的，不写这句，8 镜会被均分成同一个长度，"喉结 → 泪膜 → 嘴角"这三拍会并成一拍，情绪的层次就没了。占比只用成数、不折算成秒。光学在这里硬切换档——18° 强压缩把人从环境里摘出来，是"被观察"这层情绪的物理来源；换档只发生在切镜处，一镜之内绝不滑档。情绪双向夹钳硬性判定句的现场用法——单写"悲伤"会漫画化，夹钳写"钉在强撑的体面与哀恸之间"并用三个"= failed take"封死三个失败方向；微表情全是肌肉级：喉结/泪膜/单侧嘴角；括号情感解析——"被人看穿了"的难堪——只挂这个情绪节点。判定句落位在它保护的镜头里，不是堆进负向段。
- 镜头8 · 结尾镜：回建立镜机位收束 + 状态不变声明"玉镯仍在原处、距离未变"——结尾镜显式声明状态是 B 轨标配，防模型在末镜自作主张收东西、挪道具。
- 结束状态与衔接：双人条的五字段覆盖两名角色；收束选接续态——这场戏没完，下一条继续对峙——故末镜不定格、靠座钟声把张力带过接缝。
- 负向与尾缀：症状负向两项全是对话戏专项：越轴/口型错配 + 倾听者嘴唇静止，化进散文；尾缀固定五项——对话戏附加项没重复挂，因为第 7 段已点名，不重复计数。
