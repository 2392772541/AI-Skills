# 空间地图母版

## 使用说明

空间地图两层制的全部母版。底版是场景级、不含人物，由 scene-design 随场景板产出，写进 04-assets/scenes-prompts.md 该场景段；场级实例即空间地图块，由 shot-design 随各场落表装载 blocking 实例化，落 03-shots/epNN-shots.md 本场场头——canonical 路径、禁止变体拼写；control-image 站位图与 motion-compile 恒定层一律从该场头取，按 [按条裁剪] 裁完贴进本条的【全局设定｜恒定层】，多人/复杂场必带。字段形态的唯一母版是 [空间地图块母版] 一节，别处只许照抄、改字段只来这里改。两个地图母版都不是生成提示词，是供动态提示词逐字引用的文本块，各占一个围栏；末节的俯视人用规划图母版才是生成条，只喂图、勿投喂进视频。

## 为什么是文本块

米数对模型无意义，"在主角左边"更无意义——空间要用三样东西说：镜头在哪一侧、180° 线在哪、每个人绑定到板内可见地标，方位用 frame-left/frame-right（画面左/画面右）表述。空间事实贴进该场每一条，模型每条都重新读到同一套空间事实，这是"模型无记忆"约束下跨条空间一致的实现方式。

## 空间地图底版母版

非生成提示词 · 场景级文本块，scene-design 出，一场景一份，只记几何事实、不含人物，供场级实例、同场景各角度板与登记块取用。「几何关系」一栏是同场景多张板共享几何的唯一真相源——凡在两张以上板里入画的结构，其相对关系在此定死一句、各板逐字取用，对账方法见 ../references/angle-coverage.md [判据卡 · 多板共享几何对账]。

```
【空间地图底版｜scene-{{NNN}} {{场景名}}】
    锚点索引：{{逐个列：与场景板提示词、登记块同名的锚点名 + 在空间中的位置 + 可见特征，如：霓虹「乐园」招牌——吧台后墙上方，品红色}}
    几何关系：{{锚点与结构之间的相对方位与距离量级，用可测量语言：贴着/相隔一张球台的台面宽度/靠墙，不用 near/beside（附近/旁边）类弱词；跨板共享的结构逐项写死一句，含下游动作要落到的接触面与开口位置，如：递物窄口的下沿自柜台面外缘切进、窄口正下方无栅条}}
    出入口：{{每个出入口的位置 + 朝向，如：大门在吧台对侧，向街开}}
    光向：{{主光源 + 方向，与场景板光逻辑一致，如：主光为球台上方白炽吊灯直下，门口补霓虹青绿侧光}}
    已有角度板与其机位侧：{{逐张列：scene-NNN 主板 = 从大门内侧看向吧台角；-a2 = 从球台短边看向吧台……——场级实例声明机位侧时从这里选}}
```

## 空间地图块母版

非生成提示词 · 供动态提示词逐字引用。全库唯一的块母版，字段名、字段序与七行形态定稿在此——shot-design 的镜头表母版、control-image 与 motion-compile 的消费端说明、三份标杆里的块，一律是本节的只读副本，逐字同形。

块分两截：上截七行是**空间事实行**，进围栏；下截**编译期注记**只给作者与编译者看，另起一段、不套围栏，不进任何条。划界判据见 [事实行与编译期注记]。场头写的永远是全场版，进条那一刻按 [按条裁剪] 裁。

```
【空间地图｜{{epNN}}-s{{XX}} · {{场景名}}（scene-{{NNN}}）】
    机位侧：镜头全程位于{{以锚点表述的一侧，如：球台的吧台一侧}}；frame 方位以此为准。
    轴线：180° 线 = {{两个主体的对视连线/运动方向线，如：年轻人与吧台边中年男人的对视连线}}；镜头全程守轴、不越过此线。
    地标绑定——板内可见地标为{{自底版锚点索引里挑本场入画的逐项列出，如：球台横贯画面中段、吧台沿右侧墙、霓虹「乐园」招牌在吧台后墙上方、临街玻璃大门在球台短边对侧}}：
        {{可视特征代称}}：{{位置 = 贴着哪个锚点 + 身体朝向 + 视线对象，如：站在球台短边、贴着台角，背对霓虹「乐园」招牌，躯干朝向吧台，视线锁在高脚凳上的中年男人脸上}}
        {{可视特征代称}}：{{同上；每人一行}}
    frame 方位：{{谁居 frame-left、谁居 frame-right，两人间距用框内参照物计量，如：隔一张球台的台面宽度}}
    可见范围：本场只用{{空间的哪一角，如：球台—吧台一角}}，不展示整个空间。
    排布变化：{{全场版逐项列，每项前缀「条 {{N}} 镜 {{M}}」：谁从哪个地标移到哪个地标、其余人是否原位；有合法越轴的项写明经哪条合法路径越、此后方位词按新轴。全场无变化则整行写「全场不变」}}
    重述规则：每次切镜后，用一句话重述谁在哪、面向哪、看着什么。
```

编译期注记 · 紧跟在场头块下方，写成普通行，不套围栏、不缩进、不进任何条：

**【编译期注记｜{{epNN}}-s{{XX}}】**
- 写法约束：人物每人一行、写可视特征代称，不写人名、不带 @编号；禁 near/beside 类弱词，用可测量语言；身体朝向与视线分开写。
- 条镜索引：{{逐项列排布变化与越轴落在哪一条哪一镜——供 shot-design 排镜、control-image 定站位图、编译时按条裁剪对照}}
- 版本与理由：{{v{{N}} · 因{{阵型变化/底版修订}}重实例化；旧版不就地改写}}
- 待办：{{如「机位侧待 scene-NNN-a3 出板后复核」，无则删本行}}

## 事实行与编译期注记

划界判据一句：**这一行删掉，模型会不会把画面画错？** 会 → 空间事实行，进围栏；不会——它只影响作者怎么填、编译者去哪找 → 编译期注记，不进围栏。
按此判，七行全是事实行；填写要求、条镜索引、版本与理由、待办全是注记。母版里那些「每人一行」「禁弱词」式的填写要求是写给作者的，一旦留在围栏里就会被逐字焊进本场每一条——那是元指令进了提示词，模型只会把它当噪声或当画面内容。
注记写成普通行：套围栏会被整块搬走，四空格缩进块在 markdown 里同样渲染成代码块、一样会被整块复制走。

## 按条裁剪

场头块是全场版；进条前按本条裁一次，只做两个法定删除动作，除删除外一个字不许增、不许改写：

1. **删非本条在场者**：地标绑定下的人物行，本条不出场的整行删；删到 frame 方位行只剩一人时，该行整行删——一个人没有相对方位可言。本条无人物出场，即纯空镜、纯物件特写，人物行、frame 方位、排布变化三处一并删空，机位侧/轴线/地标清单/可见范围/重述规则照贴。
2. **删不落在本条的条镜项**：排布变化逐项看，非本条的整项删；保留项删掉「条 {{N}}」前缀，只留「镜 {{M}}」——镜号是条内编号，跨条无意义，围栏里出现别条的镜号即噪声。本条内一项不剩时，整行写母版固定句「本条内排布不变」——这是母版给的唯一替代文本，不许自拟。

放行判据，逐条自问：
- 删掉的每一项，在本条正文与本条条头【上传清单】里是否零出现？出现即不许删。
- 保留的每一项，是否与场头版逐字相同？改一个同义词就是扩大采样范围。
- 机位侧、轴线、板内可见地标清单、可见范围、重述规则五处，跨本场每一条是否逐字一致？这五处是场级恒定量，条间出现差异即错——差异只允许出现在人物行、frame 方位、排布变化三处。
裁剪发生在取用那一刻，场头版本不因裁剪改动；裁不动的场面——本条人物与全场一致、无排布变化——裁完就等于全场版，正常。

## 实例化规则

- 越轴写进「排布变化」，不另设行、不再挂在「轴线」上：越轴总带着镜号、只落在某一条，挂在场级恒定的「轴线」行上会让那一行跨条不一致；四条合法路径与判据见 blocking 的 axis-and-coverage.md [判据卡 · 越轴的四条合法路径]，此处只记哪一镜经哪条路径越、此后方位词按新轴。
- 机位侧从已有板里选：场级块声明的机位侧必须对应一张已有角度板，或已列入取角清单——声明了一个没板的机位侧，等于让模型凭空编那一侧的世界。
- 静态对话给一角：地图只圈空间的一角，不给整个房间——范围越小，模型越稳。
- 弱空间词禁令——完整禁令表在 blocking 的 spatial-language.md [判据卡 · 弱空间词禁令]，此处内联最低要求：near、around、beside、nearby（附近/周围/旁边）不用，换可测量语言：贴着、相隔{{框内参照物}}、背靠{{锚点}}、在{{锚点}}与{{锚点}}之间。
- 身体朝向与视线分开写：躯干朝向是一件事、眼睛看哪是另一件事，各写各的。
- 人物变了就重实例化：同一场景不同场——人物、站位不同——底版复用、场级块各自实例化；同场内场头版本逐字不变，人物换位、阵型变了由 shot-design 出新版本块并标版本，不在提示词里就地改写。

## 俯视人用规划图母版

可选产物，出图只给人看、勿投喂进视频。下面两行是落盘文件内的元信息行，不进生成框、不进围栏：

> 人用规划 · 勿投喂：本图仅供规划走位、核对机位侧与 180° 线，不作任何生成参考帧，不进任何条的条头【上传清单】、不得被【参考资产绑定】段 @。编号 scene-{{NNN}}-plan，不占角度板序列。

条头：## scene-{{NNN}}-plan {{场景名}}俯视规划图（人用）

生成条 · 图像规则集，整块投喂即梦平台文生图：

```
极简俯视平面示意图，白底细线：{{空间轮廓与主结构，如：矩形厅面，中央一张球台，右侧沿墙吧台}}，标出{{逐项：与底版同名的锚点位置、出入口、主光源方向箭头}}。图上不出现人物、不出现文字标注——位置说明全部留在本提示词与底版文字里，人对照着读。
{{可选：拟规划的走位用一条虚线路径示意，起点在{{锚点}}、终点在{{锚点}}；不需要则删}}
```

## 自检

- [ ] 底版锚点与场景板提示词、登记块三处同名同位；跨板共享的结构在「几何关系」里各定死一句，各板逐字取用。
- [ ] 场级块的机位侧对应一张已有角度板或已列入取角清单。
- [ ] 地标绑定每人一行、人物写可视特征代称不带 @编号、无弱空间词、朝向与视线分开写。
- [ ] frame 方位与间距用框内参照物计量，无米数、无"在他左边"。
- [ ] 场头版七行齐全、字段序与本卡母版逐字同形；排布变化与重述规则两行不省。
- [ ] 填写要求、条镜索引、版本与待办全在围栏外的编译期注记里，围栏内零元指令。
- [ ] 进条的块按 [按条裁剪] 裁过：无非本条人物、无别条镜号、场级恒定五处跨条逐字一致。
- [ ] 俯视图若出，围栏外带「人用规划 · 勿投喂」标注、编号 -plan、图上无文字标注。
