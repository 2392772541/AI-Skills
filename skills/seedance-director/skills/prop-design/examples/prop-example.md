# 标杆道具包 · 《雾河》煤油提灯 prop-001（两状态分立 + 载具判例 + 登记块）

## 示例定位

虚构短片《雾河》的道具建档标杆：一件功能道具——煤油提灯，两状态分立 + 状态时序；一组载具分立判例——渡船外观与舱内两件资产；一条不收判例与去向注记；登记块。写实向项目。每条后附「为什么这么编」。

本例的通用基准段是示意——实际产出逐字照搬 00-bible/visual-style.md 的通用基准段，媒介质感 / 色域 / 光逻辑 / 镜头性格四件，角色/场景/道具三方同一段、一字不差。它是场域中立的：全片通用，不含任何具体房间陈设——道具板是中性浅灰空场，年代由这件东西自身的形制与工艺承担，承载陈设与时代物证的场域锚句只进场景板与该场域的条。

## 四视条 · prop-001 · 煤油提灯（核心，收录级 A，首登场 ep01 场03）——生成条

```
写实电影质感，低饱和青灰打底、暖黄灯光作唯一强调色且必须来自画面内真实光源物，柔和散射光交代质感与体积，胶片颗粒细腻、写实克制；球面镜头，构图安静克制。道具定妆设定图，纯净中性浅灰无缝背景，画面中除道具与比例手掌外空无一物，柔和均匀软光，画面水平排列同一件道具的四个视图：细节特写、正面、侧面、背面，旁附一只摊开的手掌作比例参照、不接触道具。四视必须是同一件，材质、配色、磨损、尺寸比例完全一致。道具是一盏老式手提煤油灯，熄灭状态。灯座与提梁为黄铜铸件，铜色深暗、棱角被常年提握摩挲得发亮，座身有一道浅浅的凹瘪；玻璃灯罩鼓腹收口，内壁积着一层薄薄的黑色油烟垢，罩身有一道细小的横向裂纹；棉质灯芯焦黑，旋钮是滚花黄铜、花纹被磨平了一半。通高约三十厘米，比摊开的手掌高出一倍半。细节特写格放大灯座正面的凹瘪与旋钮磨平的滚花，让下游引用时对得准。
```

为什么这么编：

开头逐字嵌通用基准段——四件内容、场域中立；版式句一遍 + 「四视同一件」复述一遍——双保险，不复述会画成四件。版式句写死「除道具与比例手掌外空无一物」，后面不接场域锚句：这盏灯要在船舱、码头、当铺各处入镜，板上多留一张柜台，它到哪都拖着那张柜台。材质四项各自落到可辨识：材质具名到工艺，黄铜铸件、滚花旋钮；年代磨损写「怎么显出来的」，摩挲发亮、油烟垢、磨平的滚花，真实表面语言抗渲染感——年代形制取自 visual-style「时代与世界锚」的年份/地理与器物形制，写的是这盏灯自己的形制工艺，不自拟、也不搬它平时摆在哪间屋子；尺寸给真实数值 + 手掌比较，即尺度三重锚定的资产侧半边。特写选位挑「凹瘪 + 磨平滚花」——恒定且不可复制的部位，不选会随点亮改变的灯罩内壁。明确写「熄灭状态」——点亮是另一件资产，不写成「可点亮的灯」让模型抽签。主体描述净量约 130 词。

## 状态时序段 · prop-001 密版附加段

    状态时序——文字资产，只进密版，供动态提示词写穷尽动作：
        阶段 1：拇指逆时针拧开滚花旋钮半圈 → 灯芯升起约半厘米，焦黑芯头露出；
        阶段 2：火柴凑近芯头点燃 → 火苗先蓝后黄、跳动两三下站稳，玻璃罩内壁映出暖橙光晕；
        阶段 3：旋钮回拧四分之一圈 → 火苗收稳成拇指高的定焰，灯罩裂纹处透出一线更亮的光。
        其中会持续入镜的稳定状态：阶段 3 定焰态已升格为变体资产 prop-001-v1（点亮）。

为什么这么编：

功能道具必写时序，这是易漏项——每阶段都是「触发动作 → 可见状态」，动作落到部位如拇指逆时针半圈、状态落到可见证据如先蓝后黄与裂纹透光，motion-compile 写穷尽动作时逐阶段有据可依。时序住密版不进动态提示词成品；跨条持续的点亮态另升格出图——时序管过程描述，变体管稳定状态长相，两层不互相替代。

## 变体条 · prop-001-v1 · （点亮）（← prop-001）——编辑条（基于原版四视成图）

```
编辑这张图：把煤油灯改为点亮状态。
改动：唯一变化是「亮」——玻璃罩内出现一簇拇指高的稳定黄色定焰，罩内壁映出暖橙光晕，罩身裂纹处透出一线更亮的光，灯座朝向灯罩的一侧铜面泛起微弱暖反光。
严格保留：灯的全部结构与材质细节——凹瘪、油烟垢、裂纹位置、磨平的滚花旋钮，四视版式、手掌比例参照与灯-手掌尺寸关系、背景、光线基调、构图、调色与颗粒。
只改点亮状态，其余 100% 不变。
```

密版增量：

    罩内定焰 + 内壁光晕 + 裂纹透光 + 座身微反光，其余同 prop-001。

为什么这么编：

点亮跨条持续 → 过状态分立判据建变体，而非在一件资产里写「可点亮」。做法是手术式编辑原版四视——底图保持同一批像素，凹瘪与滚花这些辨识锚不重掷；道具附加规则全落实：PRESERVE 含手掌比例与尺寸关系，防道具悄悄变大；「亮」拆成四个可见证据而非一个形容词。编号 -v1、语义标签（点亮）、谱系登记，熄灭原版永不覆盖。

## 载具分立判例 · prop-002 渡船外观与 prop-003 渡船舱内——两件资产、两个主编号

    prop-002 · 渡船外观（核心，收录级 A）——生成条。正文略，套四视条母版：木壳机动渡船，全长约八米……细节特写格放大船头挡板的褪色红漆船名「雾河 07」与漆下木纹。
    prop-003 · 渡船舱内（核心，收录级 A）——生成条。正文略，套四视条母版变体：舱内以三四分之三视角出正/侧两向 + 细节特写舵轮与磨亮的木质扶手……

为什么这么编：

车前后内饰分开各成资产的判例——外观是「一台船」，舱内是「一个被拍摄的空间物」，同图必两头糊。两件是主编号并列不是父子变体：它们会同时存在于不同镜头，无谱系关系。船名帧内文字走第一档——船号是剧情认得出这条船的凭据、内容承重，给引号内精确文案「雾河 07」，不让模型编字；同一件上舵轮座那圈厂牌模印走第二档——只要「看得出有字」，写成「一圈模印小字，笔画被油污与磨损挤压到难以逐字分辨」的正向不可辨认态，既不写「不可读」，也不替它编一个厂名。舱内这类空间型道具的视图数可按需减为「特写 + 两向」，同一件复述、比例参照、中性底的版式原则不变。

## 不收判例与去向注记

    码头货摊的搪瓷缸一排：不入库，归 scene-002 码头晨市的陈设描述，scene-design 承接。
    老周的旱烟杆：B 级纯文字登记，见登记块 @prop-004（无图）——单场持握、无特写；若后续集反复出现则升 A 补四视，编号沿用。

为什么这么编：

搪瓷缸没人拿、没特写、不变化 = C 级，但去向注记必须留——否则资产审审到「拆解清单有、哪儿都找不到」的悬空项。烟杆被持握——手空铁律要求角色表手空着、拿的东西必须有着落——但风险中等 = B 级纯文字登记，附升级条款。
