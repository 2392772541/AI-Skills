# 剧本拆解母版

## 使用说明

按此母版生成结构完整、可被下游各站与拆解审对账的 epNN-breakdown.md。采集到的信息照填；没采集到、又不能从剧本稳妥推断的，标 [待确认]，不凭空补。字段名和 ID 口径不要改，下游靠它们引用。轻装档项目按内容取块：三张清单可并成一张带「类型」列的简表、接缝卡并入条尾一行，用不到的块整块删——结构服务内容，不为格式凑字。时长数字全部是预算区间——真相源在 references/duration-pacing.md，标注待实测校准。

## 写作要点

1. 单位口径：场 = 叙事单位与循环粒度，场号跟剧本场头走；条 = 生成单元 = 一条提示词，2.5 上限 30s、容量非必须填满、一场 ≈ 2–5 条；镜头 = 条内分镜，数量归 shot-design、本文档只预估。条的划分是本文档独占真相源。
2. 上游对账区只记指针与版本，不复制蓝图/基准正文——一个信息只住它的真相源。
3. 概览表让下游 O(1) 定位；"一句话场目的"不许用"并且/然后/同时"——用得上就说明该拆。
4. 每条：先节奏意图，再数拍，气口单独预算，时长落预算区间——数字真相源在 duration-pacing，全表待实测校准；具名主体逐个列名、≤5，镜尾二态标清，条间接缝卡齐全；缝上有省略的，下条要用的画面物证逐件指到上游条的落点。
5. 条阐述全用可拍的物理动作和具体光影；声音线索——台词引号、音效绑动作、环境声、音乐意向——就地写进散文，最终全部编译进动态提示词文字；群演外观写死在阐述里。
6. 高光条落逐拍骨架：含 hold 拍的顺序清单、零时间戳；非高光条维持散文，判据是密度落差不是题材。
7. 三张清单：入表标准筛过；每项核心/边角 + 三态；复用/变体对 reference-index 既有编号；新资产不在此分配编号，设计站登记时分配。
8. 生成注记只转不改，先定去向、再定层级。去向：shot-design/motion-compile/sound-writing/review 的进生成注记栏，三个设计站的进对应清单附注，script-breakdown 自己的当场执行掉不留栏。层级按辖域定，一条只住一栏、不逐场重抄：辖域跨场的住第 1 节集级栏并点名辖域场次，辖域覆盖本场全部条的住场头场级栏，只管一条的住该条栏——跨场注记只落一场场头，编译另一场就拿到空指针。逐字转，不概括不合并；一条都不许落地失踪。
9. ID 稳定：场 sXX、条 sXX-cN 补零连续、不跳号、不复用、不改指向；迭代插条用 c2a。
10. 完成度用自包含测试：不靠脑中剧本记忆，光凭本文档下游能直接动手。
