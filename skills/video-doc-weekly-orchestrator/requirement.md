# Skill 需求单

- 名称：video-doc-weekly-orchestrator
- 用户角色：每周维护且曼/水球泡周报的内容运营者
- 真实问题：每周重复提醒联网补链、来源归属、截图证据、飞书目录和重复文档清理；修复没有沉淀成下周的硬门禁。
- 使用频率：每周一次，偶尔同周返工
- 当前流程：视频 OCR -> 人工找缺链 -> 多平台搜索 -> 补截图 -> 生成 XML -> 写入飞书 -> 手工发现位置/重复文档问题
- 输入：本周视频、源截图、目标飞书目录
- 输出：一个本周终稿 docx、完整本地审计包、问题账本更新、线上目录/内容验证
- 自动化边界：本地解析和确定性门禁自动化；来源归属、模糊标题和删除操作保留人工/用户确认边界
- 必须保留的规则：源帧所有权、深度联网检索、短抖音拒绝、截图 fallback、目标目录预检、重复文档 guard、发布后回读
- 成功标准：本地门禁通过；线上 revision 和 folder token 可核验；目标目录只有一个当前周终稿；每张 fallback 图位于所属条目下
- 失败与恢复：记录 issue ledger；可从当前周 report、Feishu token 和维护副本恢复；不删除未确认对象
- 依赖工具：video-doc-weekly-ocr、agent-reach、lark-doc、lark-drive、lark-cli
- 典型请求示例：每周用这两个视频做周报，自动补全所有链接，放到水球泡周报，记住上周的问题
- 不应触发的请求：只总结会议录音；只改一个飞书错别字；只查一个网页
