# 平台与参考资产适配

本包是提示词与制作流程，不内置模型通道。先记录“平台入口 + 实际模型 + 生成模式”；同名模型的网页端、第三方入口和接口可能有不同限制。

## 能力记录

记录是否已核实，以及单条时长上限、参考图数上限、多视图支持、时间戳支持、绑定语法和声音方式。未知写 null/未知，不能拿来源包参数当所有平台硬上限。沿用当前会话已核实资料，不必每镜联网。

无法核实且不妨碍设计时，先交平台无关分镜和草稿提示词。未确定上传语法或资产路径时，明确标“待绑定”，不能把 `@char-001` 项目编号冒充平台令牌。

## 三种输入各司其职

- 角色参考：身份、体型、装束；注明不复制其背景与中性布光。
- 场景参考：空间、材质、氛围；不默认固定所有镜头构图。
- 分镜/关键帧：构图、站位、时间进程；不能代替角色身份参考。

三格人物板适合汇总，独立面部与全身图便于按任务投喂；具体选择要实测。九宫格预览不等于九个镜头已经被精确执行。需精确构图时优先考虑平台支持的独立关键帧，并标明仍待生成验证。

## 编译交付

每个生成单元先列上传清单：项目资产 ID、真实文件或待生成状态、用途、对应角色/变体、平台令牌。按实际上传顺序建立令牌映射，保证一图一职责，不引用未上传的编号。

提供简洁自包含的图像或视频提示词：主体及参考职责 → 当前事件与动作 → 必要空间 → 风格与光线 → 镜头组织 → 声音。保留用户要求的声音制作方式，允许后期添加。图像和视频分别按工具规定写参数与负向提示，不使用跨模型通用禁令。

只写文本不生成时，角色图可以全部“待生成”，仍可交试用文本，但审核结论必须是“文字方案完成，视觉一致性未验证”。需要可直接上传的成品时，待生成图片和待确认绑定不能通过就绪检查。
