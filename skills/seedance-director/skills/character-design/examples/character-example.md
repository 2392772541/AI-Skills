# 标杆角色包 · 《雾河》老周 char-001（完整包 + 状态变体 + 群演 + 登记块）

## 示例定位

虚构短片《雾河》的核心角色「老周」完整提示词包 + 一个状态变体 + 一个群演资产 + 登记块。写实向项目。每条后附「为什么这么编」。

本例的通用基准段是示意——实际产出逐字照搬 00-bible/visual-style.md 的通用基准段，媒介质感 / 色域 / 光逻辑 / 镜头性格四件，角色/场景/道具三方同一段、一字不差。它是场域中立的：全片通用，不含任何具体房间陈设——角色板是中灰底空场，时代由服装形制承担，承载陈设与时代物证的场域锚句只进场景板与该场域的条。

## 角色包 · char-001 · 老周（核心，首登场 ep01 场01）

### G1 大特写 · 不笑（校验锚）——生成条

```
写实电影质感，低饱和青灰打底、暖黄灯光作唯一强调色且必须来自画面内真实光源物，柔和散射光交代质感与体积，胶片颗粒细腻、写实克制；球面镜头，构图安静克制。角色定妆特写照，三四分之三视角头肩构图，纯中灰色无缝背景，画面中除人物外空无一物，柔和均匀的定向光从一侧打来，影调过渡自然。这是六十岁上下的中国南方男性，常年在江面讨生活的渡船人，偏暖的深小麦色皮肤，被江风磨出粗粝质感，颧骨和鼻梁上有深浅不一的晒斑，保留真实的微细毛孔与肌肤纹理。窄长的单眼皮眼睛、眉骨低平，鼻梁高而带一处旧断痕，嘴唇薄且下唇干裂，下颌松弛、颌角有花白胡茬。眼神浑浊却定，像看惯了涨水与退水的旧码头石桩，底下压着一层化不开的倦意。花白的板寸头，发茬硬而稀疏，鬓角灰白杂黑，额前无碎发。表情平静不带笑意，嘴唇自然闭合，双眼看向镜头方向。
```

为什么这么编：

开头逐字嵌通用基准段——四件内容、场域中立，是跨资产画风唯一锚；紧跟版式句——三四分之三视角/中灰底/软光/除人物外空无一物，studio、顶光灯具、边缘光三个雷词全部用正向描述替代。基准段后面不接场域锚句：版式句刚说完空无一物，再补一句「一间当铺，柜台是齐胸的黑漆木栅」，模型两头取平均，这个人从此拖着一间屋子进每个场景。人物描述只取七维中头部相关四维：定位；肤色，挂官方保真后缀；面部，断痕鼻梁等 4 点正是日后 G1 成图对照密版的核对点；眼神，形容词 + 石桩比喻 + 倦意；发型。体型服装不进特写条。主体描述净量约 140 词，散文不堆词。「不笑、闭唇」写死——这是默认锚版，笑版另出。

### G2 大特写 · 笑版——编辑条（基于 G1 成图）

```
编辑这张图：让人物露出克制的笑容。
改动：仅嘴部与眼周——嘴角向两侧微抬，露出上排牙齿，牙齿黄而齐整、有真实牙渍，眼角挤出鱼尾纹，眼神放松。
严格保留：五官、脸型、肤质、发型、光线、背景、构图、调色与颗粒，全部与原图一致。
只改笑容，其余 100% 不变。
```

为什么这么编：

笑版是编辑不是重生成——重生成整张会让脸微漂、肤质重掷。牙齿写到「黄而齐整、有真实牙渍」是这条的全部意义：不做笑版，角色第一次笑时牙齿是别人的。CHANGE 只有一件事——笑；PRESERVE 穷举到调色与颗粒；结构化改动块只在编辑条合法。

### G3 三格角色表——生成条（以 G1 成图为参考图，表中特写格 = G1 的脸）

```
写实电影质感，低饱和青灰打底、暖黄灯光作唯一强调色且必须来自画面内真实光源物，柔和散射光交代质感与体积，胶片颗粒细腻、写实克制；球面镜头，构图安静克制。角色定妆设定图，纯中灰色无缝背景，画面中除人物外空无一物，柔和均匀的定向光从一侧打来。画面水平排列同一个人的三个视图：左格是三四分之三视角的头肩大特写、表情平静不带笑意；中格是正面全身、画面从领口以下取景、不含头部；右格是完整的背面全身、含后脑发型。三格必须是同一个人，发型发色、服装、体型完全一致，脸与所给参考特写是同一张脸。人物自然站立，双臂垂放身体两侧，双手空着。一米七上下，肩背厚实但已微驼，是常年弓身撑篙压出来的形。上身是洗到发白的藏蓝色粗帆布对襟褂子，领口磨出毛边，袖口挽两折露出小臂；下身黑色宽腿布裤，裤脚沾着干涸的泥点；脚上一双旧黄胶鞋，鞋头磨白。胸前用一根黑棉绳挂着一副老花镜，镜腿断过一条、接口用细麻线密密缠了几道。整体气质沉默、耐磨，像一件用旧但没坏的工具。特写格突出面部与板寸发茬细节，中格看清对襟褂子的剪裁与垂坠，右格看清背部剪裁与后脑发型。
```

为什么这么编：

三格法三件套齐。去头——中格「从领口以下取景、不含头部」，广角格的糊脸是模型复制进远景的脸源，去掉后全图唯一脸源 = 特写格。同一人双保险——版式句一遍 + 「三格必须是同一个人……同一张脸」复述一遍。手空与穿戴两分——「双手空着」，老周的竹篙会在船上放下、会递给人，是持握物、归 prop-design 的 prop-005，绝不长进表里；胸前那副老花镜全片挂着不摘，是穿戴类固定特征，必须画进表里，不画的话他每次入镜戴不戴由模型即兴。它同时有特写、过了道具入库判据 = 双源件，形态真相源在道具板 prop-006，这里照它的形制写、不自拟，生成顺序上 prop-006 四视排在 G3 之前。服装维承担时代：对襟褂、黄胶鞋的年代形制写死——取自 visual-style「时代与世界锚」的年份/地理与服装形制，不自拟；角色板上时代只穿在身上，不摆在背景里。G3 引用 G1 当参考图同源生成，正文不重描五官——脸交给参考图，文字重复描脸反而制造第二脸源。

### 声线锁——非生成提示词 · 供动态提示词逐字引用

```
「六十岁上下的男性渡船人，长江下游水乡口音——尾音拖平、声调偏低。沙哑偏干的中低音区；语速慢、句子短、字与字之间留缝；平静里带倦意，被激怒时不升调、反而更低更慢。」
```

为什么这么编：

年龄 + 身份 + 口音条件化 + 音区音色 + 语速形制 + 压力方向，六件齐——口音是类别加两个音位标记而不是「南方口音」标签，压力方向锁死越怒越低越慢、最吓人的话说得最轻。两句成块，此后 motion-compile 在每条台词行逐字引用，连同义词都不换——换措辞就扩大采样范围导致声音漂移。

### 生成与验证注记

    顺序 G1 → G2 → G3 → G4+；双源穿戴件 prop-006 老花镜的道具四视排在 G3 之前，G3 拿它当形态参照。G1 先生成并与密版逐维对照——断痕鼻梁/单眼皮/下唇干裂/板寸发茬，锚不对改词重出、不往下；G1 成图此后不再整体过模型。批量生成期的稳定性验证按 06-motion-prompts/ep01-motion-prompts.md 头部「生成顺序与校准」小节执行。

## 变体条 · char-001-v1 · （EP1 基础装束）（雨夜湿身）（← char-001，G4）

编辑条（基于 G3 三格表成图）

```
编辑这张图：把人物改为刚被暴雨浇透的状态。
改动：唯一变化是「湿」——板寸发茬吸水贴向头皮、发色变深，对襟褂子和布裤整体颜色变深、湿布料贴在肩背与小臂上、有纵向水渍，裤脚与鞋面滴水反光。
严格保留：五官、脸型、肤质、三格版式、姿态、服装的款式与磨损细节、胸前老花镜的形制与麻线缠法、背景、光线、构图、调色与颗粒。
只改湿透状态，其余 100% 不变。
```

密版增量：

    发贴头皮色深、衣裤透湿贴身、裤脚鞋面滴水，其余同 char-001。

为什么这么编：

湿身跨条持续、下一条还看得见 → 过状态升格判据，建变体而非写一句散文——写散文三条之后模型把他晾干。做法是蒙版点改 G3 而非重新生成，底图保持同一批像素、纹理存活；「湿」拆成贴、色深、滴水这些可见证据，而不是一个形容词。新编号 -v1、语义标签、谱系登记，原版 char-001 一字不动永不覆盖。

## 群演条 · char-090 · 码头晨市人群（边角，群演，首登场 ep01 场02）——生成条 · 跨条复用，出图

```
写实电影质感，低饱和青灰打底、暖黄灯光作唯一强调色且必须来自画面内真实光源物，柔和散射光交代质感与体积，胶片颗粒细腻、写实克制；球面镜头，构图安静克制。群体质感参考图，三四分之三视角中景，清晨阴天的散射光。画面是挤在码头石阶与摊位之间的身体：前景交叠的手臂、扁担和竹筐的局部，中景弓身讨价与递接货物的身影，后景是雾里无清晰面孔的人影层。所有人物面孔模糊不可辨。衣着一律是九十年代江边小镇的形制——粗布短打、藏蓝与灰褐的旧夹克、胶鞋与解放鞋，一律素面本色、颜色灰旧统一。氛围潮湿、拥挤、嗡嗡作响的早市感。
```

为什么这么编：

人群是一个资产，不逐人建档；通篇没有人数——超过 15 人必塌缩成三五个人形——写的是「身体的质量与局部」：挤着的身体、前景手臂、后景人影层。「所有人物面孔模糊不可辨」是脸源唯一性纪律：群演图里的清晰脸会成为杂脸源，污染主角远景。服装用正向穷举锚死年代，不写「没有现代服装」——负面措辞会注入被禁概念。环境只给一层承托面——石阶与摊位边、雾里的人影层，够托住这堆身体即止：群演质感板是角色类板里唯一带环境的一张，再铺下去就成了半张场景板，与 scene-design 的板打架。编号从 090 段起与具名角色隔开。
